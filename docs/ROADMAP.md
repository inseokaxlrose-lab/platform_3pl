## M2.5. 플랫폼 기반 — 명명 규칙 · 공통 칸 · 멀티테넌트

목표: 운영사 정의서(tb_operator)의 규칙을 모든 표에 맞추고, 여러 운영사가 한 시스템을 쓰는 구조로 바꾼다. 업무 화면(품목·재고)을 만들기 전에 끝낸다 (나중에 바꾸면 더 어렵다).

- [x] 1a. DB 이름 바꾸기 — 표 `tb_` + snake_case, 칸 접미사(`_id`·`_cd`·`_nm`·`_no`·`_yn`·`_dt`·`_at`), 코드 이름은 그대로(Prisma `@map`), 데이터 보존(RENAME) (`docs/db-conventions.md`, 0037)
- [x] 1b. 내부 키 BIGINT 자동 증가 — 기존 데이터는 등록 순서대로 번호를 다시 매겨 보존, Better Auth `serial`, 서버는 bigint · 화면은 글자 (`src/lib/id.ts`)
- [x] 1c. 예/아니오 칸(`_yn`) CHAR(1) `'Y'`/`'N'` + 검사 조건, 화면은 true/false 그대로·DB 경계에서 `toYn`/`isYes` (`is_active`는 2단계 `status_cd`로)
- [x] 2. 기준정보 공통 칸 (0038)
  - [x] 2a. 등록·수정한 사람(`created_by`/`updated_by`, 자동 기록) + 동시 수정 막기(`row_version`, 수정 화면·팝업 전부)
  - [x] 2b. `status_cd`(사용/중지)가 `isActive` 대체 — 화면은 true/false 그대로, DB 경계에서 변환, 로그인 검사 포함
  - [x] 2c. `del_yn` 논리 삭제 + 코드 재사용(부분 고유 인덱스) + 목록 "삭제됨" 보기·[되살리기] (공통코드는 [지운 항목] 팝업)
- [x] 3. 멀티테넌트 (0039)
  - [x] 3a. 운영사 키·데이터 분리 — 11개 표에 `operator_id`, 코드는 운영사 안에서만 고유·아이디는 전체 고유, 데이터 범위 + Prisma 안전망(운영사 출입증) 두 겹, 두 운영사 격리 테스트
  - [x] 3b. 플랫폼 관리자(`/platform`) — 운영 중이 아닌 운영사 로그인 막기, 운영사 전환(배너 "○○ 운영사로 작업 중 [나가기]", 기록은 플랫폼 관리자 아이디)
  - [x] 3c. 운영사 만들기 — 공통코드·단위·권한그룹 기본값 복사 + 관리자 `admin.○○` 자동 생성, 시드에 두 번째 견본 운영사(나라물류)
- [x] 4. 운영사 정의서 반영 — 1차 칸 DB·API·화면 / 2차 칸 DB·API 기본값, 운영사 목록(플랫폼), 상태 변경 팝업(사유 필수), 공통코드·enum 등록, 담당 업무 → `CONTACT_ROLE` (0040, `docs/operator-columns.md`)
- [x] 5. 문서 정리 (도메인 모델·PRD·README·가이드, 옛 결정 기록에 갱신 표시)

완료 기준: 빈 DB에서 마이그레이션만으로 새 구조가 만들어지고, 운영사 두 곳의 데이터가 서로 보이지 않는다. → 완료 (2026-11-15: 빈 DB 마이그레이션·차이 없음, 두 운영사 격리 DB 테스트 + `admin.nara`로 예시물류 센터 404 확인)

- [ ] 재고 조회: 소유 기준 (화주사 / 품목), 환산단위 함께 표시
- [ ] 재고 조회: 로트번호 / 유통기한 기준 (품목별 임박 기준으로 "임박" 배지 표시)
- [ ] 재고 실사 차이 등록
- [ ] 재고 조정 등록 (사유 필수, 권한 필요)
- [ ] 재고 이력 조회
- [ ] 화주 포털: 내 재고 조회

완료 기준: 실사 차이를 조정하면 수량과 이력이 일치하고, 화주사는 자기 재고만 본다.

## M7. MVP 마무리

- [ ] 정산·보고용 자료 추출 화면 (기간별 입고·재고 현황 엑셀)
- [ ] 전체 흐름 브라우저 테스트 (Playwright)
- [ ] 화면 다듬기 (빈 상태, 에러 메시지, 로딩)
- [ ] 배포 방법 결정 및 첫 배포

## MVP 이후 (아이디어 보관함)

- 출고: 배송요청 등록(화주 포털), 피킹, 패킹, 상차, 거래처출고
  - 배송권역 연결: 배송지 주소(카카오 `bcode` 앞 5자리)로 센터·권역 정하기, 권역 삭제 전 "쓰인 적" 검사(`findUsedZoneIds`) 채우기, 배송 요일·마감 시각 등 운영 정보 (0033)
- 센터 간 이동: 수송출고 / 수송입고
- 정산·청구 계산
- 바코드 스캐너 / 모바일 작업 화면
- 외부 연동 (쇼핑몰, 택배사)
- 비밀번호: 다음 로그인 때 변경 강제, 내 비밀번호 변경 화면
