## M1. 로그인과 권한

목표: 사용자마다 보이는 메뉴·버튼·데이터가 다르다

- [ ] 사용자 / 권한그룹 / 권한 코드 DB 모델
- [ ] 메뉴·버튼 권한 코드 정의 (코드 한 곳에 목록으로)
- [ ] 로그인 / 로그아웃
- [ ] 최종 권한 계산 (그룹 권한 + 사용자 추가 − 사용자 제외) + 테스트
- [ ] 화면: 권한에 따른 메뉴·버튼 표시
- [ ] 서버: 권한 검사 공통 함수
- [ ] 데이터 범위 장치 (전체 / 소속 센터 / 자기 화주사) + 테스트
- [ ] 권한그룹 관리 화면, 사용자 관리 화면
- [ ] 개발용 시드 데이터 (역할별 계정 4종)

완료 기준: 권한 없는 메뉴·버튼이 안 보이고 서버에서도 거부되며, 다른 센터·화주사 데이터가 안 보인다 (테스트로 증명).

## M2. 기준정보 — 운영사 · 센터

- [ ] 운영사 정보 관리
- [ ] 센터 관리 (생성 시 입고대기 창고 + 기본 로케이션 자동 생성)
- [ ] 센터별 창고 관리 (창고 유형)
- [ ] 창고별 로케이션 관리 (일괄 생성 기능 포함: 예 A-01-01 ~ A-10-05)
- [ ] 센터별 배송권역 관리

완료 기준: 센터 2곳, 각 센터에 창고·로케이션을 화면에서 등록할 수 있다.

## M3. 기준정보 — 화주사

- [ ] 단위 코드 관리 (EA, KG, BOX, CARTON, PLT 등)
- [ ] 화주사 정보 관리 (기본값: 로트·유통기한 사용, 라벨 단위 PLT/BOX / 이용 센터 연결)
- [ ] 화주사 품목 관리 (기본단위, 환산단위·입수량, 로트·유통기한 사용 여부, 라벨 단위, 유통기한 임박 기준 일수) — 운영사 화면 + 화주 포털
- [ ] 단위 환산 공통 함수 + 테스트
- [ ] 화주사 거래처 관리

완료 기준: 로트를 쓰는 화주사와 안 쓰는 화주사의 품목을 각각 등록하고, 환산단위가 올바르게 계산된다.

## M4. 재고 기반

목표: 입고 전에 "재고를 바꾸는 유일한 통로"를 먼저 만든다

- [ ] 재고 / 재고 이력 DB 모델 (재고 주소: 센터+창고+로케이션+화주사+품목+로트+유통기한)
- [ ] 재고 변경 공통 함수 (증가, 감소, 이동 — 이력 기록과 한 트랜잭션)
- [ ] 마이너스 재고 방지, 동시 처리 안전성 테스트

완료 기준: 재고 변경 함수 테스트가 모두 통과하고, 이 함수 말고는 재고를 바꿀 방법이 없다.

## M5. 입고 관리

목표: 입고 한 바퀴가 끝까지 돈다

- [ ] ASN / 입고확정 모델 (헤더 + 라인, 입고 유형, 등록 경로, 누적 확정·적치 수량)
- [ ] ASN 화면 등록 — 화주 포털 + 센터 운영자 대리 등록
- [ ] 엑셀 업로드 공통 컴포넌트 (양식 다운로드, 검증 미리보기, 오류 행 표시)
- [ ] ASN 엑셀 업로드
- [ ] ASN 조회: 목록 / 입고·적치 상태, 라인별 잔량·초과 수량 표시
- [ ] ASN 잔량 마감 (사유 필수, 권한 필요, 마감 후 추가 확정 차단)
- [ ] 입고 검수 (검수 수량, 불량 수량, 로트·유통기한 — 품목 설정에 따라 표시)
- [ ] 관리 라벨 데이터 + QR / Data Matrix 코드 생성 (형식 버전 포함)
- [ ] 라벨 양식 4종 (PLT 2종 + BOX 2종, 단위별 기본 양식)
- [ ] 라벨 인쇄 화면 (양식 선택·기억, 미리보기, 여러 장 인쇄, 재발행 — 브라우저 인쇄)
- [ ] 입고 확정 (부분 확정, 초과 확정 가능) → 입고대기 창고에 재고 생성
- [ ] 적치 등록 (확정된 재고만, 부분 적치 가능) → 보관 로케이션으로 이동
- [ ] 입고 흐름 통합 테스트
  - 부분 확정 2회 + 부분 적치
  - 초과 입고 확정
  - 잔량 마감 후 추가 확정 차단, 기존 확정분 적치는 가능

완료 기준: 위 시나리오에서 수량(예정/확정/잔량/초과/적치)이 정확히 맞고, 재고가 정확한 위치에 생기며 이력이 남는다. 라벨이 실제 프린터로 인쇄되고 코드가 스캔된다.

## M6. 재고 관리

- [ ] 재고 조회: 위치 기준 (센터 / 창고 / 로케이션)
- [ ] 재고 조회: 소유 기준 (화주사 / 품목), 환산단위 함께 표시
- [ ] 재고 조회: 로트번호 / 유통기한 기준 (품목별 임박 기준으로 "임박" 배지 표시)
- [ ] 재고 실사 차이 등록
- [ ] 재고 조정 등록 (사유 필수, 권한 필요)
- [ ] 재고 이력 조회
- [ ] 화주 포털: 내 재고 조회

완료 기준: 실사 차이를 조정하면 수량과 이력이 일치하고, 화주사는 자기 재고만 본다.

## M7. MVP 마무리

- [ ] 정산·보고용 자료 추출 화면 (기간별 입고·재고 현황 엑셀)
- [ ] 전체 흐름 브라우저 테스트 (Playwright)
- [ ] 화면 다듬기 (빈 상태, 에러 메시지, 로딩)
- [ ] 배포 방법 결정 및 첫 배포
