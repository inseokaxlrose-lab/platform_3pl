# 0093. 센터·창고 사용자 정의 코드, 사용자 연락처·로그인 잠금·로그인 이력 (M8 A7)

- 날짜: 2026-11-20
- 상태: 채택
- 관련: 0025·0068 (기준정보 코드 3층), 0086 (임시 비밀번호), 0010 (인증), 기준정보 누락 검토 1-1·2-1
- 코드: `src/lib/users/login-guard.ts`, `src/lib/auth.ts`(세션 만들기 검사), `src/app/login/actions.ts`, `src/app/admin/system/users/`(계정 관리·로그인 이력), `src/lib/centers/centers.ts`·`src/lib/warehouses/warehouses.ts`
- 마이그레이션: `20261120140000_codes_security`

## 배경

- 화주사·품목·거래처에는 사용자 정의 코드(`*_cust_cd`)가 있는데 센터·창고에는 없어, 화주·ERP 시스템이 쓰는 센터·창고 코드를 둘 곳이 없었다.
- 사용자에 연락처·부서가 없어 담당자에게 연락하기 어렵고, 비밀번호를 계속 틀려도 막지 않았으며 누가 언제 로그인했는지 남지 않았다.

## 결정

### 센터·창고 사용자 정의 코드

- `tb_center.center_cust_cd`, `tb_warehouse.warehouse_cust_cd` (VARCHAR(50), 선택). 0025의 3층 구조 중 두 번째 층.
- 겹침 검사: 센터는 **운영사 안**, 창고는 **같은 센터 안**(창고코드와 같은 범위). 언제든 고칠 수 있고 시스템 기본 창고도 고칠 수 있다.
- 목록 검색어에 포함한다.

### 사용자 연락처

- `tb_user`에 `tel_no`(숫자만, 0029)·`dept_nm`·`position_nm`·`emp_no` (모두 선택). 등록·수정 화면 기본 정보에 둔다.

### 로그인 실패 잠금 (사용자 결정: 5회 연속 실패 → 30분 잠금)

- `tb_user.login_fail_cnt`(연속 실패 수)·`locked_until`(잠금 끝 시각).
- 비밀번호가 틀리면 +1, **5회**가 되면 `locked_until = 지금 + 30분`, 실패 수는 0으로. 성공하면 실패 수 0·잠금 해제.
- 잠긴 동안은 맞는 비밀번호여도 로그인되지 않는다. 로그인 화면 액션이 먼저 막고(남은 분 안내), **세션 만들기 hook(`auth.ts`)도 다시 막아** 인증 API를 직접 불러도 우회되지 않는다.
- 관리자는 사용자 수정 > 계정 관리의 [잠금 풀기](`system.users.update`)로 바로 푼다.
- 마지막 로그인: `last_login_at`·`last_login_ip`. 사용자 목록에 "마지막 로그인" 열.

### 로그인 이력

- `tb_login_hist` (사용자·운영사·아이디·결과·IP·브라우저·일시). 결과 `SUCCESS`·`FAIL`·`LOCKED`·`DISABLED` (상수 `LOGIN_RESULT_VALUES` + CHECK).
- 없는 아이디의 실패도 남긴다(사용자·운영사 비움) — 아이디 추측 공격을 나중에 볼 수 있게.
- 화면: 사용자 수정 맨 아래 **로그인 이력**(최근 20건, 보기만 — `MasterFormSection.standalone: 'view'`로 "바로 적용" 표시를 뺌).
- 운영사 자동 거르기(`TENANT_MODELS`)에 넣지 않는다: 로그인 전(운영사를 모름)에 쓰고, 화면에서는 범위 검사를 통과한 사용자 키로만 읽는다.

## 버린 안

- **실패 횟수를 일정 시간 창으로 세기**(예: 10분 안 5회): 구현이 복잡하고, "연속 실패"가 사용자에게 설명하기 쉽다.
- **잠금을 관리자만 풀기**: 현장 작업자가 실수로 잠기면 업무가 멈춘다. 30분 뒤 자동으로 풀리고, 급하면 관리자가 푼다.
- **로그인 이력 보관 기간 설정**: 지금은 지우지 않는다. 정리 기준은 로그 보관 정책(0092 상수)과 함께 정한다.

## 남은 일

- 인증 API를 직접 부른 실패는 횟수를 세지 않는다(로그인 화면 액션에서만 센다). 잠금 자체는 hook이 막는다.
- 이력 정리 작업(보관 기간)은 운영 배포 결정(0067) 때 함께.
