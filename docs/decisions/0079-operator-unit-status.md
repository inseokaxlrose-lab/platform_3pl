# 0079. 시스템 기본 단위의 운영사별 사용 여부 · 소수 자리수

- 날짜: 2026-11-17
- 상태: 채택
- 관련: 0078 (시스템 기본 단위 공유 행 — 운영사가 고칠 수 없음), 0039 (운영사별 데이터)
- 코드: `src/lib/units/unit-status.ts`, `units.ts`의 `setUnitsActive`, 마이그레이션 `20261117220000_operator_unit_status`·`20261117230000_operator_unit_decimals`

## 배경

시스템 기본 단위 20개를 모든 운영사가 함께 쓰게 했더니(0078) 쓰지 않는 단위(LB·INCH 등)도 늘 단위 고르기에 나왔다. 사용자 제안: 기본으로 제공하되 사용/사용 중지는 운영사별로 갖는다.

## 결정 (사용자 결정: 추천안)

- **운영사별 설정 표 `tb_operator_unit`** (운영사, 시스템 단위, 상태)
  - 사용 중지한 단위만 줄이 생긴다. 줄이 없으면 시스템 단위의 상태(사용)다.
  - 시스템 단위만 받는다(DB 트리거). 운영사 추가 단위는 자기 `status_cd`를 쓴다.
  - 운영사별로 갖는 것은 **사용 여부와 소수 자리수**다(소수는 아래 "추가"). 이름·정렬·출력명은 같은 값이다.
- **실제 상태** = 운영사 설정 ?? 단위 상태 (`effectiveUnitStatus`)
  - 읽는 곳은 `unitStatusSelect(운영사)`로 설정을 함께 읽는다: 단위 목록(상태 거르기 `unitStatusWhere` 포함), 편집 화면 배지, `getUnitOptions`, 품목 화면 선택지, 품목 저장 검사.
- **[사용 중지]·[다시 사용]**
  - 목록에서 시스템 단위도 고를 수 있다.
  - 운영사 단위는 상태를 바꾸고, 시스템 단위는 이 운영사의 설정만 upsert한다.
  - 삭제는 여전히 운영사 단위만 할 수 있다.
- **사용 중지할 수 없는 단위**
  - **EA·BOX·PLT**: 프로그램이 직접 쓰는 기본 수량·라벨 단위다.
  - 운영사의 **중량·길이 표시 단위**: 운영사 추가 단위여도 막는다.
  - 섞여 있으면 전체를 거부한다.
- 쓰는 곳이 있는 단위를 사용 중지하면 경고(notice)한다. 기존 데이터는 그대로 보이고 새로 고를 때만 빠진다.

## 추가 (같은 날): 운영사별 소수 자리수 · 목록 버튼 잠금

사용자 요청: "소수 자리수도 운영사별로 따로" / "EA를 고르면 사용 중인데도 [다시 사용]·[삭제]가 눌린다".

- **`tb_operator_unit.decimal_cnt`** (비면 시스템 값, 0~6 검사 조건)
  - 실제 소수 자리수 = 운영사 설정 ?? 단위 값 (`effectiveUnitDecimals`). 운영사 추가 단위는 자기 `decimal_cnt`.
  - 시스템 값과 같게 되돌리면 설정 칸을 비운다(null).
- **읽는 곳**: 단위의 `decimals`를 읽던 select를 `unitDecimalsSelect(운영사)`로 바꾸고 결과를 `resolveUnitDecimals`로 감싼다. 결과 안의 단위마다 `decimals`를 실제 값으로 바꾸므로 화면·계산 코드는 그대로 `unit.decimals`를 쓴다.
  - 대상: ASN·검수·입고·적치·라벨·재고 조정 조회와 저장, `receiveStock` 등 재고 변경 검사, 품목 화면·저장 검사, `getUnitOptions`, 단위 목록·편집 화면.
- **편집 화면**: 시스템 단위는 **소수 자리수만** 고칠 수 있다(`setUnitDecimalsAction`). 칸 아래에 "시스템 값 3 · 이 운영사만 바꿈"을 보인다.
  - 줄일 때는 운영사 단위와 같은 검사(`findDecimalOverflow`)로 막는다. 이 운영사의 데이터만 본다.
- **목록 버튼 잠금** (`unit-bulk.ts`의 `bulkAvailability`): 고른 단위로 할 수 없는 버튼은 누를 수 없게 하고, 마우스를 올리면 이유를 보인다.
  - [사용 중지]: EA·BOX·PLT·표시 단위가 섞였거나 모두 이미 사용 중지.
  - [다시 사용]: 모두 이미 사용 중.
  - [삭제]: 시스템 기본 단위가 섞임.
  - 서버 검사는 그대로 둔다(화면 + 서버 둘 다).

## 버린 안

- **운영사별 복사본으로 되돌리기**: 0078에서 버린 이유 그대로다(시스템 단위 수정 때 모든 복사본을 맞춰야 함).
- **정렬·출력명도 운영사별**: 요청 범위를 넘는다. 필요해지면 같은 표에 칸을 더한다.
- **소수 자리수를 읽는 곳마다 운영사 설정을 따로 조회**: 고칠 곳이 많고 빠뜨리기 쉽다. select 조각 + 결과 한 번 감싸기로 모았다.

## 남은 일

- 목록의 "상태" 열 정렬은 단위 자체의 상태 기준이다(운영사 설정 반영 정렬은 건수가 적어 두지 않음).
