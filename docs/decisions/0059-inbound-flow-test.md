# 0059. 입고 흐름 통합 테스트 (M5 완료)

- 날짜: 2026-11-16
- 상태: 채택
- 관련: 0047~0058 (M5 입고 관리), PRD 완료 기준 "화주사가 ASN을 등록하면 → 작업자가 검수·라벨 발행 → 입고 확정 → 적치하고, 화주사가 포털에서 … 확인"

## 테스트 `src/app/admin/inbound/inbound-flow.db.test.ts`

서버 액션을 실제 사용자 역할(화주사 포털 사용자 / 이천센터 작업자, 권한 코드를 그 역할만큼)로 바꿔 가며 한 바퀴 돈다.

1. 화주사: 포털에서 ASN 등록 — 생수 PLT 2(= 2,880 EA), 우유 50 EA
2. 작업자: 검수 — 생수 2,000(불량 10), 우유 로트 MA 30 · MB 20 → ASN 검수중
3. 라벨 — 생수 2,000 ÷ PLT 1,440 → 2장(1,440 / 560), 코드 글자 확인, 인쇄 기록. 우유는 PLT 입수량이 없어 거부
4. 부분 확정 — 생수 1,500 + 우유 전부 → 부분확정
5. 적치 — 생수 A-01 1,000 + A-02 500, 우유 두 로트 A-02 → 부분적치
6. 나머지 도착 — 생수 검수 1,000(초과), 남은 500과 함께 확정 → 누적 3,000(예정 2,880, 초과 120) → 확정완료
7. 나머지 적치 → 적치완료

확인: 입고대기 재고 0, 로케이션·로트별 재고, 품목별 재고 합계 = 확정 합계(불량 제외), 재고 줄마다 이력 합계 = 수량·음수 없음, ASN 진행(초과 120·잔량 0), 목록 초과 줄, 화주사 포털 목록의 상태.

## 함께 한 것

- 밤사이 브라우저 확인에 쓴 임시 데이터(임시 품목·ASN·검수·라벨·확정·재고·적치·임시 창고)를 개발 DB에서 모두 지웠다. 재고 이력은 수정 금지 트리거 때문에 한 트랜잭션 안에서만 그 트리거를 껐다 켰다(켜진 것 확인).
- 화주 포털의 "늘어난 재고 확인"은 M6 "화주 포털: 내 재고 조회"에서 만든다(지금은 ASN 진행 상태로 확인).
