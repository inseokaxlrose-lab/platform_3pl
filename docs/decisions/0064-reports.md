# 0064. 정산·보고용 자료 추출

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: PRD 공통 3 (정산·보고용 자료 엑셀 추출), ROADMAP M7 "기간별 입고·재고 현황 엑셀"

## 화면 `/admin/system/exports` (권한 `system.exports.read`, 내려받기 `system.exports.export`)

자료 고르기 → 기간·센터·화주사 → [엑셀 내려받기]. 서버가 시트 모양(제목 + 행)을 만들고 화면이 기존 `downloadXlsx`로 파일을 만든다.

| 자료 | 내용 |
| --- | --- |
| 입고 실적 | 기간 안 입고 확정 줄: 확정 일시·번호, ASN·화주사 문서 번호, 센터, 화주사, 품목, 로트·유통기한, 확정 수량, 단위, 확정자 |
| **기간 재고 수불** | 화주사·품목별 **기초(시작일 0시) + 입고 + 조정(+) + 조정(−) = 기말(종료일 24시)** — 재고 이력을 합산. 이동은 같은 화주사·품목 안이라 합계 0이어서 칸을 두지 않음 |
| 현재 재고 | 재고 조회(위치별)와 같은 내용 |

- 수량은 BigInt로 계산하고 엑셀 칸에만 숫자로(엑셀에서 더할 수 있게).
- 기간은 한국 날짜 기준, 최대 1년(366일). 1만 행을 넘으면 앞 1만 행만 담고 안내.
- 데이터 범위 적용(센터 직원은 소속 센터).
- 함수: `src/lib/reports/report-schema.ts`, `src/lib/reports/reports.ts`.

## 추천안으로 정한 것 (검토 필요)

- 자료 3가지(입고 실적·기간 재고 수불·현재 재고). 보관료 계산(일별 보관량 × 단가)은 요금 체계가 정해지면 다음 단계에서 — 수불 자료가 그 기초.
- 파일은 화면에서 만든다(1만 행까지). 더 크면 서버 파일 생성 방식으로 바꾼다(0002 원칙과 같음).
- 출고·센터 간 이동은 MVP 이후라 수불 칸에 없다.
