# 0021. DataGrid 사용자별 설정 저장

- 날짜: 2026-11-13
- 상태: 채택
- 관련: 0002 (UI와 DataGrid), 0015 (서버 액션 공통 틀)
- 코드: `src/components/data-grid/` (`settings.ts`, `grid-settings-context.ts`, `grid-settings-provider.tsx`, `use-data-grid-state.ts`, `data-grid-resizer.tsx`), `src/lib/grid/grid-settings*.ts`

## 결정

### 저장하는 것

| 항목 | 비고 |
|---|---|
| 숨긴 컬럼, 컬럼 순서 | [컬럼] 팝오버: 체크 = 표시, ↑↓ = 순서 |
| 컬럼 너비 | 제목 칸 오른쪽 손잡이: 끌기 / ←→ 10px / 두 번 클릭 = 그 컬럼만 기본 너비 |
| 행 높이, 한 페이지 건수, 정렬 | 마지막으로 쓴 값 |

- 검색어·페이지 번호는 저장하지 않는다 (그때그때 쓰는 값).
- [기본값 되돌리기]는 위 모든 항목을 지우고 처음 모습으로 돌린다.

### 저장 위치와 흐름

- DB 표 `UserGridSetting`: 사용자 + 그리드 이름(`<DataGrid id>`) 하나에 JSON 한 줄. 어느 PC에서든 같은 설정.
- **읽기**: 레이아웃이 권한과 함께 그 사용자의 모든 그리드 설정을 한 번에 읽어 `GridSettingsProvider`로 나눠준다. 그리드가 처음 그려질 때부터 내 설정이라 깜빡임이 없다 (서버가 그리는 HTML부터 적용).
- **쓰기**: 설정이 바뀌면 0.5초 미뤘다가 마지막 값만 저장한다 (너비 끌기·연속 변경 때 매번 보내지 않음). 화면을 떠날 때 남은 저장은 바로 보낸다. 저장 실패는 화면을 막지 않는다 (개인 편의 설정).
- 서버 액션은 메뉴 권한이 아니라 로그인만 필요하다: `createAction`에 `permission: 'signed-in'` 추가 (0015 보완). 항상 로그인한 본인의 설정만 다룬다.
- 보관함이 없는 곳(`/dev/grid` 쇼케이스)은 저장하지 않고 그 화면 안에서만 기억한다.
- DataGrid는 보관함 "꺼내기"(`grid-settings-context.ts`)만 부른다. 서버 액션을 부르는 Provider는 따로 둬서, 그리드 부품 테스트에 DB 연결이 딸려 오지 않게 했다.

### 화면의 컬럼이 바뀌어도 깨지지 않게 (`settings.ts`)

- 읽을 때 Zod로 모양을 검사하고, 깨졌으면 설정 없음(기본 모습)으로 본다.
- 없어진 컬럼의 값은 버린다. 새 컬럼은 기본 순서에서 바로 앞 컬럼 뒤에 넣는다.
- 숨김 금지(`hideable: false`) 컬럼은 저장값이 있어도 숨기지 않는다. 대신 순서는 바꿀 수 있어서 팝오버에 잠긴 체크로 보인다.
- 너비는 60~800px로 보정한다. 정렬할 수 없는 컬럼의 정렬은 버린다.

### 너비 조절 방식

- 처음 조절할 때 지금 보이는 모든 컬럼의 너비를 재서 고정하고, 표를 고정 배치(`table-fixed`)로 바꾼다. 하나를 바꿔도 다른 컬럼이 들썩이지 않는다. 넘치는 글자는 말줄임(…)으로 보인다.
- 끄는 동안에는 화면만 바꾸고, 손을 뗄 때 한 번 저장한다.

### 화면 개발 규칙 (CLAUDE.md)

- 목록 상태는 `useDataGridState('그리드-id')`로 만들고 `<DataGrid id>`에 같은 id를 준다. 그러면 저장된 건수·정렬로 시작한다.
- 그리드 id: 영문 소문자·숫자·하이픈 (예: `system-users`).

## 대안과 버린 이유

- **브라우저 저장소(localStorage)**: 다른 PC에서 유지되지 않는다. 요구사항이 "어느 PC에서든"이다.
- **TanStack 너비 조절 기능**: 너비 저장·고정 방식은 어차피 직접 정해야 하고, 손잡이 하나면 충분해서 작은 부품으로 직접 만들었다.
- **제목 끌어서 순서 바꾸기**: 끌어서 놓기 라이브러리가 필요하고 키보드 사용·테스트가 어렵다. ↑↓ 버튼으로 시작하고, 필요하면 나중에 추가한다 (아이디어 보관함).

## 확인

- 테스트: 설정 정리 함수 6개, 서버 DB 5개, createAction 'signed-in' 2개, 그리드 부품 9개(시작값·저장·되돌리기·너비).
- 브라우저(사용자 목록): 소속 숨김, 상태 순서 변경, 행 높이, 이름 정렬, 이름 컬럼을 마우스로 끌어 402→252px. 새로고침해도 모두 유지됐다. 다른 계정(`ops.admin`)은 기본 모습이었다. [기본값 되돌리기]를 누르자 처음 모습으로 돌아왔고 DB의 줄도 지워졌다. 여러 번 바꿨지만 저장 요청은 2번이었다.
