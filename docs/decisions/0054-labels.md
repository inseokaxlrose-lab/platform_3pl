# 0054. 관리 라벨 데이터 + QR / Data Matrix

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요** (라이브러리 설치 포함)
- 관련: 0003 결정 6 (관리 라벨), 0053 (검수), 0042 (`labelQuantities`)

## 표 `tb_inbound_label` (마이그레이션 `20261116110000_labels`)

- 검수 결과 하나 → 라벨 여러 장. 칸: 라벨 번호(`LB261116-00001`, 하나뿐), 검수, 순번/장수(2/3), 라벨 단위(PLT·BOX), 이 장의 수량(기본단위), **형식 버전**, 2D 코드 글자(`payload`), 인쇄 횟수·마지막 인쇄 일시·사람, 만든 일시·사람.
- DB 검사: 수량 > 0, 1 ≤ 순번 ≤ 장수, 형식 버전 ≥ 1, 인쇄 횟수 ≥ 0. (검수, 순번) 하나.

## 발행 (`src/lib/labels/labels.ts`)

- `ensureLabels(검수)`: 정상 검수 수량 ÷ 라벨 단위 입수량(품목 → 화주사 기본값으로 정해진 PLT·BOX) → `labelQuantities`(올림, 마지막 장은 나머지, 최대 1,000장). 이미 있으면 그대로(번호 고정).
  - 거부: 라벨 단위 입수량이 품목에 없음, 정상 수량이 0(불량뿐).
- `markLabelsPrinted`: 인쇄할 때마다 횟수 +1 (재발행 = 같은 번호를 다시 인쇄).
- 검수 지우기: 인쇄한 라벨이 있으면 거부, 인쇄 전 라벨은 함께 지운다.

## 2D 코드 글자 (`src/lib/labels/label-payload.ts`, 형식 버전 1)

```
L1|라벨번호|센터|화주사|품목코드|로트|유통기한YYYYMMDD|수량|단위
L1|LB261116-00001|ICN|GANA|WATER|L240101|20270131|1440|EA
```

- 맨 앞 `L1` = 형식 버전. 항목이 늘면 `L2`로 올리고 스캐너가 버전을 보고 읽는다(`parseLabelPayload`).
- 칸 나눔 `|`, 값 안의 `|`는 `/`로 바꿔 넣는다. 수량은 기본단위.

## 코드 그림 (`src/lib/labels/barcode.ts`)

- **라이브러리 bwip-js 4.11.4 (MIT)** 설치 — QR·Data Matrix를 모두 그리고(SVG), 필요한 두 종류만 불러온다(`bwip-js/generic`). 설치 전후 `npm audit` 결과는 같다(기존 경고 8개, bwip-js와 무관).
- `codeSvg('QR' | 'DATAMATRIX', 글자)` → SVG 글자.

## 추천안으로 정한 것 (검토 필요)

- **bwip-js 설치**(밤사이 작업이라 묻지 않고 설치 — 바꾸려면 알려 주세요).
- 글자 모양 `L1|…|…` (구분자 방식, 0003 대로), 유통기한은 `YYYYMMDD`, 수량은 기본단위.
- 라벨은 인쇄 화면에서 처음 열 때 만든다(검수 등록 때 자동으로 만들지 않음).
