# 0098. 외부코드 대상 확대·세트 구성품·거래처별 품목코드 (M8 B5)

- 날짜: 2026-11-22
- 상태: 채택 (사용자 결정: 거래처별 품목코드는 별도 메뉴 + 엑셀, 세트는 가상·실물 구분하되 1차는 가상만, 구성품은 품목 화면 안 섹션 — 모두 추천안)
- 관련: 0025·0068 (외부코드 매핑), 0084 (코드 3층), 기준정보 누락 검토 1-10·2-6·2-9·3-6

## 1. 외부코드 대상에 납품처·구역

- `tb_ext_code.entity_type_cd`에 `SHIP_TO`(납품처)·`ZONE`(구역) 추가 (마이그레이션 `20261122100000_ext_code_targets`). 운송사·배송 코스는 B1·B2에서 이미 넣었다.
- 외부코드 매핑 화면의 대상 순서: 센터 계열(센터·창고·구역) → 화주 계열(화주사·품목·거래처·납품처) → 공통(단위·운송사·배송 코스).
- 소속 칸: 납품처 = 거래처, 구역 = 창고. 데이터 범위: 납품처는 거래처와 같은 규칙(화주사·센터), 구역은 센터.
- 로케이션(`LOCATION`)은 DB에는 있지만 아직 연동 대상이 아니라 화면에서 뺀 그대로 둔다.

## 2. 세트 구성품·세트 방식

- `tb_item.set_type_cd` (상수 `SET_TYPE`, 세트 품목만): `VIRTUAL` 가상 세트(세트 재고 없이 출고 때 구성품 재고에서 뺀다) / `KIT` 실물 세트(조립해 세트 자체를 재고로). 1차 출고는 가상 세트만 쓰고, 실물 세트 조립 작업은 부가작업(C1) 때. 기존 세트 품목은 마이그레이션에서 가상 세트로 채웠다.
- `tb_item_set_component` (세트 품목 × 구성 품목, 수량 = 구성 품목의 기본단위, 순서). 품목 저장 때 바코드처럼 통째로 다시 쓴다.
- 규칙
  - 같은 화주사의 품목만, **세트 안에 세트 불가**(한 단계), 자기 자신 불가, 같은 품목 두 번 불가, 1개 이상, 50개까지, 수량은 구성 품목 기본단위의 소수 자리까지.
  - 다른 세트의 구성품인 품목은 세트로 바꿀 수 없고 지울 수 없다(세트에서 먼저 빼거나 함께 지운다). 세트를 되살릴 때 구성품이 지워져 있으면 거부.
  - 세트가 아닌 유형으로 바꾸면 구성품·세트 방식을 지운다.
- **구성품을 보내지 않으면 그대로 둔다**(입력 규칙의 `components`·`setType`은 선택): 엑셀 업로드·연동 API는 구성품을 다루지 않는다. 세트 방식 없이 세트를 만들면 가상 세트. 수정 화면 조회(`itemInputOf`)는 세트 품목만 구성품을 채운다 — 세트가 아닌 품목에 빈 목록을 주면 API가 유형만 SET으로 바꿀 때 "1개 이상"에 막히기 때문.
- 화면: 품목 등록·수정(운영사·포털 공용)에서 유형을 세트로 고르면 **세트 방식** 칸과 **세트 구성품** 섹션(`EditableSubTable`, 구성 품목 검색 선택 + 수량 + 기본단위 표시)이 나타난다. 선택지는 `listSetComponentOptionsAction`(운영사)·`listPortalSetComponentOptionsAction`(포털, 자기 화주사 고정).

## 3. 거래처별 품목코드

- `tb_customer_item` (거래처 × 품목): 거래처 품목코드(필수, 거래처 안에서 고유)·거래처 품목명·거래처 바코드·납품 단위(품목의 단위 중, NULL = 기본 주문단위)·최소 잔여 유통기한 일수·비율(품목별 예외, NULL = 거래처 값)·상태(사용/사용 중지)·비고. 같은 거래처에 같은 품목은 한 줄. 지우지 않고 숨긴다(`del_yn`) + 되살리기(같은 품목·같은 코드가 다시 생겼으면 거부).
- 거래처와 품목은 같은 화주사, 거래처는 **매출처·매출매입만**(매입처는 납품하지 않는다).
- 메뉴 **기준정보 › 거래처별 품목코드** (`/admin/master/customer-items`), 권한 `master.customer-items.*`(조회·등록·수정·삭제·엑셀). 기본 역할: 슈퍼 관리자 전체, 센터 운영자 전체(범위는 소속 센터를 이용하는 화주사 — 거래처와 같은 범위).
- 목록 + 팝업(화주사를 고르면 그 화주사의 거래처·품목을 불러온다) + **엑셀 업로드**: 거래처·품목은 화주사의 연동 조회 키(0084)로 찾고, 이미 있으면 넣은 칸만 고친다(비운 칸 그대로). 오류가 하나라도 있으면 파일 전체를 등록하지 않는다(거래처 업로드와 같은 방식).
- 화주 포털 화면은 아직 없다(출고 기능 때 화주 사용자가 직접 관리할지 정한다). 납품서·라벨에 찍는 것은 출고·출력 양식(B6) 때 연결.

## 버린 안

- 거래처별 품목코드를 **거래처 화면·품목 화면 안 표로**: 거래처 하나에 품목이 수백~수천 개라 화면이 길어지고, 엑셀 일괄 등록과 맞지 않는다.
- **가상 세트만**(세트 방식 칸 없이): 실물 세트를 나중에 넣을 때 기존 세트를 다시 분류해야 한다.
- 세트 구성품 **별도 메뉴**: 세트는 품목의 한 종류라 품목 화면에서 함께 보는 편이 자연스럽다.
