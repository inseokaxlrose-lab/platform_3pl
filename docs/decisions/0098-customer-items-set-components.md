# 0098. 외부코드 대상 확대·세트 구성품·거래처별 품목코드 (M8 B5)

- 날짜: 2026-11-22
- 상태: 채택 (사용자 결정: 거래처별 품목코드는 별도 메뉴 + 엑셀, 세트는 가상·실물 구분하되 1차는 가상만, 구성품은 품목 화면 안 섹션 — 모두 추천안)
- 관련: 0025·0068 (외부코드 매핑), 0084 (코드 3층), 기준정보 누락 검토 1-10·2-6·2-9·3-6

## 1. 외부코드 대상에 납품처·구역

- `tb_ext_code.entity_type_cd`에 `SHIP_TO`(납품처)·`ZONE`(구역) 추가 (마이그레이션 `20261122100000_ext_code_targets`). 운송사·배송 코스는 B1·B2에서 이미 넣었다.
- 외부코드 매핑 화면의 대상 순서: 센터 계열(센터·창고·구역) → 화주 계열(화주사·품목·거래처·납품처) → 공통(단위·운송사·배송 코스).
- 소속 칸: 납품처 = 거래처, 구역 = 창고. 데이터 범위: 납품처는 거래처와 같은 규칙(화주사·센터), 구역은 센터.
- 로케이션(`LOCATION`)은 DB에는 있지만 아직 연동 대상이 아니라 화면에서 뺀 그대로 둔다.
