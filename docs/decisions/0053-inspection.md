# 0053. 입고 검수

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0003 결정 5 (검수 결과는 라인별: 검수·불량·로트·유통기한), 0047 (ASN 모델)

## 표 `tb_inbound_inspection` (마이그레이션 `20261116100000_inspection`)

- ASN 라인 하나에 **여러 건**: 로트·유통기한이 다르게 오면 나눠 적는다.
- 칸: ASN·ASN 라인·품목, 로트·유통기한(품목 설정에 따라 필수/null), **검수 수량(정상)**·**불량 수량**·**그중 확정 수량**(기본단위), 입력 단위·수량(표시용), 비고, 검수 일시·검수자.
- DB 검사: 검수·불량 0 이상, 둘 중 하나 > 0, 0 ≤ 확정 ≤ 검수, 로트 빈 글자 금지.
- 입고확정 라인에 `inspection_id`(NOT NULL, 어느 검수 결과를 확정했는지)를 더했다 — 확정은 검수된 수량에서만 한다.

## 규칙 (`src/lib/inbound/inspections.ts`)

- 권한 `inbound.inspection.read`(화면)·`update`(등록·지우기), 데이터 범위는 ASN 범위.
- 수량은 입력 단위 → 기본단위(`entryToBase`, ASN 등록과 같은 함수로 나눠 씀), 단위·소수 자리 검사.
- 로트·유통기한: 관리 품목은 **필수**, 아니면 넣으면 거부(CLAUDE.md).
- 마감된 ASN은 검수 불가. 첫 검수에 ASN 상태 예정 → **검수중**(이때부터 ASN 수정 불가).
- 지우기: 확정하지 않은 검수만, 마감된 ASN은 불가. 남은 검수가 없으면 ASN은 다시 **예정**.

## 화면

- `/admin/inbound/inspection`: 검수할 ASN 고르기(ASN 목록 재사용, 상태를 고르지 않으면 예정·검수중·부분확정).
- `/admin/inbound/inspection/[asnId]`: 위 품목별 예정·검수·불량·확정·잔량 / 가운데 [검수 등록] / 아래 검수 기록(확정 전이면 지우기).
- 공통 부품 `LocalDataGrid` 추가: 화면이 이미 가진 작은 목록을 공통 그리드로(페이지 나누기만 화면에서). 진행 현황 표도 이것으로 바꿨다.

## 추천안으로 정한 것 (검토 필요)

- **불량은 재고가 되지 않는다**(기록만). 불량 재고·반품 처리는 MVP 이후.
- **검수 수정은 없고 지우고 다시 등록**한다(확정 전까지).
- 검수 화면에 품목을 고르면 화주사가 ASN에 적은 로트·유통기한을 기본값으로 채운다.
- 예정보다 많이 검수해도 막지 않는다(초과 입고 허용, 0003). 확정 때 초과를 안내한다.
