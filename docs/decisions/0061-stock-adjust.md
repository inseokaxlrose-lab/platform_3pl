# 0061. 재고 실사 차이 · 재고 조정

## 표 (마이그레이션 `20261116140000_stock_adjust`)

- `tb_stock_adjust`: 번호(`AJ261116-00001`), 유형(`COUNT` 실사 / `ADJUST` 조정), 센터, 상태(`DRAFT` 등록 / `CONFIRMED` 확정 / `CANCELED` 취소), **사유(필수)**, 비고, 등록·확정·취소 일시·사람.
- `tb_stock_adjust_line`: 재고 줄, 등록 때 재고(참고), 실사는 센 수량(0 이상) / 조정은 바꿀 수량(±, 0 아님), 확정 때 실제로 바꾼 수량·재고 이력.
- DB 검사: 사유 공백 금지, 확정·취소면 그 사람·일시, 줄은 센 수량과 바꿀 수량 중 하나만.

## 규칙 (`src/lib/stock/adjusts.ts`)

- **등록**(작업자, `stock.adjustments.create`): 재고는 그대로. 재고 줄은 그 센터의 것, 기본단위 소수 자리, 같은 재고 두 번 금지.
- **확정**(관리자, `stock.adjustments.confirm`): 등록 상태일 때만(조건부로 바꿔 두 번 확정 금지). 줄마다 재고 줄을 잠그고
  - 실사: 바뀔 수량 = 센 수량 − **확정할 때** 재고 (등록 뒤 재고가 바뀌어도 맞게)
  - 조정: 적은 수량
  - 0이 아니면 `adjustStock`(사유 = "실사/조정 번호: 사유", 원본 `ADJUSTMENT` + 번호). 하나라도 실패(부족 등)하면 전부 취소되고 등록 상태 그대로.
- **취소**: 등록 상태만(등록 권한).
- 데이터 범위: 센터(`ADJUST_SCOPE`), 화주사 사용자는 쓸 수 없다.

## 화면

- `/admin/stock/adjustments`: 목록(번호·유형·상태·센터·사유·줄 수·등록/확정).
- `/admin/stock/adjustments/new`: 유형·센터·사유·비고 + 줄(재고 줄 검색 선택 + 수량, 실사는 지금 재고와의 차이 표시).
- `/admin/stock/adjustments/[id]`: 줄별 등록 때 재고·지금 재고·센 수량·바뀔(바뀐) 수량, [확정]·[취소].

## 추천안으로 정한 것 (검토 필요)

- 실사와 조정을 **한 문서(유형으로 구분)·한 메뉴**로.
- 2단계(등록 → 확정): 권한 정의를 따랐다. 바로 반영하려면 같은 사람에게 두 권한을 준다.
- **재고 줄이 없는 곳(새 로케이션·새 로트)에 늘리는 조정은 MVP에서 없다** — 이미 있는 재고 줄(수량 0 포함)만 고른다. 필요하면 다음 단계에서 "주소 직접 입력"을 더한다.
- 실사 차이는 확정 때 재고 기준(등록 때 재고는 참고로만 보여 줌).
