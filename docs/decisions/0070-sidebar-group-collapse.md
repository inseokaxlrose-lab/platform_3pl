# 0070. 사이드바 대메뉴 접기·펴기

- 날짜: 2026-11-16
- 상태: 채택 (사용자 요청)
- 관련: 0022 (사이드바·즐겨찾기), 0069 (메뉴 탭)

## 정한 것

| 상황 | 동작 |
| --- | --- |
| 대메뉴 제목(기준정보·입고·재고·시스템 등) 클릭 | 그 묶음을 접고 편다. 오른쪽 ▸(접힘) / ▾(펼침) |
| 기억 | 쿠키 `sidebar_closed_groups`(묶음 이름을 `\|`로 이어 붙임, 1년) → 서버가 처음부터 같은 모양으로 그린다 (사이드바 탭 기억과 같은 방식) |
| 지금 보는 메뉴가 접힌 묶음 안 | 묶음 제목 옆에 ● (메뉴 탭의 선택 색과 같은 브랜드 색) |
| 메뉴 검색 중 | 접기 없이 모두 펼쳐 보인다 (찾은 메뉴가 가려지지 않게) |
| 즐겨찾기 탭 | 같은 접힌 상태를 쓴다 |
| 사이드바를 아이콘만 보이게 접었을 때 | 묶음 접기와 상관없이 아이콘을 모두 보인다 (`group-data-[collapsible=icon]:flex!`) |

- 기본은 모두 펼침. 묶음 이름으로 기억하므로 영역(운영사·포털·플랫폼)이 달라도 이름이 같으면 같이 접힌다 (지금은 겹치는 이름이 "재고" 정도라 문제 삼지 않는다).
- 접근성: 제목은 버튼(`aria-expanded`, `aria-controls`), 접힌 목록은 `hidden`.

## 구현

- `sidebar-tab.ts`: 쿠키 이름 + `parseClosedGroups`·`formatClosedGroups` (서버도 읽으므로 `'use client'` 없는 파일)
- `sidebar-nav-list.tsx`: `collapse` 속성이 있으면 제목을 접기 버튼으로
- `app-sidebar.tsx`: 접힌 묶음 상태·쿠키 쓰기, `app-shell.tsx`: 쿠키 읽기
