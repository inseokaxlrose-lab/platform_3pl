# 0042. 단위 환산 공통 함수 — BigInt 고정 소수점

- 날짜: 2026-11-15
- 상태: 채택
- 관련: 0003 결정 3(단위와 환산)·6(라벨 수량), 0034 (단위), 0041 (품목), CLAUDE.md "재고는 기본단위로 저장"
- 코드: `src/lib/units/convert.ts` (화면·서버 공용 순수 함수), 테스트 `convert.test.ts`

## 배경

재고는 기본단위로 저장하고 환산은 공통 함수에서만 한다(CLAUDE.md). 자바스크립트 숫자는 `0.1 + 0.2 = 0.30000000000000004`처럼 오차가 있어 재고 수량 계산에 쓸 수 없다. 입수량은 DB에 DECIMAL(18,3)로 있다.

## 결정 (사용자 결정: 추천안)

- **BigInt 고정 소수점**: 수량 × 1,000,000을 정수로 바꿔 계산한다(소수 6자리까지 정확). 새 라이브러리(decimal.js 등) 없이 화면·서버 어디서나 돈다. 기본단위 소수 최대 3자리 × 입수량 소수 최대 3자리 = 6자리.
- 수량은 **글자로 주고받는다**(`'2.5'`). DB Decimal의 `toString()`과 바로 맞물리고, 결과도 끝의 0을 뺀 글자.
- 6자리를 넘는 결과는 반올림하지 않고 거부한다(조용히 틀리는 것보다 낫다).

## 함수

| 함수 | 하는 일 |
| --- | --- |
| `toBaseQty(수량, 입수량)` | 환산단위 → 기본단위 (BOX 3, 24 → 72) |
| `splitBaseQty(기본수량, 입수량)` | 묶음 수 + 나머지 (3,000, 1,440 → 2 + 120) |
| `breakdownQty(기본수량, 환산단위들, 기본단위)` | 큰 단위부터 나눠 보여 주기, 0인 단위 생략 |
| `labelQuantities(수량, 라벨 입수량)` | 라벨 장마다 수량 (3,000, 1,440 → 1,440 / 1,440 / 120), 최대 1,000장 |
| `checkQtyDecimals(수량, 자리수)` | 기본단위 소수 자리 검사 (끝의 0은 세지 않음) |
| `formatQty(수량)` | 화면 표시 (천 단위 쉼표, 끝의 0 제거) |
| `parseQty` · `qtyText` | 글자 ↔ 고정 소수점 정수 (음수 허용 — 재고 조정용) |

- 품목 목록의 환산단위 표시·수정 화면 불러오기·저장 때 소수 자리 검사를 이 함수로 바꿨다(이전에는 `Number`로 변환).

## 검증

- 테스트 14개: 글자↔정수 왕복·잘못된 값·소수 오차 없음, 정수·소수 단위 환산, 나머지, 큰 단위부터 나누기, 결정 기록의 라벨 예(3,000 EA → 3장), 장수 제한, 소수 자리 검사, 표시 형식. 품목 테스트는 그대로 통과.
