# 0028. 창고별 로케이션 관리

- 날짜: 2026-11-13
- 상태: 채택
- 관련: 0026 (센터·창고 기본 구조, 입고대기 창고), 0027 (창고), 0025 (코드 체계: 로케이션은 시스템 코드 없음)
- 화면: `/admin/master/locations` (목록, `?warehouseId=`), `/bulk` (일괄 생성, `?warehouseId=`)
- 코드: `src/lib/locations/`, `src/app/admin/master/locations/`

## 결정

### 항목과 코드 규칙

- 창고(등록 후 변경 불가), 로케이션 코드(같은 창고 안 중복 금지, 영문 대문자·숫자·하이픈 1~30자), 구역·열·단(일괄 생성 시 함께 저장: 거르기·정렬용), 사용 여부.
- **코드는 등록 후 바꿀 수 없다** (사용자 결정): 나중에 재고·적치 기록이 이 주소를 가리킨다. 잘못 만들면 삭제하거나 사용 중지한다. 그래서 수정 화면이 없고, 상태 변경은 목록에서 한다.
- 0을 채운 코드라 글자 순서 = 위치 순서 → 기본 정렬은 센터 → 창고 → 코드.

### 일괄 생성 (핵심)

- 구역(영문 한 글자 범위) × 열(숫자 범위, 자릿수) × 단(숫자 범위, 자릿수) + 구분자(하이픈 / 없음) → `A-01-02`.
- 규칙은 순수 함수(`location-range.ts`)로, 화면 미리보기와 서버가 같이 쓴다. 끝 < 시작, 자릿수 초과, 2,000개 초과(실제 개수 안내)를 거부한다.
- **미리보기(만들지 않음) → 생성** 두 단계. 화면은 현재 입력으로 미리보기를 한 뒤에만 [생성]을 켠다(범위를 바꾸면 다시 꺼짐) — 확인하지 않은 범위로 만드는 실수 방지.
- 이미 있는 코드는 건너뛴다(`skipDuplicates` 포함). 같은 범위를 다시 실행해도 안전하다.

### 삭제와 사용 중지 (사용자 결정)

- **한 번도 쓰이지 않은 로케이션만 삭제**한다 (일괄 생성 실수 정리용). 쓰인 적 있으면 사용 중지만.
- "쓰인 적 있음" 검사 `findUsedLocationIds`는 지금 재고 표가 없어 **빈 목록을 돌려주는 자리**다. → **재고 작업(M4 재고 기반) 때 반드시 채운다** (ROADMAP에 기록).
- 목록에서 여러 개를 골라 사용 중지 / 다시 사용 / 삭제. 고른 것 중 하나라도 범위 밖이면 전체를 거부한다.

### 입고대기 창고 보호

- 입고대기 창고에는 로케이션을 추가할 수 없다 (기본 `DEFAULT` 하나만). 사용 중지된 창고에도 추가할 수 없다.
- 입고대기 창고의 `DEFAULT`는 사용 중지·삭제할 수 없다 (섞여 있으면 전체 거부). 목록에 "입고대기 기본"으로 표시한다.

### 권한·데이터 범위

- `master.locations.read / create / update(사용 중지) / delete`
- 센터 직원은 소속 센터 창고의 로케이션만 (`scopeFilter(scope, { center: 'warehouse.centerId' })`). 창고 고르기에도 범위 안 창고만.

### 화면

- 목록: 센터 → 창고 → 구역 고르기(구역은 창고를 골랐을 때), [한 칸 추가] 팝업, [일괄 생성], 행 선택 일괄 처리.
- 일괄 생성: 왼쪽 단만. 입력 중에도 예시 코드와 대략의 개수를 보여준다.
- 창고 상세 오른쪽 로케이션 요약: [로케이션 관리](그 창고를 고른 목록), [일괄 생성](일반·사용 중 창고만).

## 함께 고친 것

- 그리드 설정 보관함(`GridSettingsProvider`)을 `@/components/data-grid` 묶음에서 뺐다. 묶음에서 숫자 표시 함수만 가져와도 서버 액션 → DB 연결까지 끌려와 부품 테스트가 실패했다. AppShell만 직접 가져온다.

## 확인

- 테스트: 일괄 생성 규칙 5개, 서버 액션 10개, 일괄 생성 화면 4개.
- 브라우저(admin):
  - 창고 상세의 [일괄 생성]으로 들어가자 창고가 미리 골라져 있었다.
  - `A~B / 1~10 / 1~5` 미리보기는 100개(`A-01-01 … B-10-05`), 생성도 100개였다. 같은 범위를 다시 미리보기하자 0개(100개 건너뜀)로 나오고 [생성]이 꺼졌다.
  - 목록에서 B구역만 걸러 20개를 골라 사용 중지하자 그 20개만 바뀌었고, 선택이 해제되며 목록이 새로 고쳐졌다.
- 확인용 창고·로케이션은 지웠다.
