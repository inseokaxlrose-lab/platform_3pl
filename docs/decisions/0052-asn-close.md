# 0052. ASN 잔량 마감

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0003 결정 5 (잔량 마감), 0047 (ASN 모델), 0051 (진행 계산)

## 규칙

- 권한 `inbound.asn.close` (운영사 화면만, 포털에는 없음), 사유 필수(200자), 동시 수정은 `rowVersion`.
- 마감할 수 있는 상태: **예정·검수중·부분확정**. 확정완료·마감은 거부, 잔량이 하나도 없으면 거부.
- 마감하면: 상태 `CLOSED`, 사유·마감자(`closed_by` = 작업자 아이디)·일시. 줄마다 그때의 잔량(예정 − 누적 확정, 0 이상)을 `closed_qty`로 남긴다 → 진행 현황의 잔량은 0, "마감" 칸에 수량(보고서용).
- 마감 후 검수·확정 금지는 검수·입고 확정 작업에서 상태를 보고 막는다. 적치는 계속 가능.
- 화면: ASN 화면 상태 영역의 [잔량 마감] (사유 입력 확인 창, `ConfirmDialog`의 `reason`).

## 추천안으로 정한 것 (검토 필요)

- **예정 상태도 마감 가능**: 아무것도 받지 않은 ASN을 지우지 않고 기록으로 남기고 싶을 때(지우기는 예정 상태에서 따로 가능).
- **마감 되돌리기는 두지 않음**: 필요하면 새 ASN을 등록한다.
