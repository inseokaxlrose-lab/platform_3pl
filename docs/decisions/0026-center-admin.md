# 0026. 센터 관리와 창고·로케이션 기본 구조

- 날짜: 2026-11-13
- 상태: 채택
- 관련: 0003 (위치 계층), 0016 (데이터 범위), 0025 (코드 체계), 0002 (입력 화면 배치)
- 화면: `/admin/master/centers` (목록), `/new` (등록), `/[id]` (수정)
- 코드: `src/lib/centers/`, `src/lib/master-code/`, `src/app/admin/master/centers/`

## 결정

### 센터 항목

| 묶음 | 항목 |
|---|---|
| 기본 정보 | 시스템 코드(자동 `CT000001`, 불변), 센터 코드(사용자 코드, 비우면 시스템 코드), 센터명\* |
| 연락처 | 대표 전화·팩스, 센터장·센터장 연락처 |
| 주소 | 카카오 주소 검색 공통 부품 |
| 외부 코드 | SAP·ERP (`ExternalCode` 매핑) |
| 상태 | 사용 / 사용 중지 (삭제 없음) |

- 센터 코드: 영문·숫자·하이픈·밑줄 2~20자, 대문자로 저장, 전체에서 중복 금지.
- **시스템 코드 모양(`CT` + 6자리)은 사용자 코드로 쓸 수 없다**(자기 시스템 코드 제외). 코드를 비워 등록한 센터가 시스템 코드를 사용자 코드로 받을 때 겹치지 않게 하기 위해서다.
- 기존 센터(이천·김해)는 마이그레이션에서 등록 순서대로 시스템 코드를 채웠다. 필수 칸을 바로 추가할 수 없어 "빈 칸 추가 → 채우기 → 필수로"를 SQL로 직접 썼다 (`prisma migrate diff`로 뽑은 SQL에 추가).

- **주의 (나중에 발견해 고침):** 마이그레이션 폴더를 직접 만들 때 이름의 시각을 한국 시각(`date`)으로 붙였더니, Prisma가 만드는 폴더(UTC 시각)보다 뒤로 정렬돼 **빈 DB에서 순서가 뒤집히는 문제**가 생겼다. 폴더 이름을 UTC 시각으로 바꾸고, 이미 적용된 DB의 기록 이름(`_prisma_migrations.migration_name`)도 맞췄다. 빈 DB로 처음부터 적용해 확인했다. → 직접 만들 때는 **`date -u +%Y%m%d%H%M%S`**를 쓴다.

### 창고·로케이션 기본 구조 (관리 화면은 다음 작업)

- `Warehouse`: 센터 소속, 시스템 코드 `WH000001`, 사용자 코드(같은 센터 안 중복 금지), 이름, 유형(일반 / 입고대기), 사용 여부.
- `Location`: 창고 소속, 코드(같은 창고 안 중복 금지, 시스템 코드 없음 — 코드 자체가 위치), 사용 여부.
- **센터 등록 = 센터 + 입고대기 창고(`INBOUND`) + 기본 로케이션(`DEFAULT`) + 외부 코드를 한 트랜잭션으로.** 외부 코드가 겹쳐 실패하면 센터·창고도 남지 않는다.
- **센터마다 입고대기 창고는 1개**: 부분 고유 인덱스 `warehouse_one_inbound_staging_per_center`로 DB가 강제한다.
- `ensureCenterDefaults`는 여러 번 불러도 안전하다 → 시드가 예시 센터에도 같은 함수로 채운다.
- 창고가 있는 센터, 로케이션이 있는 창고는 지울 수 없다(`Restrict`, 이력 보호).

### 권한·데이터 범위

- 메뉴 권한 `master.centers.read/create/update`를 화면과 서버에서 검사한다.
- 데이터 범위: 센터 직원은 **소속 센터만** 목록에 보이고 열 수 있다. 다른 센터 주소를 직접 열면 "찾을 수 없음"이다(존재 여부도 알리지 않음). 수정 요청은 `assertInScope`로 다시 막는다.
- **등록·사용 중지는 운영사(전체 범위)만** 할 수 있다. 권한 코드가 있어도 센터 직원은 안 된다. 센터 직원이 새 센터를 만들면 자기가 볼 수 없는 센터가 생기고, 자기 센터를 사용 중지하면 스스로 잠기기 때문이다.

### 함께 만든 공통 장치

  - 다른 센터의 코드(`ICN`)와 시스템 코드 모양(`CT000009`)은 이유와 함께 거부됐다.
- `center.manager`(이천 소속, 조회만): 이천 상세는 읽기 전용(입력 잠김, 저장 버튼 없음), 김해 상세는 404, [센터 등록] 버튼 없음.
