# 0095. 배송 코스·우편번호 코스 배정·납품처 납품 조건 (M8 B2)

- 날짜: 2026-11-20
- 상태: 채택
- 관련: 0076 (권역설정 — 우편번호 → 센터), 0082 (납품처), 0094 (운송사), 0030 (공통코드), 기준정보 누락 검토 1-7·2-7
- 코드: `src/lib/routes/` (입력 규칙·코스·우편번호 배정·코스 정하기·붙여넣기 해석), `src/app/admin/master/routes/`, 납품처 저장 `src/lib/customers/customers.ts`, 입력창 `ship-to-sheet.tsx`
- 마이그레이션: `20261120160000_routes`

## 배경

권역설정은 "어느 센터가 보낼지"까지만 정한다. 센터 안에서 "어느 차·어느 길로 보낼지"(수송 분류, 1순위 목적)와 납품처의 납품 조건(시간·요일·차량·하차)을 둘 곳이 없었다.

## 결정

### 배송 코스 `tb_route`

- 센터별. 우리 코드(필수·불변, 센터 안 고유) + 사용자 정의 코드(센터 안 고유) + 외부코드(대상 `ROUTE`).
- 수송 수단은 **운송사 FK** (사용자 결정 — 0094의 택배·화물·자차·용차를 다시 만들지 않는다).
- 운행 요일(월~일 7글자 Y/N, 하나 이상)·출발 마감 시각·기본 차량 톤수(공통코드 `VEHICLE_TON`)·도착 거점·정렬·상태.
- 메뉴 기준정보 › **배송 코스**, 권한 `master.routes`(+엑셀). 센터 직원은 소속 센터 코스만. 기본 권한그룹: 센터 운영자도 전체.
- 지우기: 납품처가 직접 지정한 코스는 거부. 우편번호 배정은 함께 지운다(되살려도 돌아오지 않음 — 그 사이 다른 코스로 배정됐을 수 있으므로).

### 우편번호 코스 배정 `tb_route_zip` (사용자 결정: 2차로 미루지 않고 지금)

- (센터, 우편번호)당 코스 하나 — DB 고유 인덱스. 권역설정(운영사·우편번호·온도대)과 달리 **온도대는 나누지 않는다**(코스가 이미 센터 안이고, 온도대별 코스는 코스를 따로 만들면 된다).
- 넣는 방법: 붙여넣기(쉼표·줄바꿈, `16300-16399` 범위 — 한 번에 1,000개) 또는 지역(시도 → 시군구 → 읍면동, 권역설정의 지역 트리 재사용). 읍면동이면 경계 우편번호 제외(권역설정과 같은 규칙).
- "권역설정에서 이 센터로 배정된 우편번호만"(기본 켜짐). 끄면 다른 센터 권역도 넣을 수 있지만 미리보기·목록에서 알린다.
- 같은 센터의 다른 코스에 있던 우편번호는 **옮긴다** — 미리보기에서 코스별 건수를 보여 주고, 저장 때 같은 계산을 다시 한다.
- 지역 마스터에 없거나 폐지된 우편번호는 넣지 않는다. 한 번에 5,000개까지.
- 이력 표는 두지 않는다(배정자·일시만). 권역설정처럼 날짜 기준 조회가 필요해지면 그때 추가한다.

### 납품처의 코스 정하기 `resolveShipToRoutes`

1. 납품처에 직접 지정한 코스 (`tb_ship_to.route_id`) — 배송센터의 사용 중인 코스일 때만
2. 배송센터 + 정제 우편번호의 코스 배정 — 사용 중인 코스만
3. 없으면 코스 없음

- **코스는 저장하지 않고 그때그때 정한다.** 배송센터는 화면·엑셀·API·권역 갱신 등 여러 길로 바뀌므로, 코스를 저장해 두면 그 모든 길에서 다시 맞춰야 한다. 납품처 목록은 한 번에 정한다(쿼리 2번).
- 직접 지정한 코스가 배송센터가 바뀌어 다른 센터의 코스가 되면 무시하고 2번으로 간다.

### 납품처 납품 조건 (`tb_ship_to`)

- 배송 코스(직접 지정)·납품 가능 시간(시작~끝)·납품 요일(비우면 제한 없음)·차량 제한(공통코드 `VEHICLE_LIMIT`)·하차 방법(공통코드 `UNLOAD_METHOD`)·사전 연락 여부.
- 차량 제한·하차 방법·차량 톤수는 화면 표시·분류용이라 **공통코드**(0030). 프로그램이 값으로 동작을 바꾸게 되면(배차 규칙) 그때 상수로 옮긴다.
- 입력 규칙에서 이 칸들은 **보내지 않으면(undefined) 저장된 값을 그대로 둔다** — 엑셀 업로드·연동 API는 아직 이 칸을 보내지 않으므로 화면에서 넣은 값이 지워지지 않게.
- 직접 지정 코스는 저장할 때 최종 배송센터의 사용 중인 코스인지 검사한다.

## 버린 안

- **코스를 납품처에 저장해 두고 배정이 바뀔 때마다 다시 계산**: 배송센터가 바뀌는 모든 길에 고리를 걸어야 해서 빠뜨리기 쉽다.
- **권역설정 화면(트리·표·이력·업로드) 전체를 코스용으로 복제**: 지금 필요한 것은 "코스에 우편번호를 넣고 빼기"라, 코스 수정 화면 안의 섹션 + 추가 창으로 충분하다.

## 남은 일

- 출고·배차에서 코스·납품 조건 사용.
