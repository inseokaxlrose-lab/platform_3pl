# 0096. 휴무관리 — 국가 공휴일 자동 가져오기·운영사/센터 휴무·특근 (M8 B3)

- 날짜: 2026-11-20
- 상태: 채택
- 관련: 0018 (시스템 메뉴는 운영사 사용자만), 0038 (지우지 않고 숨김), 0095 (배송 코스 운행 요일), 기준정보 누락 검토 1-8·3-8
- 코드: `src/lib/holidays/` (값 목록·API·가져오기·입력 규칙·개별 휴일·영업일 판단), `src/app/admin/system/holidays/`
- 마이그레이션: `20261120170000_holidays`

## 배경

출고 예정일·리드타임(D+1)·코스 운행일을 계산하려면 "센터가 그날 일하는가"를 알아야 하는데, 센터에는 운영 요일(`work_days`)만 있었다.

## 결정 (사용자 결정: 시스템관리에 휴무관리 메뉴, 국가 공휴일은 API로 자동, 개별 휴일은 운영사별 — 세부는 모두 추천안)

### 표

- `tb_holiday` 국가 공휴일: **운영사 공통**. 날짜·이름만, (날짜, 이름) 고유(같은 날 두 공휴일이 겹치는 해가 있다). API로만 채운다.
- `tb_holiday_year` 연도별 가져오기 결과: `OK` 가져옴 / `EMPTY` 0건(발표 전) / `FAILED` 실패, 건수·사유·일시.
- `tb_operator_holiday` 운영사 개별 휴일: 센터(NULL = 운영사 전체)·날짜·이름·구분 `CLOSED` 휴무 / `OPEN` 특근·비고. 기준정보 규칙대로 감사 칸·버전·`del_yn`. 같은 범위(운영사 전체 / 같은 센터)에 같은 날짜 한 건 — 부분 고유 인덱스 2개(센터 NULL은 일반 고유 인덱스로 막히지 않으므로).

### 국가 공휴일 가져오기

- 공공데이터포털 「한국천문연구원_특일 정보」 `getRestDeInfo`(`isHoliday=Y`만), 키 `.env` `DATA_GO_KR_SERVICE_KEY`(Encoding·Decoding 키 모두 받는다). 주소 검색 API(0076)처럼 호출부를 약속(`HolidayFetcher`)으로 두고 시험은 가짜를 끼운다.
- **연도 단위로 통째로 바꾼다**(임시공휴일 추가·이름 변경 반영). API를 못 쓰거나 0건이면 기존 자료는 그대로 두고 결과만 남긴다.
- **자동**(사용자 결정 — 예약 실행 장치가 아직 없으므로): 휴무관리 화면을 열 때 올해·내년 중 가져온 적 없는 연도를 가져온다. 발표 전·실패는 하루 뒤 다시 시도. 키가 없으면 자동 가져오기를 건너뛰고 안내만 보인다.
- [공휴일 다시 가져오기]: 작년~내후년 중 연도를 골라 즉시(권한 `system.holidays.update`). 공통 자료라 어느 운영사가 가져와도 결과가 같다.

### 영업일 판단 `dayStatus` / `addBusinessDays`

1. 그 센터를 고른 휴무·특근
2. 운영사 전체 휴무·특근
3. 국가 공휴일 → 쉼
4. 센터 운영 요일

- 질문 때 "특근 → 휴무 → 공휴일 → 운영 요일"로 설명했지만, 같은 날짜는 범위마다 한 건이므로 실제로 겹치는 것은 "운영사 전체 vs 센터"뿐이다. 이때 **좁은 범위(센터)가 이긴다** — 운영사 전체 특근이어도 그 센터가 점검 휴무면 쉰다.
- 순수 함수(`business-calendar.ts`) + DB 읽기(`loadCenterCalendar`). 출고 예정일 계산에서 쓴다.

### 화면·권한

- 시스템 › **휴무관리**, 권한 `system.holidays`(조회·등록·수정·삭제). 국가 공휴일과 개별 휴일을 한 목록(연도·구분·센터·검색어, 삭제됨)으로 보여 준다 — 연도별 수십 건이라 합쳐서 메모리에서 정렬·페이지. 국가 공휴일은 고르거나 고칠 수 없다(쉬지 않으려면 같은 날짜로 특근).
- **시스템 메뉴는 운영사 사용자만**(0018)이라 센터 운영자 기본 권한에는 넣지 않았다. 센터별 휴일도 운영사 관리자가 센터를 골라 등록한다. 저장 함수는 데이터 범위를 검사하므로(센터 직원은 소속 센터만, 운영사 전체 휴일은 운영사 전체 범위만) 나중에 메뉴를 센터에 열어도 안전하다.

## 버린 안

- **국가 공휴일을 운영사마다 복사**: 공통 자료를 운영사 수만큼 갱신해야 한다. 운영사별 예외는 특근으로 충분하다.
- **예약 작업(cron) 경로**: 배포 환경의 예약 설정이 정해지지 않았다(0067). 화면 열 때 자동 + 버튼으로 충분하다.
- **판단 순서를 "특근 항상 먼저"로**: 운영사 전체 특근이 센터 점검 휴무를 덮어쓰게 된다.

## 실제 API 확인 (2026-11-22)

- 키를 넣고 2026~2028년을 받아 봤다. JSON 응답이 `parseHolidayResponse`대로 읽히고, 대체공휴일·선거일·노동절도 들어온다. 화면을 열자 2026년 22일, 2027년 24일이 자동으로 들어왔다.
- **같은 날 이름이 둘**인 경우가 있다(2028-10-03 개천절·추석). 둘 다 저장하고(고유 키가 날짜+이름), 연도 배지의 건수는 **날짜 수**로 센다.
