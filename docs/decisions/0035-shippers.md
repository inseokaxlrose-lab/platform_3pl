# 0035. 화주사 정보 관리

- 날짜: 2026-11-15
- 상태: 채택
- 관련: 0003 (화주사·이용 센터·품목 기본값), 0016 (데이터 범위), 0025 (코드 3층), 0031·0032 (화면 틀)
- 화면: `/admin/master/shippers` · 코드: `src/lib/shippers/`, `src/app/admin/master/shippers/`

## 결정

- `Shipper` 확장: 코드 3층(시스템 코드 `SH`+6자리 — 기존 GANA·DARA는 마이그레이션에서 만든 순서대로 채움), 사업자번호(선택, 검증번호 확인, 숫자만)·대표자·업태/종목·연락처·주소, **품목 기본값**(로트 사용·유통기한 사용·라벨 단위 PLT/BOX, 기본 PLT).
- **이용 센터** `ShipperCenter`(1곳 이상 필수, 사용자 결정). 이미 연결된 센터가 사용 중지돼도 유지할 수 있지만 새로 붙이지는 못한다. 재고가 있는 이용 센터 빼기 금지는 M4에서.
- **담당자** `ShipperContact`: 운영사 담당자와 같은 규칙 — 입력 규칙을 공용 `src/lib/contacts/contact-schema.ts`로 옮겼다. 담당 업무 공통코드 사용처에 화주사 담당자도 등록.
- **데이터 범위**: 센터 직원은 **자기 센터를 이용하는 화주사만 조회**(사용자 결정). `scopeFilter`/`isInScope`에 여러 개와 연결된 관계 경로(`centers.some.centerId`)를 지원하도록 보강. 등록·수정·사용 중지는 운영사(전체 범위)만.
- 권한 `master.shippers`에 엑셀(`export`) 추가.
- 수정 화면에 소속 **포털 사용자** 목록(따로 처리하는 섹션, 사용자 메뉴로 이동).
- 견본: GANA(가나식품, 로트·유통기한 사용, 이천) / DARA(다라전자, 미사용, 이천·김해) — M3 완료 기준 확인용.
