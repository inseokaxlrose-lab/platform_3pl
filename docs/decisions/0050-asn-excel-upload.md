## 양식 (`src/lib/inbound/asn-upload-template.ts`)

한 행 = ASN 라인 하나. **묶음키**가 같은 행들이 ASN 하나가 된다.

| 칸 | 필수 | 설명 |
| --- | --- | --- |
| 묶음키 | ✓ | 같은 값의 줄이 ASN 하나 |
| 화주사코드 | ✓ (운영사 화면만) | 화주 포털은 칸 없음 — 자기 화주사 |
| 센터코드 | ✓ | |
| 입고예정일 | ✓ | YYYY-MM-DD (점·빗금, 엑셀 날짜 칸도 됨) |
| 화주사문서번호 | | |
| 품목코드 | ✓ | 그 화주사의 품목 |
| 단위 | | 비우면 기본단위 |
| 수량 | ✓ | 고른 단위의 수량 |
| 로트번호·유통기한·비고 | | 관리 품목만 로트·유통기한 |

## 검증·등록 (`src/lib/inbound/asn-upload.ts`)

- 검증은 **화면 등록과 같은 규칙**: 라인 검사 함수 `resolveAsnLine`(단위·환산·소수 자리·로트)과 입력 규칙 `asnLineSchema`를 그대로 쓴다. 이를 위해 `asns.ts`의 라인 검사를 한 줄 단위로 나누고, 등록을 트랜잭션 안에서 부를 수 있게 `createAsnInTx`로 나눴다.
- 행마다 문제를 모아 칸 이름과 함께 보여 준다: 묶음 안 헤더 칸 불일치, 없는·사용 중지 화주사/센터, 화주사가 이용하지 않는 센터, 센터 직원의 소속 밖 센터, 다른 화주사 품목, 날짜 형식, 수량·단위·로트 규칙, 필수 칸.
- 등록: 서버가 **다시 검증**하고, 문제가 하나라도 있으면 거부. 없으면 모든 ASN을 **한 트랜잭션**으로 만든다(하나라도 실패하면 전부 취소). 등록 경로 `EXCEL`.
- 권한: 운영사 화면 `inbound.asn.create`, 포털 `portal.asn.create` (업로드 전용 권한은 두지 않음).
- 화면: ASN 등록 화면 머리글의 [엑셀 업로드] (`AsnUploadButton`). 등록이 끝나면 ASN 목록으로 간다.

## 추천안으로 정한 것 (검토 필요)

- **묶음키 방식**: 한 파일에 여러 ASN을 넣을 수 있게 행마다 묶음키를 둔다(헤더·라인 두 시트보다 엑셀에서 다루기 쉬움). 헤더 칸은 같은 묶음의 모든 줄에 반복해 적는다.
- **코드는 대소문자 구분 없이** 찾는다(품목·화주사·센터).
- 업로드 전용 권한 없이 등록 권한을 그대로 쓴다.

## 함께 고친 것

- 엑셀 업로드 대화상자: 미리보기 표가 넓으면 대화상자 전체가 옆으로 밀려 [닫기]·[등록] 버튼이 화면 밖으로 나가던 문제 → 표 안에서만 가로 스크롤.
