# 0049. 엑셀 업로드 공통 컴포넌트

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0003 "엑셀 업로드 공통 규칙", 0002 (DataGrid), 0042 (수량은 글자)

## 흐름

1. [양식 내려받기]: `입력` 시트(제목 줄만, 필수는 `*`, 모든 칸 글자 서식 — 코드 앞의 0 보존) + `안내` 시트(칸별 필수·예시·설명)
2. [파일 고르기] → **화면에서 파일을 읽어**(exceljs, 쓸 때만 불러옴) 행 목록으로 바꾼다 → **서버 검증**(저장 안 함) → 미리보기(행 번호·결과·오류 사유·칸들, "오류 행만 보기")
3. 오류가 하나도 없을 때만 [N행 등록] → 서버가 **다시 검증**하고, 하나라도 오류면 아무것도 저장하지 않는다

## 추천안으로 정한 것 (검토 필요)

- **파일은 화면에서 읽고, 서버에는 행(글자)만 보낸다**: 서버에 파일을 올리지 않아 파일 보관·바이러스 검사 같은 일이 없다. 대신 서버는 받은 글자를 처음부터 다시 검증한다(화면을 믿지 않음).
- **칸은 제목 글자로 찾는다**: 순서가 바뀌어도, 제목에 `*`·공백이 있어도 된다. 필수 칸 제목이 없으면 파일 전체를 거부.
- **한도**: 한 번에 1,000행, 파일 5MB. 넘으면 나눠 올리게 안내.
- **숫자·날짜 칸**: 엑셀 숫자는 그대로 글자로(예: 2.5 → '2.5'), 날짜 칸은 'YYYY-MM-DD'. 양식은 모든 칸을 글자 서식으로 만들어 이런 바뀜을 줄인다.
- **미리보기 표는 공통 DataGrid**(화면 안에서 나눠 보여 주기), 오류가 있으면 처음부터 "오류 행만 보기".
- 업로드 기록(누가 어떤 파일을 올렸는지) 표는 두지 않는다 — 각 업무 데이터에 등록 경로(예: ASN `EXCEL`)·등록자가 남는다.
