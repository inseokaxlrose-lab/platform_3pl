# 0048. ASN 화면 등록 (화주 포털 + 센터 대리)

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0047 (ASN 모델), 0041 (품목), 0042 (단위 환산), 0031 (입력 화면 틀)

## 만든 것

| 화면 | 주소 | 권한 | 등록 경로 |
| --- | --- | --- | --- |
| ASN 등록 (운영사) | `/admin/inbound/asn/new` | `inbound.asn.create` | `PROXY` 센터 대리 |
| ASN 보기·수정 (운영사) | `/admin/inbound/asn/[id]` | `inbound.asn.read`·`update`·`delete` | |
| ASN 등록 (포털) | `/portal/asn/new` | `portal.asn.create` | `PORTAL` 화주 포털 |
| ASN 보기·수정 (포털) | `/portal/asn/[id]` | `portal.asn.read`·`update`·`delete` | |

- 화면은 하나(`src/components/inbound/asn-form.tsx`)를 운영사 화면·포털이 같이 쓴다. 포털은 화주사가 자기 화주사로 고정, 서버도 범위의 화주사로 정한다(화면 값은 쓰지 않음).
- 업무 함수 `src/lib/inbound/asns.ts`: `createAsn`·`updateAsn`·`deleteAsns` — 엑셀 업로드(다음 작업)도 같은 함수를 쓴다(경로 `EXCEL`).
- 데이터 범위: `ASN_SCOPE` = 센터 `centerId`, 화주사 `shipperId`. 센터 직원은 소속 센터의 ASN만, 화주사 사용자는 자기 화주사만.

## 규칙

- 화주사: 사용 중이고 범위 안. 센터: 사용 중이고, 화주사가 이용하는 센터이고, 센터 직원이면 소속 센터.
- 품목: 그 화주사의 사용 중인 품목. 단위: 기본단위 또는 품목의 환산단위.
- 수량: 입력 단위의 소수 자리 검사 → `toBaseQty`로 기본단위 예정 수량 → 기본단위 소수 자리 검사(EA 정수인데 BOX 0.3 × 24 = 7.2면 거부). 입력 단위·수량은 표시용으로 함께 저장.
- 로트·유통기한: 관리하지 않는 품목은 적으면 거부, 관리 품목은 **선택**(실제 값은 검수에서).
- 수정·삭제: 예정(PLANNED) 상태에서만. 수정은 라인을 통째로 바꾼다. 동시 수정은 `rowVersion`.
- 오류 문구에 "N번째 줄"을 붙여 어느 줄인지 알 수 있게.

## 추천안으로 정한 것 (검토 필요)

- **화면 하나로 보기·수정**: 상세 화면이 곧 수정 화면(예정 상태), 검수 후에는 읽기 전용. 진행 현황(누적 확정·적치·잔량)은 ASN 조회 작업에서 목록·상세에 보인다.
- **품목 고르기 = 검색 선택(`SearchSelect`)**: 품목이 많을 수 있어 검색해서 고른다(코드·이름·바코드, 100건까지 보여 주고 검색으로 좁힘). 공통 입력 부품으로 추가했다.
- **수량 입력 = `QtyInput`**: 글자 그대로 다루는 수량 입력 부품을 새로 만들었다(`NumberInput`은 Number라 수량에 쓰지 않는다, 0042).
- **기본 예정일 = 오늘**, 화주사가 이용하는 센터가 하나면 자동 선택.
- **화주사를 바꾸면 품목 줄을 비운다** (다른 화주사의 품목이 남지 않게).
