# 0034. 단위 코드 관리

- 날짜: 2026-11-15
- 상태: 채택
- 관련: 0003 결정 3 (단위와 환산), 0025 (코드 체계: 단위는 시스템 코드 없음·외부 코드 있음), 0030 (공통코드), 0032 (목록 틀)
- 화면: `/admin/master/units` (목록 + 등록·수정 팝업)
- 코드: `src/lib/units/`, `src/app/admin/master/units/`, `prisma/seed-units.ts`

## 결정

- **공통코드가 아닌 별도 `Unit` 표** (사용자 결정): 프로그램이 단위의 **종류**(기본/환산)와 **소수 자리수**를 보고 수량 입력·검사·환산을 다르게 한다 (0030 "동작을 바꾸는 값은 공통코드에 두지 않는다"). 또 SAP·ERP 단위 코드와 매핑해야 한다 (`ExternalCode(UNIT)`).
- 칸: 코드(전체 고유, 대문자, **등록 후 변경 불가** — 품목·재고에 글자가 저장된다), 이름, 종류(`BASE` 기본단위 / `PACK` 환산단위), 소수 자리수(기본단위만, 0~6. 환산단위는 0으로 맞춤), 정렬 순서, 사용 여부, 시스템 단위.
- 0025대로 **시스템 코드 없이** 표준 코드(EA·KG·BOX…)를 그대로 쓴다. 데이터 범위 없음(운영사 전체 공통).
- **시스템 단위 EA·BOX·PLT**: 기본 단위와 라벨 단위(0003 결정 7)라 삭제·사용 중지·종류 변경 불가. 이름·순서·외부 코드는 고칠 수 있다.
- **기본 단위 시드** (운영에서도 생성, 없으면 만들기만): 기본단위 EA(0)·SET(0)·KG(3)·G(0)·L(3)·ML(0)·M(2), 환산단위 BOX·CARTON·PLT·PACK.
- 삭제는 품목에서 쓰지 않는 단위만 — 사용 검사(`findUsedUnitIds`)는 **품목 작업 때 채운다** (ROADMAP).
- 입수량(1 BOX = 24 EA)은 단위가 아니라 **품목**에서 정한다 (다음 작업). 환산 계산은 "단위 환산 공통 함수" 작업에서.

## 화면

- 칸이 적고 건수가 수십 개라 **목록 + 팝업**으로 등록·수정한다 (사용자 결정 — 입력 화면 틀(0031)의 예외, 공통코드 화면과 같은 방식). 이를 위해 `MasterListPage`에 `onRowClick`(주소 이동 대신 화면 안 처리)을 더했다.
- 목록: 검색어·종류·상태, 기본 정렬 기본단위 → 환산단위 → 정렬 순서. SAP·ERP 코드는 숨김 컬럼. 일괄 사용 중지·다시 사용·삭제(시스템 단위가 섞이면 전체 거부). 건수가 적어 엑셀은 두지 않았다.
