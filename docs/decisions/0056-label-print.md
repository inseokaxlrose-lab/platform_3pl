## 화면

- `/admin/inbound/labels`: 라벨을 뽑을 ASN 고르기(상태를 고르지 않으면 검수중·부분확정·확정완료). 입고 검수 화면의 [라벨 인쇄]로도 온다.
- `/admin/inbound/labels/[asnId]`: 검수 기록 고르기(여러 개) → PLT·BOX 양식과 코드 종류 고르기 → [미리보기](처음이면 라벨을 만든다, 실제 크기) → [N장 인쇄](브라우저 인쇄 → 윈도우 프린터 드라이버).
- 권한: 화면 `inbound.labels.read`, 미리보기·인쇄 `inbound.labels.print`. 데이터 범위는 ASN 범위.
- **재발행**: 같은 라벨을 다시 인쇄하면 번호는 그대로, 인쇄 횟수만 +1 (미리보기에 "인쇄 N회 (재발행)").
- **여러 양식 한 번에**: 인쇄 CSS에 양식마다 이름 붙인 용지(`@page PLT_A { size … }`)를 두고 라벨마다 자기 용지를 쓰게 해서, PLT·BOX를 한 번에 인쇄해도 장마다 크기가 맞다(1장 = 1페이지, 여백 0).

## 사용자별 기억 — 개인 설정 표 `tb_user_pref` (마이그레이션 `20261116120000_user_pref`)

- (사용자, 키) → JSON 값. 키와 값 규칙은 코드에만 정한다(`src/lib/prefs/pref-schemas.ts`). 저장은 로그인만 필요한 `saveUserPrefAction`(본인 것만), 읽기는 `getUserPref`(깨졌으면 기본값).
- 지금 키: `label-print` = 단위별 마지막 양식 + 코드 종류(기본 PLT_A·BOX_A·QR).

## 추천안으로 정한 것 (검토 필요)

- **인쇄 기록 시점**: 인쇄 창을 연 뒤 기록한다 — 브라우저는 인쇄를 취소했는지 알려 주지 않아, 취소해도 1회로 센다.
- 사용자별 기억은 브라우저 저장소가 아니라 **서버**(다른 PC에서도 같게).
- 라벨 미리보기는 실제 크기(mm). 프린터 배율은 100%로 하라고 화면·도움말에 안내.
