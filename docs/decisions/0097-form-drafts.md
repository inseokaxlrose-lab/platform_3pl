# 0097. 작성 중 내용 임시 보관 — 다른 메뉴 탭에 다녀와도 이어서 작성

- 날짜: 2026-11-22
- 상태: 채택 (사용자 결정: 임시 보관 방식, 브라우저 창 단위, 다른 탭으로 갈 때 묻지 않고 보관 — 모두 추천안)
- 관련: 0031 (입력 화면·변경 감지), 0038 (동시 수정 막기 row_version), 0069 (상단 메뉴 탭 — 책갈피 방식)
- 코드: `src/lib/navigation/form-drafts.ts`, `src/components/master-form/use-master-form.ts`·`use-dirty-guard.ts`·`master-form-page.tsx`, `src/components/app-shell/menu-tabs.tsx`

## 배경

사용 중 불편: "수정하던 화면에서 다른 탭으로 이동할 수 없다. 이동했다가 돌아와서 이어서 작업하고 싶다."
메뉴 탭은 책갈피 방식(0069)이라 탭을 옮기면 화면이 사라지고 입력값도 사라진다. 그래서 저장하지 않은 변경이 있으면 확인 창으로 이동을 막았다.

## 결정

입력 화면(`useMasterForm` + `MasterFormPage`, 18곳)의 **작성 중 내용을 브라우저 창 저장소에 보관**하고, 돌아오면 다시 채운다.

| 하는 일 | 동작 |
| --- | --- |
| 입력값이 처음 값과 달라짐 | 그때마다 `sessionStorage`의 `form-draft:{화면 경로}`에 값·작성을 시작한 버전을 보관. 처음 값과 같아지거나 저장·[취소]하면 지운다 |
| 다른 **메뉴**로 가는 링크 (메뉴 탭·사이드바·홈) | 묻지 않고 이동. 떠난 탭에 ● |
| 같은 메뉴 안의 이동 (수정 → 목록, 이 메뉴의 다른 항목) | 지금처럼 확인 창. [나가기]면 보관한 것도 버린다 |
| 돌아옴 (탭·같은 주소) | 보관한 값을 채우고 위쪽 안내 "저장하지 않은 작성 내용을 불러왔습니다 · [처음 값으로 되돌리기]" |
| 그 사이 다른 사람이 같은 자료를 저장함 (버전이 다름) | 주의 색 안내. 저장은 작성을 시작한 버전으로 보내므로 기존 동시 수정 검사(0038)로 막힌다 — 남의 변경을 덮어쓰지 않는다 |
| ● 탭 [×] · [전체 닫기] | "저장하지 않은 작성 내용이 있습니다 … [버리고 닫기]"를 물은 뒤 보관도 지운다 |
| 로그아웃 · 로그인 화면 | 이 창의 보관을 모두 지운다 (같은 창에서 다른 사람이 로그인해도 남의 작성 내용이 보이지 않게) |
| 새로고침 | 보관이 남아 이어서 채운다 (브라우저 확인 창은 그대로) |
| 창 닫기 | 보관도 사라진다 (브라우저 확인 창은 그대로) |

- "다른 메뉴인가"는 메뉴 탭이 등록한 주소 → 메뉴 함수(`setMenuResolver`, `findActiveHref`)로 판단한다. 메뉴가 아닌 화면(비밀번호 변경 등)에서는 지금처럼 묻는다.
- 저장소를 쓸 수 없는 브라우저(보관 실패)에서는 예전처럼 다른 메뉴로 갈 때도 묻는다.
- 보관한 값은 화면이 처음 그려질 때(서버 화면과 맞춘 뒤) 한 번 읽는다. 메뉴 탭으로 돌아오는 이동은 첫 그리기부터 채워져 깜빡이지 않는다.
- 시험 공통 준비(`vitest.component-setup.ts`)가 시험마다 `sessionStorage`를 비운다.

## 대상이 아닌 것

- **팝업**(휴일 등록·단위 등록 등 목록 + 팝업 화면): 입력이 짧아 그대로 둔다. 탭을 옮기면 팝업 입력은 사라진다.
- 입력값 외의 화면 모습(스크롤 위치·펼친 섹션)은 남기지 않는다.

## 버린 안

- **Next 16 `cacheComponents`(React `<Activity>`로 화면을 숨겨 유지)**: 팝업·스크롤까지 남지만, Next가 "최근 몇 개" 화면만 살려 두고 나머지는 지워서 작성 내용이 말없이 사라질 수 있다. 켜려면 앱 전체의 데이터 읽기 방식(동적 데이터는 Suspense·`'use cache'`)을 바꿔야 한다.
- **DB 임시 저장**: 다른 PC·브라우저를 껐다 켜도 남지만, 표·정리 작업이 필요하고 미완성 입력(개인정보 포함)이 DB에 쌓인다. 필요해지면 `form-drafts.ts`의 저장 위치만 바꿔 넓힌다.
- **localStorage(브라우저 전체)**: 브라우저를 껐다 켜도 남지만, 공용 PC에서 다음 사람이 볼 수 있다.
- **떠날 때마다 "보관하고 이동 / 버리고 이동" 묻기**: 탭을 오갈 때마다 창이 떠 불편하다. 버리는 것은 탭을 닫을 때만 묻는다.
