# 0033. 센터별 배송권역 관리

- 날짜: 2026-11-15
- 상태: 채택
- 관련: 0025 (코드 3층), 0026 (센터), 0031·0032 (입력·목록 화면 틀), 0016 (데이터 범위)
- 화면: `/admin/master/delivery-zones` (목록·등록·수정), 센터 수정 화면의 "배송권역" 섹션
- 코드: `src/lib/delivery-zones/`, `src/app/admin/master/delivery-zones/`, `src/config/korea-regions.ts`, `scripts/generate-korea-regions.py`

## 결정

### 무엇을 저장하나

- **배송권역**(PRD: 센터가 배송을 담당하는 지역 구분) = 센터 + 이름 + **담당 지역 목록**. 지금은 정의·관리까지만, 출고(MVP 이후)에서 "주소 → 센터·권역"을 정하는 기준으로 쓴다.
- 표: `DeliveryZone`(센터, 시스템 코드 `DZ`+6자리, 사용자 코드(같은 센터 안 중복 금지), 이름, 설명, 사용 여부) + `DeliveryZoneRegion`(권역, 지역 코드). 외부 코드는 `ExternalCode(DELIVERY_ZONE)` — 0025 코드 3층 그대로.
- **지역 단위: 시·도 / 시·군·구** (사용자 결정, 우편번호 범위는 사람이 알기 어려워 버림). 지역은 **법정동코드 앞자리**로 저장한다: 시·도 2자리 = 그 시·도 전체, 시·군·구 5자리. 이름은 바뀔 수 있지만(예: 전남광주통합특별시) 코드는 그대로이고, 카카오 주소 검색 결과의 `bcode` 앞 5자리와 같아 나중에 주소 매칭에 바로 쓸 수 있다.
- 일반구(수원시 장안구 등)는 넣지 않고 시 단위까지. 세종특별자치시는 시·군·구 없이 시·도 하나.
- 운영 정보(배송 요일·마감 시각·리드타임)는 지금 넣지 않고 출고 기능 때 더한다 (사용자 결정).

### 겹침 규칙 (사용자 결정)

- **같은 센터 안**: 한 지역은 권역 하나에만. `서울 전체`와 `서울 종로구`처럼 시·도 전체와 그 안의 시·군·구도 겹침으로 본다. 같은 권역 안 겹침은 입력 규칙에서, 다른 권역과의 겹침은 저장할 때 서버가 막는다. 사용 중지 권역도 지역을 잡고 있다(다시 사용할 때 겹치지 않게).
- **다른 센터끼리**: 겹쳐도 된다 (출고 때 화주사 이용 센터 기준으로 고른다). 겹칠 때 배송 센터를 정하는 규칙은 **0072** (거래처 지정 → 더 구체적인 지역 → 우선순위 → 배정 대기).

### 지역 목록 (행정구역 기준 데이터)

- 기억으로 만들지 않고 **공공데이터포털 '국토교통부_법정동코드'**(data.go.kr/data/15123287, 2026-09-29 갱신, CSV·CP949)에서 폐지여부 '존재'만 뽑아 `src/config/korea-regions.ts`로 고정했다 (사용자 허락 후 내려받음). 시·도 16개, 시·군·구 229개.
- 다시 만들기: `scripts/generate-korea-regions.py` (파일 머리에 방법). 원본 CSV는 저장소에 넣지 않는다.
- 행정구역이 바뀌면(통합·명칭 변경) 스크립트로 다시 만들고, 저장된 권역 코드가 사라진 경우는 화면에서 코드 그대로 보인다(`regionLabel`이 모르는 코드는 그대로 표시).

### 화면·권한

- 목록: 검색어·센터·상태 / 상세: 담당 시·도·등록일. 담당 지역은 요약("서울특별시 전체, 경기도 성남시 외 3곳"), 엑셀에는 전체. 일괄 사용 중지·다시 사용·삭제.
- 등록·수정: 기본 정보 / **담당 지역**(시·도 고르기 → 시·군·구 체크, "전체" 체크 시 그 안은 잠김, 다른 권역이 쓰는 지역은 흐리게 + 권역 이름, 고른 지역은 태그) / 외부 코드 / 상태(따로 처리하는 섹션). 센터 상세의 [권역 추가]는 센터를 미리 고른다.
- 권한 `master.delivery-zones` CRUD + `export`. 센터 직원은 소속 센터 권역만(목록·한 건·이미 쓰는 지역 목록 모두).
- 삭제는 "쓰인 적 없는 권역만" — 지금은 쓰는 곳이 없어 `findUsedZoneIds`가 빈 목록. **출고 작업 때 채운다** (ROADMAP).
