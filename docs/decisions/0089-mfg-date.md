# 0089. 제조일 저장과 유통기한 계산 (M8 A3)

- 날짜: 2026-11-20
- 상태: 채택
- 관련: 0083 (품목 기한 입력 방식·총 기한 일수), 0053 (검수), 0057 (입고 확정), 0045 (재고 변경 공통 함수), 0088 (재고 주소), 기준정보 누락 검토 2-2·3-2
- 코드: `src/lib/items/expiry-dates.ts` (`resolveExpiryDates`·`addDays`·`isMfgInput`, 화면·서버 공용), `src/lib/inbound/asns.ts` (`resolveItemDates`), `src/lib/stock/stock-change.ts`
- 마이그레이션: `20261120100000_mfg_date`

## 배경

품목에 기한 입력 방식(기한일·제조일·둘 다)과 총 기한 일수가 있고 "제조일도 함께 저장"으로 정했지만(0083), 검수·입고확정·재고·이력에 제조일을 둘 칸이 없었다.

## 결정 (검토 문서 3-2 권장안)

- `mfg_dt`(DATE)를 `tb_asn_line`(화주가 알려 준 값)·`tb_inbound_inspection`·`tb_inbound_receipt_line`·`tb_stock`·`tb_stock_txn`에 둔다.
- **재고 주소(고유키)에는 넣지 않는다.** 같은 로트·유통기한이면 제조일이 달라도 같은 재고 줄. 재고 줄의 제조일은 그 줄이 **처음 생길 때의 값**이고, 이동·상태 변경으로 새 줄이 생기면 출발 줄의 제조일을 옮긴다. 이력에는 그때 재고 줄의 제조일이 남는다.
- **기한 정하기 규칙**(`resolveExpiryDates`, 화면 미리보기와 서버가 같은 함수):
  - 기한일 입력(또는 방식 미지정): 유통기한 필수, 제조일 선택.
  - 제조일 입력: 제조일 필수, **유통기한 = 제조일 + 총 기한 일수**(입력한 유통기한은 쓰지 않음, 화면 칸은 잠기고 계산 값 표시).
  - 둘 다: 둘 다 필수.
  - 공통: 제조일 ≤ 유통기한. 유통기한을 관리하지 않는 품목은 둘 다 비운다.
- 검수는 필수 검사를 하고, ASN(예정 정보)은 필수 검사 없이 넣은 값만 같은 규칙으로 계산·검사한다. ASN 엑셀 업로드에 선택 열 '제조일'.
- 화면: 검수 입력·기록에 제조일, ASN 줄 표에 제조일 열(표가 창보다 넓어지지 않게 열 너비 조정), 재고 조회 위치별 보기에 제조일 열(기본 숨김).

## 버린 안

- **제조일을 재고 주소에 포함**: 같은 유통기한의 재고가 제조일마다 갈라져 로케이션·피킹이 복잡해진다. 기한 관리는 유통기한 기준이면 충분하다.
- **재고 줄의 제조일을 가장 최근 값으로 덮기**: 같은 줄에 여러 제조일이 섞이면 어느 값도 정확하지 않다. 처음 값으로 두고, 정확한 값은 입고확정 줄·이력에서 본다.
