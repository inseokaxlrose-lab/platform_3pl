# 0051. ASN 조회

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0047·0048 (ASN), 0003 결정 5 (잔량·초과 계산), 0032 (목록 화면 틀)

## 만든 것

| 화면 | 주소 | 권한 |
| --- | --- | --- |
| ASN 조회 (운영사) | `/admin/inbound/asn` | `inbound.asn.read`, 엑셀 `inbound.asn.export` |
| ASN 조회 (포털) | `/portal/asn` | `portal.asn.read` (엑셀 없음) |
| ASN 화면의 **진행 현황** | `/…/asn/[id]` | 품목별 예정·누적 확정·잔량·초과·적치·적치 가능·마감 (기본단위) |

- 목록 함수 `src/lib/inbound/asn-list.ts`, 목록 화면 `AsnsList`(운영사·포털 공용), 진행 계산 `src/lib/inbound/asn-progress.ts`(`lineProgress`, 화면·서버 공용 순수 함수).
- 검색 조건: 검색어(ASN 번호·화주사 문서 번호·화주사), 화주사, 입고 센터, 입고 상태(여러 개) / 상세: 입고 예정일 기간, 적치 상태, 등록 경로, 등록일.
- 잔량 = max(예정 − 누적 확정 − 마감, 0), 초과 = max(누적 확정 − 예정, 0) — 저장하지 않고 계산(0003). 마감 수량을 빼는 것은 마감 후 잔량을 0으로 보기 위해서.

## 추천안으로 정한 것 (검토 필요)

- **목록 한 행 = ASN 하나**: 품목마다 단위가 달라(EA·KG) 수량을 더하면 뜻이 없다 → 목록은 **품목 수 / 잔량 줄 수 / 초과 줄 수**로 요약하고, 수량은 ASN 화면의 진행 현황(품목별, 기본단위)에서 본다. 초과 줄이 있으면 주황색.
- 목록에서 여러 건 지우기는 두지 않았다(지우기는 ASN 화면에서, 예정 상태만).
- 등록 경로 칸은 운영사 화면에서만 기본 표시(포털은 숨김).
