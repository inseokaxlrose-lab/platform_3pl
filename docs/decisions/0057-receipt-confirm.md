# 0057. 입고 확정

- 날짜: 2026-11-16
- 상태: 채택 — **추천안으로 진행, 사용자 검토 필요**
- 관련: 0003 결정 5 (부분 확정·초과 확정·확정 문서), 0045·0046 (재고 변경 공통 함수·트랜잭션 도우미), 0053 (검수)

## 규칙 (`src/lib/inbound/receipts.ts` `confirmReceipt`)

- 입력: ASN + 검수 기록마다 확정 수량(기본단위). 같은 검수 기록이 두 번 오면 합친다.
- **검수된 정상 수량 중 원하는 만큼만**(부분 확정, 여러 번). 확정할 때마다 입고확정 문서(`RC261116-00001`) + 라인.
- 거부: 마감된 ASN, 검수가 없는 ASN(예정), 다른 ASN의 검수, 확정 가능 수량(검수 − 확정됨) 초과, 기본단위 소수 자리.
- **초과 입고 허용**: 예정보다 많아도 확정한다. 화면이 "초과 입고" 확인을 받는다(줄 번호와 초과 수량을 보여 줌).
- 재고: 센터의 **입고대기 창고 기본 로케이션**에 `receiveStock`(원본 문서 `RECEIPT` + 확정 번호), 로트·유통기한은 검수 값. 입고확정 라인에 재고 줄·재고 이력 키를 남긴다(적치는 이 줄에서).
- 누적: 검수의 확정 수량, ASN 줄의 누적 확정 수량을 더한다. 검수 확정 수량은 **조건부로 더해서**(`확정됨 ≤ 검수 − 이번`) 동시에 확정해도 검수 수량을 넘지 않는다.
- 상태: 모든 줄 누적 확정 ≥ 예정 → **확정완료**, 아니면 **부분확정**.
- 전체를 `stockTransaction`(교착 시 자동 다시 시도) 하나로 — 문서·재고·누적이 함께 저장되거나 함께 취소.
- 권한: 화면 `inbound.confirm.read`, 확정 `inbound.confirm.confirm`. 데이터 범위는 ASN 범위.

## 화면

- `/admin/inbound/confirm`: 확정할 ASN 고르기(상태를 고르지 않으면 검수중·부분확정).
- `/admin/inbound/confirm/[asnId]`: 확정할 검수(줄마다 "이번 확정" 수량, 기본은 남은 전부) → [입고 확정](확인 창, 초과면 초과 확인) / 입고 확정 이력(확정 번호·일시·품목·로트·수량·적치·확정자).

## 추천안으로 정한 것 (검토 필요)

- "이번 확정" 기본값 = 남은 수량 전부(대부분 한 번에 확정하므로). 0이면 이번에 확정하지 않는다.
- 확정 취소 기능은 없다 — 잘못 확정하면 재고 조정으로 바로잡는다.
- 불량 수량은 확정 대상이 아니다(재고가 되지 않음).
