---

우리 회사 재고만 보입니다. 수량은 낱개(기본단위)로 세고, **환산** 칸은 상자(BOX)·팔레트(PLT)로 나눈 모양입니다 (예: 3,000 EA → 2 PLT · 5 BOX).

![내 재고](/help/portal/stock/list.png)

① 보기 기준과 검색 조건 · ② 재고 목록 · ③ [도움말]

## 보기 기준

| 보기 | 한 줄 |
| - | - |
| 위치별 | 센터·창고·로케이션 + 품목 + 로트 + 유통기한 |
| 품목별 | 품목 합계 (모든 위치·로트를 더함) |
| 로트·유통기한별 | 품목 + 로트 + 유통기한 합계 |

- **재고상태**: 정상 / 보류 / 불량 / 격리. 센터가 품질 확인·파손 등으로 상태를 바꾼 재고는 따로 보입니다.
- **가용**은 재고 − 할당(출고를 위해 잡아 둔 수량)이며, **정상 재고만** 가용으로 셉니다.
- **임박**: 유통기한까지 남은 일수가 품목의 임박 기준 일수 이하입니다 (예: D-10). **만료**: 유통기한이 지났습니다.
- 수량이 0이 된 줄은 기본으로 빠집니다. [상세 조건]의 **수량 0 포함**으로 볼 수 있습니다.
