여기에 등록한 품목으로 입고예정(ASN)을 만들고 재고를 확인합니다. 우리 회사의 품목만 보입니다.

## 검색 · 목록 보기

- 검색어(품목코드·품목명·바코드)와 **상태**로 찾고, [조회] 또는 Enter로 적용합니다. 로트·유통기한 사용 여부와 등록일은 [상세 조건]에 있습니다.
- 행이나 품목코드를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 환산단위 | 묶음 단위와 입수량 (예: `BOX 24` = 한 상자에 24개) |
| 로트 · 유통기한 · 라벨 | **지금 실제로 적용되는 값**입니다. "화주사 기본값"을 고른 품목은 우리 회사 설정을 따릅니다 |
| 라벨 옆 ⚠ | 라벨 단위(BOX·PLT)의 입수량이 없습니다. 센터에서 그 품목의 라벨을 붙일 수 없으니 넣어 주세요 |

## [품목 등록]

1. **품목명**을 입력합니다. 품목코드를 비우면 자동으로 코드가 붙습니다. 직접 정하면 영문·숫자·점·하이픈·밑줄 2~30자이고, 같은 코드나 바코드는 다시 쓸 수 없습니다.
2. **기본단위**를 고릅니다. 재고를 세는 단위입니다 (낱개면 EA, 무게면 KG).
3. 상자·팔레트로 보내면 [환산단위 추가]로 BOX·PLT 등과 **입수량**을 넣습니다. 예: 한 상자에 24개면 BOX 24.
4. **관리 옵션**: 로트번호·유통기한을 적어야 하는 상품인지, 라벨을 어느 단위로 붙일지 정합니다. 기본은 **화주사 기본값**(우리 회사 설정)을 따르고, 이 품목만 다르면 직접 고릅니다.
   - 유통기한을 쓰면 **임박 기준 일수**를 정할 수 있습니다. 유통기한까지 그 일수 이하로 남으면 재고에 "임박"으로 표시됩니다.
5. [저장]하면 수정 화면으로 이동합니다.

## 수정 · 사용 중지

- 이름·단위·관리 옵션을 고칠 수 있습니다.
- 더 이상 보내지 않는 품목은 **사용 중지**합니다. 새 입고예정에서 고를 수 없게 되고, 이미 있는 재고·기록은 그대로입니다.

## 삭제 · 되살리기

- 아직 입고·재고 기록이 없는 품목만 지울 수 있습니다. 실수로 지웠으면 상태 거르기의 **삭제됨**에서 골라 [되살리기]를 누릅니다.
