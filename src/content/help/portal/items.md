여기에 등록한 품목으로 입고예정(ASN)을 만들고 재고를 확인합니다. 우리 회사의 품목만 보입니다.

![품목 목록](/help/portal/items/list.png)

① 검색 조건 · ② 목록(파란 글자를 누르면 상세) · ③ [품목 등록]

## 검색 · 목록 보기

- 검색어(품목코드·품목명·어느 단위의 바코드든), **상태**(사용·사용중지·단종), **품목 유형**으로 찾고, [조회] 또는 Enter로 적용합니다.
- [상세 조건]에는 분류1·브랜드·보관 온도대·기한 관리·LOT 관리·위험물·**체적**(미등록/등록)·**PLT 적재**(미등록/등록)·등록일이 있습니다.
- 행이나 품목코드를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| BOX 입수 · PLT 입수(BOX) | 상자 하나에 낱개 몇 개, 팔레트 하나에 상자 몇 개 |
| BOX CBM · BOX 중량 | 상자 규격으로 계산한 체적과 총중량 |
| 체적 | 상자 가로·세로·높이·총중량이 모두 있으면 **등록**, 하나라도 없으면 **미등록** — 센터가 보관 공간을 계산하려면 필요합니다 |
| 상태 | 사용 · 사용중지 · **단종**(센터가 정함: 새 입고예정에 넣을 수 없고, 남은 재고는 출고 가능) |

> [!TIP]
> [상세 조건]의 **체적: 미등록**으로 상자 규격을 아직 넣지 않은 품목을 모아 볼 수 있습니다.

## [품목 등록]

1. **품목코드**와 **품목명**을 넣습니다. 품목코드는 우리 회사가 쓰는 코드 그대로(영문·숫자·점·하이픈·밑줄 50자 이하)이고 **등록 후 바꿀 수 없습니다.** 같은 코드는 다시 쓸 수 없습니다.
2. **단위·규격**: **기본단위**(재고를 세는 단위, 낱개면 EA·무게면 KG)를 고르고, 상자·팔레트로 보내면 [BOX 추가]·[PLT 추가]로 행을 더합니다.
   - **환산수량**은 "이 단위 1개 = 기본단위 몇 개"입니다. 예: 한 상자에 24개면 `1 BOX = 24 EA`.
   - 상자 **가로·세로·높이(cm)와 총중량(kg)**을 넣어 주세요. 센터가 보관 공간과 운송을 계산하는 데 씁니다. 없으면 "체적 미등록"으로 표시됩니다.
3. **팔레트 적재**: 팔레트 한 단에 상자 몇 개(TI) × 몇 단(HI)으로 쌓는지 넣으면 PLT 수량·높이가 자동으로 계산됩니다. 모르면 팔레트당 상자 수만 넣어도 됩니다.
4. **소비기한·LOT**: 처음에는 우리 회사 기본 설정이 채워집니다. 기한을 관리하면 기한 종류·입력 방식을, 제조일로 입력하면 **총 기한 일수**도 넣습니다. LOT를 관리하면 LOT 생성 방식을 고릅니다.
5. **바코드**: [바코드 추가]로 낱개·상자 바코드를 넣습니다. EAN-13 등은 체크디지트를 검사하고, 우리 회사의 다른 품목과 같은 바코드는 쓸 수 없습니다.
6. [저장]하면 그 자리에 "등록했습니다."가 나옵니다. [계속 등록]으로 다음 품목을 넣거나 [등록한 항목 보기]로 수정 화면으로 갑니다.

> [!WARNING]
> "확인할 것: …"이 함께 나오면 저장은 됐지만 값을 다시 봐 주세요. 예: 상자 규격을 mm로 넣으면 체적이 1,000배가 되어 **밀도 이상**으로 알려 드립니다.

## 수정 · 사용 중지

- 이름·단위·규격·관리 옵션·바코드를 고칠 수 있습니다. **품목코드는 바꿀 수 없습니다.**
- 센터에 재고나 진행 중인 입고예정이 있으면 기본단위와 기한·LOT 관리 여부는 바꿀 수 없습니다 (화면에 이유가 나옵니다).
- 더 이상 보내지 않는 품목은 **사용 중지**합니다. 새 입고예정에서 고를 수 없게 되고, 이미 있는 재고·기록은 그대로입니다.

<!-- 권한: portal.items.delete -->
## 삭제 · 되살리기

- 아직 입고·재고 기록이 없는 품목만 지울 수 있습니다. 실수로 지웠으면 상태 거르기의 **삭제됨**에서 골라 [되살리기]를 누릅니다.
