title: 재고 조회

---

재고는 항상 **기본단위**(EA·KG 등)로 셉니다. **환산** 칸은 같은 수량을 큰 묶음부터 나눠 보여 줍니다 (예: 3,000 EA → 2 PLT · 5 BOX).

![재고 조회](/help/admin/stock/list.png)

① 보기 기준(위치별·품목별·로트·유통기한별)과 검색 조건 · ② 재고 목록 · ③ [도움말]

## 보기 기준

| 보기 | 한 줄 | 쓰임 |
| - | - | - |
| 위치별 | 로케이션 + 품목 + 로트 + 유통기한 + 재고상태 하나 | 어디에 얼마나 있는지 |
| 품목별 | 화주사 + 품목 + 재고상태 합계 (여러 로케이션·로트를 더함) | 화주사가 맡긴 품목이 모두 몇 개인지 |
| 로트·유통기한별 | 화주사 + 품목 + 로트 + 유통기한 + 재고상태 합계 | 유통기한 관리 |

- **재고상태**: 정상 / 보류 / 불량 / 격리. 같은 자리의 같은 품목이라도 상태가 다르면 다른 줄입니다.
- **할당**은 출고를 위해 잡아 둔 수량, **가용**은 재고 − 할당입니다. **정상 재고만 가용**이고, 보류·불량·격리 재고의 가용은 0입니다.
- **임박**: 유통기한까지 남은 일수가 품목의 임박 기준 일수 이하 (예: D-10). 기준이 없는 품목은 만료만 표시합니다. **만료**: 유통기한이 지났습니다.

## 검색

- 검색어(품목코드·품목명·바코드·로케이션·로트), 센터, 화주사로 찾습니다. 창고·유통기한(임박·만료)·재고상태·수량 0 포함은 [상세 조건]에 있습니다.
- 수량이 0이 된 재고 줄은 기본으로 빠집니다.

## [상태 변경]

위치별 보기의 줄마다 있습니다. 특정 로트만 출고 금지로 묶거나(보류), 불량·격리로 나눌 때 씁니다. 창고를 옮기지 않아도 됩니다.

1. 바꿀 **재고상태**를 고릅니다.
2. **수량**을 넣습니다. 비우면 가용 수량 전부입니다(할당된 수량은 바꿀 수 없습니다).
3. 보류·불량·격리로 바꿀 때는 **사유**(품질 검사·화주 요청·파손 의심·리콜 등)를 꼭 고릅니다. 정상으로 되돌릴 때는 고르지 않아도 됩니다.
4. [상태 변경]을 누르면 같은 자리에 상태별 줄이 생기고, 재고 이력에 **상태 변경** 두 줄(나감·들어옴)이 남습니다.

> [!NOTE]
> 창고의 **기본 재고상태**가 보류·불량·격리인 창고(예: 격리 창고)로 입고·이동하면 그 상태가 됩니다. 반대로 보류 재고를 정상 창고로 옮겨도 보류는 풀리지 않습니다 — 풀 때는 [상태 변경]으로 정상으로 바꿉니다.
