---
title: 재고 조회
summary: 지금 재고를 위치별·품목별·로트·유통기한별로 봅니다.
---

재고는 항상 **기본단위**(EA·KG 등)로 셉니다. **환산** 칸은 같은 수량을 큰 묶음부터 나눠 보여 줍니다 (예: 3,000 EA → 2 PLT · 5 BOX).

## 보기 기준

| 보기 | 한 줄 | 쓰임 |
| - | - | - |
| 위치별 | 로케이션 + 품목 + 로트 + 유통기한 하나 | 어디에 얼마나 있는지 |
| 품목별 | 화주사 + 품목 합계 (여러 로케이션·로트를 더함) | 화주사가 맡긴 품목이 모두 몇 개인지 |
| 로트·유통기한별 | 화주사 + 품목 + 로트 + 유통기한 합계 | 유통기한 관리 |

- **할당**은 출고를 위해 잡아 둔 수량, **가용**은 재고 − 할당입니다.
- **임박**: 유통기한까지 남은 일수가 품목의 임박 기준 일수 이하 (예: D-10). 기준이 없는 품목은 만료만 표시합니다. **만료**: 유통기한이 지났습니다.

## 검색

- 검색어(품목코드·품목명·바코드·로케이션·로트), 센터, 화주사로 찾습니다. 창고·유통기한(임박·만료)·수량 0 포함은 [상세 조건]에 있습니다.
- 수량이 0이 된 재고 줄은 기본으로 빠집니다.
