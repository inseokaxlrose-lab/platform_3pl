---
title: 실사·조정
summary: 실제로 센 수량과 재고의 차이, 파손·분실 등으로 재고를 바로잡습니다.
---

재고는 직접 고칠 수 없고, 이 화면에서 **등록 → 확정**을 거쳐야 바뀝니다. 바뀐 내용은 재고 이력에 사유와 함께 남습니다.

| 유형 | 적는 것 | 확정하면 |
| - | - | - |
| 실사 | 재고 줄마다 **실제로 센 수량** | (센 수량 − **확정할 때** 재고)만큼 바뀝니다 |
| 조정 | 재고 줄마다 **늘릴(+)·줄일(−) 수량** | 적은 수량만큼 바뀝니다 |

![실사·조정 목록](/help/admin/stock/adjustments/list.png)

① 검색 조건 · ② 목록(번호를 누르면 상세) · ③ [실사·조정 등록]

## 목록

- 검색어(번호·사유·등록자), 센터, 유형, 상태(등록·확정·취소)로 찾습니다. 번호를 누르면 상세를 봅니다.

<!-- 권한: stock.adjustments.create -->
## [실사·조정 등록] · [취소]

1. **유형**(실사·조정)과 **센터**를 고르고 **사유**를 꼭 적습니다 (예: 정기 실사, 파손, 분실).
2. [줄 추가]로 재고 줄(로케이션·품목·로트)을 검색해 고르고 수량을 넣습니다. 실사는 지금 재고와의 차이가 아래에 보입니다.
3. [저장]하면 **등록** 상태가 됩니다. 아직 재고는 바뀌지 않습니다.

- 확정 전에는 상세 화면의 [취소]로 없앨 수 있습니다.

<!-- 권한: stock.adjustments.confirm -->
## [확정]

- 상세 화면에서 줄마다 **바뀔 수량**을 확인하고 [확정]합니다. 재고가 바뀌고 재고 이력에 남습니다. 되돌릴 수 없습니다.
- 실사는 등록 뒤 입고·적치 등으로 재고가 바뀌었으면 **확정할 때의 재고**로 다시 계산합니다 ("지금 재고" 칸).
- 줄이려는 수량이 할당되지 않은 재고보다 많으면 확정되지 않습니다.
