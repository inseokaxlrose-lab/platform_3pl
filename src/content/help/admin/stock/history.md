---
title: 재고 이력
summary: 재고가 바뀐 기록(입고·이동·조정·상태 변경)을 찾아봅니다.
---

재고는 입고 확정·적치·실사·조정으로만 바뀌고, 바뀔 때마다 여기에 한 줄씩 남습니다. 이력은 **고치거나 지울 수 없습니다**.

![재고 이력](/help/admin/stock/history/list.png)

① 검색 조건(기간·유형) · ② 이력 목록(변동 +/−, 원본 문서) · ③ [도움말]

## 검색 · 목록 보기

- 검색어(품목·로케이션·로트·문서 번호·사유·처리자), **유형**, **기간**으로 찾습니다. 센터·화주사·원본 문서는 [상세 조건]에 있습니다.

| 칸 | 뜻 |
| - | - |
| 유형 | 입고(입고 확정) / 이동(나감·들어옴: 적치 등) / 조정(실사·조정) / 상태 변경(정상·보류·불량·격리, 나감·들어옴 두 줄) |
| 재고상태 | 그때 그 줄의 재고상태 |
| 변동 · 변동 후 | 이번에 늘거나 준 수량과 바뀐 뒤 그 재고 줄의 수량 (기본단위) |
| 원본 문서 | 어떤 작업으로 바뀌었는지 (입고확정·적치·실사·조정 번호) |
| 묶음 번호 | 이동처럼 두 줄(나감·들어옴)이 한 작업이면 같은 번호 (칸 설정에서 보이기) |
