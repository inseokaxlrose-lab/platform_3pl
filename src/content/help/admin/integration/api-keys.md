모든 화주사의 API 키를 모아 보는 화면입니다. **운영사 관리자만** 볼 수 있습니다.

## 목록 보기

- **기본 조건**: 검색어(화주사 코드·화주사명·키 이름·키 식별부), 화주사, 상태(사용 중·폐기·만료).
- **[상세 조건]**: 환경(TEST·LIVE), **만료 예정(14일 안)** — 곧 만료되는 키를 미리 찾아 화주에게 교체를 안내하세요.
- 키는 `live_ak7f2c9x_••••`처럼 **식별부만** 보입니다. 키 원문은 발급할 때 한 번만 볼 수 있고, 시스템에는 해시만 남습니다.

> [!NOTE]
> **TEST 키**는 검증만 하고 저장하지 않습니다(dry-run). 화주 개발자가 실제 데이터를 건드리지 않고 형식·필수값을 확인할 때 씁니다. 실제 저장은 **LIVE 키**만 합니다.

## [키 발급]

화주 시스템이 연동 API를 부를 때 쓰는 키입니다. **화주사 편집 화면 → API 키** 섹션에서 관리하고 (목록 줄의 화주사를 누르면 바로 감), [저장]과 상관없이 바로 처리됩니다.

1. [키 발급]을 누르고 **키 이름**(예: ERP 연동용), **환경**, **권한**, 허용 IP, 만료일, 분당 호출 한도를 정합니다.
2. 처음에는 **TEST** 키로 연동을 검증하고, 끝나면 **LIVE** 키를 발급합니다.
3. 발급하면 키 원문이 **한 번만** 보입니다. [복사]한 뒤 "보관했습니다"에 체크해야 창이 닫힙니다. 키는 화주 개발 담당자에게 안전하게 전달하세요.

> [!WARNING]
> 창을 닫으면 키를 다시 볼 수 없습니다. 잃어버리면 그 키를 폐기하고 새로 발급합니다. LIVE 키는 **허용 IP**를 화주 서버로 제한하는 것을 권장합니다.

## [수정] · [폐기] · 교체

- [수정]: 이름·권한·허용 IP·만료일·호출 한도를 고칩니다. 환경은 바꿀 수 없습니다. 팝업 아래에 **키 이력**(발급·수정·폐기·만료, 누가·언제)이 보입니다.
- [폐기]: 사유를 넣으면 **즉시** 효력이 생겨 다음 호출부터 거부됩니다. 되돌릴 수 없습니다.
- **교체**: 환경마다 사용 중인 키는 2개까지입니다. 새 키 발급 → 화주가 시스템에 적용 → 옛 키 폐기 순서로 합니다.
- 만료 14일 전부터 **만료 예정** 배지가 붙습니다. 이 화면의 **만료 예정** 조건으로 모아 볼 수 있습니다.

> [!WARNING]
> 화주사의 **연동 → API 사용**이 꺼져 있으면 키가 있어도 모든 호출이 거부됩니다. 준비중 화주는 TEST 키로만, 일시정지 화주는 조회 API만 부를 수 있고, 해지하면 키가 모두 폐기됩니다.
