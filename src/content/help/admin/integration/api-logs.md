화주 시스템이 연동 API를 부를 때마다 한 줄씩 남습니다. **운영사 관리자만** 볼 수 있습니다.

![API 호출 이력 목록](/help/admin/integration/api-logs/list.png)

① 검색 조건(기간을 비우면 최근 7일) · ② 호출 목록(요청 일시를 누르면 상세, 위에 [엑셀]) · ③ [도움말]

## 오늘 요약

제목 아래에 **오늘 호출 수 · 실패율 · 호출 한도 초과(429) · 실패 많은 화주**가 보입니다. 화주 배지를 누르면 그 화주의 실패·부분 성공만 걸러 봅니다.

## 검색

- **기본 조건**: 화주사, 기간(비우면 최근 7일), API 구분, 결과(성공·부분 성공·실패).
- **[상세 조건]**: 환경(TEST·LIVE), 키, 요청ID, 화주 문서번호(주문번호·품목코드 등, 건별 결과에서 찾음), 오류코드, HTTP 상태.
- 화주가 문의하면 응답에 들어 있던 **요청ID**(`req_…`)로 찾으세요.

> [!NOTE]
> 키 확인 전에 실패한 요청(키 없음·틀린 키)은 어느 운영사의 것인지 알 수 없어 이 화면에 보이지 않습니다. 키는 맞지만 거부된 요청(폐기·만료·허용 IP·화주 상태)은 그 화주로 남습니다.

## 상세

요청 일시를 누르면 **요약**(API·화주·키·IP·HTTP 상태·처리 시간·오류코드), **건별 결과**(등록 API의 한 건마다 결과·오류), **요청·응답 본문**이 보입니다.

- 본문의 이름·전화·주소·이메일은 **저장할 때 가린 값**입니다(예: `홍*동`, `010****5678`). 키 원문은 어디에도 남지 않습니다.
- 본문은 **90일**, 요약 줄은 **1년** 보관합니다.
- **이 키의 최근 7일 호출**을 누르면 같은 키의 호출만 모아 봅니다. 유출이 의심될 때 낯선 IP·시각이 있는지 확인한 뒤 화주사 화면에서 키를 폐기하세요.
