화주사 포털·센터 대리·엑셀 업로드로 등록된 ASN이 모두 모입니다. 센터 직원은 소속 센터의 ASN만 봅니다.

## 검색 · 목록 보기

- 검색어(ASN 번호·화주사 문서 번호·화주사), **화주사**, **입고 센터**, **입고 상태**(여러 개)로 찾습니다. 예정일·적치 상태·등록 경로·등록일은 [상세 조건]에 있습니다.
- **잔량 줄**: 아직 다 받지 않은 품목 수, **초과 줄**: 예정보다 많이 받은 품목 수입니다. 초과가 있으면 주황색으로 보입니다.
- ASN 번호를 누르면 ASN 화면으로 가서 품목별 **진행 현황**(예정·누적 확정·잔량·초과·적치)을 봅니다.

| 입고 상태 | 뜻 |
| - | - |
| 예정 | 아직 검수 전. 고치거나 지울 수 있습니다 |
| 검수중 | 검수를 시작했습니다 |
| 부분확정 | 일부만 입고 확정했습니다 |
| 확정완료 | 모든 품목을 예정 수량 이상 확정했습니다 |
| 마감 | 남은 수량을 더 받지 않기로 마감했습니다 |

## [ASN 등록]

- 화주사를 대신해 ASN을 등록합니다. 여러 건은 등록 화면의 [엑셀 업로드]로 한 번에 올릴 수 있습니다.

<!-- 권한: inbound.asn.close -->
## [잔량 마감]

- ASN 화면의 **상태**에서 누릅니다. 더 도착하지 않을 남은 수량을 **사유와 함께** 마감합니다 (예: 화주사 요청으로 잔량 취소).
- 품목마다 그때의 잔량이 **마감 수량**으로 남고, 잔량은 0이 됩니다. 마감한 사람·일시도 기록됩니다.
- 마감하면 더 검수·입고 확정할 수 없습니다. 이미 확정된 재고의 **적치는 계속** 할 수 있습니다.
- 확정완료된 ASN이나 잔량이 없는 ASN은 마감할 수 없습니다.
