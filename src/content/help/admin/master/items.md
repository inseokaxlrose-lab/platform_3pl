title: 품목
summary: 화주사가 맡긴 상품을 등록하고, 단위·규격(BOX·PLT), 팔레트 적재, 소비기한·LOT 관리, 바코드를 정합니다.
---

품목은 **화주사별**로 관리합니다. 같은 품목코드라도 화주사가 다르면 다른 품목입니다. 센터 직원은 소속 센터를 이용하는 화주사의 품목만 보고 다룹니다.

![품목 목록](/help/admin/master/items/list.png)

① 검색 조건 · ② 목록(파란 글자를 누르면 상세, 골라서 일괄 처리) · ③ [엑셀 업로드] · [품목 등록]

## 검색 · 목록 보기

- 검색어(품목코드·사용자 정의 코드·품목명·화주사, 그리고 **어느 단위의 바코드든**), **화주사**, **상태**(사용·사용중지·단종), **품목 유형**으로 찾고, [조회] 또는 Enter로 적용합니다.
- [상세 조건]에는 분류1·브랜드·보관 온도대·기한 관리·LOT 관리·위험물·**체적**(미등록/등록)·**PLT 적재**(미등록/등록)·등록 경로·등록일이 있습니다.
- 행이나 품목코드를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| BOX 입수 · PLT 입수(BOX) | BOX 하나에 기본단위 몇 개, 팔레트 하나에 BOX 몇 개 |
| BOX CBM · BOX 중량 | BOX 규격으로 계산한 체적과 총중량 |
| 기한 관리 | 기한을 관리하면 기한 종류(소비기한 등), 안 하면 `-` |
| 체적 | BOX의 가로·세로·높이·총중량이 모두 있으면 **등록**, 하나라도 없으면 **미등록** |
| 상태 | 사용 · 사용중지 · **단종** |
| 숨긴 칸 | [컬럼]에서 바코드(기본단위 대표)·환산단위·라벨·임박 기준·등록 경로·최근 연동을 켤 수 있습니다 |

> [!TIP]
> 체적·PLT 적재를 아직 넣지 않은 품목은 [상세 조건]에서 **체적: 미등록** 또는 **PLT 적재: 미등록**으로 모아 보고, 아래 [팔레트 적재 일괄 입력]으로 한 번에 채우세요.

## 상태 바꾸기 · [팔레트 적재 일괄 입력]

목록에서 품목을 골라 한 번에 처리합니다.

- **[사용] · [사용중지] · [단종]**: 고른 품목의 상태를 바꿉니다.
  - **단종**: 새 입고예정(ASN)에서 고를 수 없습니다. 남은 재고는 출고할 수 있습니다.
  - **사용중지**: 새 입고예정과 출고요청에서 모두 고를 수 없습니다.
- **[팔레트 적재 일괄 입력]**: 팔레트 종류와 단당 박스 수(TI)·단수(HI)(또는 팔레트당 박스 수)를 넣고 [적용]하면, 고른 품목마다 PLT를 다시 계산해 저장합니다.
  - **BOX 단위가 없는 품목은 건너뛰고** 나머지에 적용합니다. 결과에 `2개 중 1개 적용 · 건너뜀 1 (TMP-C: BOX 단위가 없습니다)`처럼 나옵니다.
  - 팔레트 높이·중량이 권장값을 넘는 품목은 "확인할 것"으로 세어 알려 줍니다(저장은 됩니다).

## [엑셀 업로드]

여러 품목을 한 번에 등록하거나 고칩니다. 품목 API와 같은 규칙으로 처리합니다. 품목 등록·수정 권한이 둘 다 있어야 버튼이 보입니다.

1. [엑셀 업로드] → [양식 내려받기]로 양식을 받습니다. 안내 시트에 칸별 설명과 코드 값이 있습니다.
2. **한 줄이 품목 하나**입니다. 화주사의 **연동 조회 키**에 따라 품목코드(기본) 또는 **사용자정의코드**로 찾아, 없으면 등록하고 있으면 고칩니다. 새 품목은 품목명·기본단위가 필수입니다.
   - 품목코드로 찾는 화주사에서 품목코드를 비운 줄은 **새 품목**으로 등록하고 코드를 자동으로 붙입니다.
   - 사용자 정의 코드로 찾는 화주사는 사용자정의코드 칸이 필수입니다.
   - BOX 규격(가로·세로·높이·총중량), 팔레트종류·TI·HI를 한 줄에 넣습니다. 적재 정보가 없을 때만 PLT입수를 직접 넣습니다.
   - 바코드는 단위마다 한 칸(기본단위·INNER·BOX·PLT)이고, 그 단위의 **대표 바코드**가 됩니다. 여러 개는 품목 화면에서 넣습니다.
   - 기한관리 Y만 넣으면 소비기한·기한일 입력, LOT관리 Y만 넣으면 입고 시 입력으로 정합니다.
3. 파일을 고르면 실제로 처리해 본 결과가 미리보기에 나옵니다(예: `신규 3 · 수정 0 · 변경 없음 0 / 체적 미등록 2 · 팔레트 높이·중량 초과 0`). 저장은 아직 안 됩니다.
4. 오류가 없으면 [등록]합니다.

> [!NOTE]
> 이미 있는 품목은 **넣은 칸만** 고치고 비운 칸은 그대로 둡니다(값을 지우려면 화면에서). 같은 파일을 다시 올리면 "변경 없음"으로 세고 아무것도 바꾸지 않습니다.

> [!WARNING]
> 오류가 하나라도 있으면 파일 전체가 등록되지 않습니다. 미리보기의 오류 사유(없는 단위 코드, Y/N 아닌 값, 화주사 없음, 같은 품목 두 줄 등)를 고쳐 다시 올려 주세요.

## [품목 등록]

![품목 등록 — 단위·규격과 팔레트 적재](/help/admin/master/items/new.png)

① 단위·규격 표(팔레트로 계산한 PLT는 `계산` 표시) · ② 팔레트 적재와 계산 요약 · ③ [저장]

1. **기본 정보**: 화주사를 고르고 **품목코드**·**품목명**을 넣습니다.
   - 품목코드를 **비워 두면 자동으로 붙습니다**: 화주사 코드 접두어 + `S` + 6자리(예: `GNS000001`). 직접 넣으면 영문·숫자·점·하이픈·밑줄 50자 이하, 대문자로 저장됩니다. 자동 모양(`GNS000001` 등)은 직접 쓸 수 없고, **등록 후 바꿀 수 없으며** 같은 화주사 안에서 겹칠 수 없습니다.
   - **사용자 정의 코드**에는 화주 시스템(ERP 등)의 품목코드를 넣습니다. 고칠 수 있고, 같은 화주사 안에서 겹칠 수 없습니다.
2. **단위·규격**: **기본단위**(재고를 세는 단위, EA·KG 등)를 고르고, 묶음으로 오가면 [INNER 추가]·[BOX 추가]·[PLT 추가]로 행을 더합니다.
   - **환산수량**은 "이 단위 1개 = 기본단위 몇 개"입니다. 예: `1 BOX = 24 EA`. 위 단위일수록 커야 합니다 (기본 < INNER < BOX < PLT).
   - 환산수량의 소수 자리는 기본단위를 따릅니다 (EA는 정수만, KG는 소수 3자리까지).
   - **규격**(가로·세로·높이 cm, 총중량 kg)을 넣으면 CBM이 자동으로 계산됩니다. 체적은 **BOX 규격**으로 계산하므로 BOX 규격이 없으면 "체적 미등록"입니다.
   - 기본 입고·주문단위는 비우면 자동입니다 (입고 = BOX, 없으면 기본단위 / 주문 = 기본단위).
3. **팔레트 적재**: 팔레트 종류와 **단당 박스 수(TI) × 단수(HI)**를 넣으면 PLT가 자동으로 계산됩니다. TI·HI를 모르면 **팔레트당 박스 수**만 넣어도 됩니다.
   - 예: BOX 24 EA, T11, 10 × 5단 → `1 PLT = 50 BOX = 1,200 EA`, 높이 5 × BOX 높이 + 팔레트 높이
   - 적재 정보를 넣지 않으면 단위 표에서 PLT 환산수량을 직접 넣습니다.
4. **보관 조건**: 보관 온도대(같은 온도대 창고에만 적치), 위험물·파손 주의·세워서 보관, 최대 적층 단수를 정합니다.
5. **소비기한·LOT**: 처음에는 **화주사 기본 설정**이 채워집니다. 이 품목만 다르면 바꿉니다.
   - 기한을 관리하면 **기한 종류**와 **입력 방식**이 필요합니다. 제조일로 입력하면 **총 기한 일수**도 넣어야 기한일을 계산합니다.
   - LOT를 관리하면 **LOT 생성 방식**을 고릅니다.
   - 저장한 뒤에는 화주사 설정이 바뀌어도 이 품목 값은 그대로입니다.
6. **바코드**: [바코드 추가]로 단위별 바코드를 여러 개 넣습니다. EAN-13·ITF-14 등은 체크디지트를 검사하고, 단위별 대표 바코드 1개를 라벨에 씁니다 (안 고르면 첫 바코드).
   - 같은 화주사의 다른 품목과는 겹칠 수 없습니다. **다른 화주사**는 같은 바코드를 쓸 수 있습니다.
7. [저장]하면 그 자리에 "등록했습니다."가 나옵니다. [계속 등록]으로 다음 품목을 넣거나 [등록한 항목 보기]로 수정 화면으로 갑니다.

> [!WARNING]
> 저장은 되지만 확인할 것이 있으면 "확인할 것: …"으로 함께 알려 줍니다. 예: 체적 미등록, **밀도 이상**(cm 대신 mm로 넣으면 체적이 1,000배가 됩니다), 팔레트 높이·중량 초과, BOX가 INNER의 배수가 아님, 최대 적층보다 단수가 많음.

## 수정 · 사용 중지

- 이름·단위·규격·관리 옵션·바코드를 고칠 수 있습니다 (SAP·ERP 외부 코드는 **외부코드 매핑** 메뉴). **화주사와 품목코드는 바꿀 수 없습니다.**
- **재고나 미완료 입고예정(ASN)이 있으면** 기본단위와 기한·LOT·시리얼 관리 여부를 바꿀 수 없습니다. 화면에 이유가 나오고 그 칸이 잠깁니다.
- 환산수량을 바꾸면 변경 이력이 남습니다. 그 단위로 입력된 미완료 ASN이 있으면 바꿀 수 없습니다.
- 수정 화면의 사용 여부로 사용·사용중지를 바꿉니다. 단종은 목록에서 골라 [단종]으로 바꿉니다.
- 수정 화면 아래 **이미지**에서 [이미지 올리기]로 품목 사진을 붙입니다. 올리면 **바로 저장**되고(한 장 10MB, 최대 20장, PNG·JPEG·WEBP·GIF), 사진을 누르면 크게 봅니다. 화주 포털에서도 그 화주사 사용자가 같은 사진을 봅니다.

## 삭제 · 되살리기

- 재고·입고 기록이 없는 품목만 지울 수 있습니다. 지우면 그 품목의 바코드는 풀려서 다른 품목이 쓸 수 있습니다.
- 지운 품목은 상태 거르기의 **삭제됨**에서 골라 [되살리기]로 되돌립니다. 같은 화주사에 같은 품목코드가 다시 생겼으면 되살릴 수 없습니다 (바코드는 다시 넣어 주세요).
