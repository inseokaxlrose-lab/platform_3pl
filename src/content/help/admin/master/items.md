---
title: 품목
summary: 화주사가 맡긴 상품을 등록하고, 단위·환산단위와 로트·유통기한 관리 여부를 정합니다.
---

품목은 **화주사별**로 관리합니다. 같은 품목코드라도 화주사가 다르면 다른 품목입니다. 센터 직원은 소속 센터를 이용하는 화주사의 품목만 보고 다룹니다.

## 검색 · 목록 보기

- 검색어(품목코드·품목명·바코드·화주사), **화주사**, **상태**로 찾고, [조회] 또는 Enter로 적용합니다. 로트·유통기한 사용 여부와 등록일은 [상세 조건]에 있습니다.
- 행이나 품목코드를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 환산단위 | 묶음 단위와 입수량 (예: `BOX 24 · PLT 1,440` = BOX 하나에 24개, PLT 하나에 1,440개) |
| 로트 · 유통기한 · 라벨 | **지금 실제로 적용되는 값**입니다. 품목에서 "화주사 기본값"을 골랐으면 화주사 설정을 보여 줍니다 |
| 라벨 옆 ⚠ | 라벨 단위의 입수량이 없습니다. 이대로는 그 품목의 라벨을 발행할 수 없습니다 |

## [품목 등록]

1. **화주사**를 고르고 **품목명**을 입력합니다. 품목코드를 비우면 자동으로 부여되는 시스템 코드(`IT00000001` 모양)를 씁니다.
   - 품목코드·바코드는 같은 화주사 안에서 겹칠 수 없습니다. 품목코드는 영문·숫자·점·하이픈·밑줄 2~30자이고 대문자로 저장됩니다.
2. **기본단위**를 고릅니다. 재고는 항상 이 단위로 셉니다 (EA, KG 등).
3. 묶음으로 오가면 [환산단위 추가]로 BOX·PLT 등과 **입수량**(기본단위 기준)을 넣습니다.
   - 예: 기본단위 EA, BOX = 24, PLT = 1,440
   - 입수량의 소수 자리는 기본단위를 따릅니다 (EA는 정수만, KG는 소수 3자리까지).
4. **관리 옵션**: 로트번호·유통기한·라벨 단위는 기본으로 **화주사 기본값**을 따릅니다. 이 품목만 다르게 하려면 "사용"·"안 함"이나 PLT·BOX를 직접 고릅니다.
   - 아래에 "지금 적용: …"으로 실제로 쓰이는 값이 보입니다.
   - 유통기한을 쓰면 **임박 기준 일수**를 정할 수 있습니다. 유통기한까지 그 일수 이하로 남으면 재고에서 "임박"으로 표시합니다.
5. [저장]하면 그 자리에 "등록했습니다."가 나오고 입력 칸이 잠깁니다. [계속 등록]을 누르면 빈 양식으로 다음 품목을 이어서 넣고, [등록한 항목 보기]를 누르면 수정 화면으로 갑니다.

## 수정 · 사용 중지

- 품목코드·이름·단위·관리 옵션을 고칠 수 있습니다 (SAP·ERP 외부 코드는 **외부코드 매핑** 메뉴). **화주사는 바꿀 수 없습니다.**
- 사용 중지하면 새 입고예정에서 고를 수 없게 됩니다. 이미 있는 재고·기록은 그대로입니다. 목록에서 여러 개를 골라 한 번에 사용 중지·다시 사용할 수도 있습니다.

## 삭제 · 되살리기

- 재고·입고 기록이 없는 품목만 지울 수 있습니다. 지운 품목은 상태 거르기의 **삭제됨**에서 골라 [되살리기]로 되돌립니다.
- 같은 화주사에 같은 품목코드·바코드가 다시 생겼으면 되살릴 수 없습니다.
