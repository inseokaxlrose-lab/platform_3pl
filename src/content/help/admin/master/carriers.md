---

운송사는 "어느 회사가 물건을 실어 가는가"입니다. 화주·센터별 고객코드와 송장 대역은 **운송 계약** 메뉴에서 정하고, 여기서는 운송사 자체(이름·유형·송장 규칙)를 관리합니다.

![운송사 목록](/help/admin/master/carriers/list.png)

① 검색 조건 · ② 목록(코드를 누르면 편집 화면) · ③ [운송사 등록]

| 운송 유형 | 뜻 |
| - | - |
| 택배 | 송장번호로 배송을 추적합니다. 운송 계약에 송장 대역을 넣을 수 있습니다 |
| 화물 | 화물차 운송 (송장 대역 없음) |
| 자차 | 우리 회사 차량 |
| 용차 | 그때그때 빌리는 차량 |

> [!NOTE]
> 처음에는 **CJ대한통운·한진택배·롯데택배·우체국택배·로젠택배·자차·용차**가 들어 있습니다. 송장 자릿수·체크디지트는 흔히 쓰는 값이니, 실제 계약서의 송장 규칙과 다르면 고쳐 주세요.

## 목록 보기

- 검색어(코드·사용자 정의 코드·운송사명), 운송 유형, 상태로 찾습니다. 상태의 **삭제됨**에서 지운 운송사를 보고 [되살리기]할 수 있습니다.
- **운송 계약** 칸은 그 운송사를 쓰는 계약 수입니다.

## [운송사 등록]

1. **운송사 코드**(영문 대문자·숫자·하이픈·밑줄 20자 이하)와 **운송사명**을 넣습니다. 코드는 등록 후 바꿀 수 없습니다.
2. **운송 유형**을 고릅니다. **사용자 정의 코드**에는 화주·ERP 시스템이 쓰는 택배사 코드를 넣습니다(선택, 운영사 안에서 겹칠 수 없음).
3. **송장 규칙**을 넣습니다.
   - **송장 자릿수**: 체크디지트를 포함한 송장번호 길이. 비우면 검사하지 않습니다.
   - **체크디지트**: **7로 나눈 나머지**면 송장번호 끝자리 = 앞자리 숫자를 7로 나눈 나머지입니다. 체크디지트를 쓰면 자릿수도 넣어야 합니다. **번호 예시**에서 모양을 확인합니다.
   - **배송 조회 주소**: 송장번호가 들어갈 자리에 `{invoiceNo}`를 넣습니다.
4. [저장]합니다.

## 수정 · 사용 중지

- 코드를 뺀 모든 칸을 고칠 수 있습니다. 외부 코드(SAP·ERP)는 **외부코드 매핑** 메뉴에서 넣습니다.
- 목록에서 골라 [사용 중지]하면 새 운송 계약·화주사 기본 택배사에서 고를 수 없습니다. 이미 정해 둔 계약·화주사는 그대로입니다.

## 삭제

운송 계약이나 화주사 기본 택배사에 쓰인 운송사는 지울 수 없습니다. 사용 중지하세요.
