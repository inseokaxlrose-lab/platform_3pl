---
title: 운영사
summary: 이 시스템을 운영하는 회사(3PL 운영사)의 정보와 담당자를 관리합니다.
---

운영사는 한 곳이며, 여기 적힌 회사명·사업자등록번호·주소는 앞으로 라벨·거래명세서 등을 출력할 때 쓰입니다.

## 화면 구성

| 묶음 | 내용 |
| - | - |
| 기본 정보 | 회사명·사업자등록번호(필수), 대표자, 업태·종목 |
| 연락처 | 대표 전화, 팩스, 대표 이메일 |
| 주소 | 우편번호·주소(검색), 상세주소 |
| 담당자 | 업무별 담당자 최대 5명 |

- 제목 아래에 **마지막으로 고친 사람과 시각**이 보입니다.
- 수정 권한이 없으면 모든 칸이 잠긴 **읽기 전용**입니다.

## 정보 입력·수정

1. 회사명과 사업자등록번호를 입력합니다.
   - 사업자등록번호는 하이픈 없이 10자리를 넣어도 저장할 때 `000-00-00000` 모양으로 바뀝니다.
   - 마지막 자리(검증번호)까지 확인하므로, 한 자리라도 틀리면 저장되지 않습니다.
2. 전화·팩스는 숫자와 하이픈(-)으로 입력합니다. 예) `02-123-4567`, `1588-1234`
3. [저장]을 누릅니다. 잘못된 칸은 빨간 글자로 알려 줍니다.

<!-- 권한: master.company.update -->
## 주소 입력

1. [주소 검색]을 누르고 도로명·건물명·지번으로 검색합니다.
2. 결과를 고르면 우편번호와 주소가 채워지고, **상세주소** 칸으로 바로 이동합니다.
3. 동·층·호수 등 상세주소를 입력합니다.

> 회사 네트워크에서 주소 검색 서비스(카카오)가 막혀 있으면 안내가 나오고, 우편번호와 주소를 직접 입력할 수 있게 바뀝니다.

<!-- 권한: master.company.update -->
## 담당자

- [담당자 추가]로 줄을 늘립니다. **최대 5명**까지 등록할 수 있습니다.
- 담당 업무(예: 입고 문의, 정산)와 담당자명은 필수, 연락처·이메일은 선택입니다.
- 줄 오른쪽 휴지통으로 지웁니다. 화면에 보이는 순서대로 저장됩니다.
