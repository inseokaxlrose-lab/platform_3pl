로그인한 계정이 속한 운영사(우리 회사)의 정보입니다. 다른 운영사의 정보·데이터는 보이지 않습니다. 여기 적힌 회사명·사업자등록번호·주소는 앞으로 라벨·거래명세서 등을 출력할 때 쓰입니다.

![운영사 정보](/help/admin/master/operator/form.png)

① 섹션 목차(누르면 그 칸으로) · ② 기본 정보 · ③ [취소]·[저장]

## 화면 구성

| 섹션 | 내용 |
| - | - |
| 기본 정보 | 운영사코드(읽기 전용), 회사명·영문명·약칭, 운영사 유형(읽기 전용), 사업자등록번호·사업자 구분·법인등록번호(법인만)·종사업장번호, 과세유형, 대표자·업태·종목, 설립일, 비고 |
| 연락처·주소 | 대표 전화, 팩스, 대표 이메일, 주소(검색) |
| 담당자 | 업무별 담당자 최대 5명, 대표 1명 |

- 넓은 화면에서는 왼쪽 **목차**를 눌러 섹션으로 이동합니다. 오류가 있는 섹션에는 빨간 점이 붙습니다.
- 제목 아래에 **운영 상태**(운영중·가입대기·일시정지·해지)와 **마지막으로 고친 사람과 시각**이 보입니다.
- **운영사코드·운영사 유형·운영 상태**는 플랫폼에서 정합니다. 바꿔야 하면 플랫폼 관리자에게 요청하세요.
- 대표자·업태·종목·대표 전화·주소는 **권장** 칸입니다. 비워도 저장되지만, 출력물(거래명세서 등)에 쓰이므로 채워 두세요.
- 수정 권한이 없으면 모든 칸이 잠긴 **읽기 전용**입니다.

## 정보 입력·저장

1. 사업자등록번호·전화·팩스는 **숫자만** 치면 하이픈이 자동으로 붙습니다. 예) `0212345678` → `02-1234-5678`
   - 사업자등록번호·법인등록번호는 마지막 자리(검증번호)까지 확인하므로, 한 자리라도 틀리면 저장되지 않습니다.
   - 사업자 구분을 **개인**으로 바꾸면 법인등록번호 칸이 사라지고, 저장할 때 비워집니다.
2. 무엇이든 고치면 위쪽 헤더에 **변경사항 있음**이 보이고 [저장]·[취소]가 켜집니다.
   - [취소]: 마지막으로 저장한 내용으로 되돌립니다.
   - [저장]: 잘못된 칸이 있으면 저장하지 않고 **첫 번째 오류 칸으로 이동**합니다.
3. 저장하지 않은 채 다른 메뉴로 가려 하면 확인 창이 뜹니다. 새로고침·창 닫기는 브라우저가 확인합니다.

## 주소 입력

1. [주소 검색]을 누르고 도로명·건물명·지번으로 검색합니다.
2. 결과를 고르면 우편번호와 주소가 채워지고, **상세주소** 칸으로 바로 이동합니다.
3. 동·층·호수 등 상세주소를 입력합니다.

> [!NOTE]
> 회사 네트워크에서 주소 검색 서비스(카카오)가 막혀 있으면 안내가 나오고, 우편번호와 주소를 직접 입력할 수 있게 바뀝니다.

## 담당자

- [담당자 추가]로 행을 늘립니다. **최대 5명**까지 등록할 수 있습니다.
- **담당 업무**는 목록에서 고릅니다(입고·출고·재고·정산·계약·IT·기타). 목록은 시스템 > 공통코드의 `CONTACT_ROLE`에서 관리합니다.
- 담당 업무·담당자명은 필수이고, **연락처와 이메일 중 하나는 꼭** 입력합니다.
- 부서·직책은 선택이고, **알림**은 그 담당자가 알림 메일을 받을지입니다(기본 받음).
- **대표**는 1명만 고를 수 있습니다. 처음 추가한 담당자가 자동으로 대표가 되고, 대표를 지우면 남은 첫 담당자가 대표가 됩니다.
- 행 오른쪽 휴지통으로 바로 지웁니다. 저장 전이면 [취소]로 되돌릴 수 있습니다. 화면에 보이는 순서대로 저장됩니다.

## 로고·직인

- 화면 아래 **로고·직인**에서 [올리기]로 이미지를 고르면 **바로 저장**됩니다([저장] 버튼과 따로). [바꾸기]로 다른 이미지로, 휴지통으로 지웁니다.
- PNG·JPEG·WEBP·GIF 이미지, 한 장 10MB까지입니다. 라벨·거래명세서 같은 출력물에 씁니다.
