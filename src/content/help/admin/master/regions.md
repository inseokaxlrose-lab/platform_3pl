---

권역설정의 기준은 **우편번호별 배정표 하나**입니다. 한 우편번호(온도대마다)에는 센터가 **하나만** 배정되고, 같은 우편번호를 두 번 배정할 수는 없습니다.
- 지역(시도·시군구·읍면동)을 골라 지정하면, 그 아래 우편번호 **전체를 덮어씁니다.** 우선순위 규칙이 없어서 화면에 보이는 배정이 곧 결과입니다.
- 배정이 없는 우편번호는 **미배정**입니다. 그 지역 주소는 배송센터를 직접 확인해야 합니다.
- 지역 마스터(법정동·우편번호)는 화면에서 고치지 않습니다. 관리자가 매월 적재 스크립트로 갱신합니다.

## 화면 위 요약

전체 우편번호 수, 배정 수(전체 온도대 기준), 미배정, **확인 필요**(자동 추천), 지역 마스터 버전을 보여 줍니다. 그 아래에는 센터별 배정 수가 나오고, 일시중지 센터는 노란색으로 표시됩니다.

지역 마스터를 갱신하면 새로 생긴 우편번호에 **자동 추천** 배정이 들어갑니다. 같은 읍면동의 다른 우편번호가 가장 많이 배정된 센터예요. 그 건수와 폐지된 우편번호에 남은 배정이 안내로 나옵니다.

## 배정 탭

![권역설정 배정 탭](/help/admin/master/regions/assign.png)

① 지역 트리 · ② 지역 전체 지정(센터를 고르고 [이 지역 전체 지정]) · ③ 우편번호 표(⚠ = 경계 우편번호)

- **왼쪽 지역 트리**: 시도 → 시군구 → 읍면동입니다. 노드마다 우편번호 수와 배지가 붙습니다.

  | 배지 | 뜻 |
  | - | - |
  | 센터 이름 | 모두 그 센터 (일부만 배정되면 비율) |
  | 혼합 | 여러 센터로 나뉨 (마우스를 올리면 센터별 비율) |
  | 미배정 n | 배정이 없는 우편번호 수 |
  | 확인 n | 자동 추천이라 확인이 필요한 수 |

- **주소로 찾기**: 주소를 넣으면 그 우편번호가 있는 곳까지 트리를 펼치고, 표 맨 위에 보여 줍니다.
- **오른쪽 우편번호 표**: 고른 지역 아래 우편번호입니다.
  - 칸: 법정동(⚠ = 여러 읍면동에 걸친 **경계 우편번호**), 대표 주소(주소가 많은 도로 2곳), 배송센터, 배정 구분(사용자 지정·자동 추천·엑셀 업로드), 확인, 폐지.
  - 거르기: 미배정만, 확인 필요만, 경계 우편번호만, 센터별.
- **온도대별로 다르게 설정**을 켜면 온도대를 고를 수 있습니다. 그 온도대에 따로 배정이 없는 우편번호는 회색 `전체: 센터`로, 전체 온도대 배정을 따른다는 뜻입니다. 특정 온도대만 다른 센터가 맡을 때만 쓰세요.

## 센터 지정 · 해제

- **지역 전체**: 표 위에서 센터를 고르고 [이 지역 전체 지정]을 누르면 그 지역 아래 우편번호를 모두 덮어씁니다. [전체 해제]는 배정을 지웁니다.
- **고른 우편번호**: 표에서 줄을 고른 뒤 센터를 정해 [센터 지정]·[배정 해제]를 누릅니다.
- **[추천 확인]**: 자동 추천 배정을 그대로 확정합니다. 다른 센터로 지정해도 확정됩니다.
- 배정할 수 있는 센터는 **준비중·운영중** 센터뿐이고, 온도대를 고른 상태면 그 온도대를 취급하는 센터만 고를 수 있습니다.

모든 저장은 **변경 미리보기**를 거칩니다.
- 미리보기에는 `이천센터 → 평택센터 132건`, `미배정 → 평택센터 4건`처럼 바뀌는 배정이 센터별로 나옵니다. 지역 마스터에 없거나 폐지되어 제외되는 우편번호도 함께 보입니다.
- 읍면동 단위로 지정하면 **경계 우편번호 n건**을 포함할지 제외할지 고릅니다.

> [!TIP]
> 경계 우편번호는 기본으로 **제외**됩니다. 하나씩 다르게 정하려면 제외하고 표에서 따로 지정하세요.

- 변경 사유(선택)를 적고 [저장]하면 **작업 단위 1건**으로 묶여 이력에 남습니다.
- **납품처 영향**: 바뀌는 우편번호에 거래처 납품처가 있으면 미리보기에 `자동 지정 납품처 n곳 센터 변경 · 수동·연동 지정 납품처 n곳 권역 불일치 발생`처럼 나옵니다. [저장]하면 바로 다시 정합니다.
  1. 권역 자동 납품처는 새 센터로 바뀝니다.
  2. 수동·연동으로 지정한 납품처는 센터를 그대로 두고 **권역 불일치**로 표시합니다.
  3. 배송센터 **확인 필요** 납품처는 다시 시도해 정해지면 지정 완료가 됩니다.

> [!NOTE]
> 다시 정한 결과는 기준정보 > **납품처**에서 확인합니다. 엑셀 업로드 저장도 같습니다. 온도대별 배정은 납품처에 쓰이지 않습니다(전체 배정만).

## 붙여넣기로 지정

엑셀이나 문서의 우편번호 목록을 붙여 넣고(줄바꿈·쉼표·공백 구분) 센터를 고른 뒤 [미리보기]를 누릅니다.
- 5자리 숫자가 아닌 것은 바로 알려 줍니다.
- 없는 우편번호·폐지된 우편번호는 미리보기에서 제외로 보여 줍니다.

## 엑셀 업로드

[양식 내려받기] → 우편번호·온도대(비우면 전체)·센터코드(비우면 해제)를 채워 올립니다. 검사 결과와 **바뀌는 배정 요약**을 먼저 보여 주고, 오류가 하나도 없을 때만 반영합니다. 한 번에 1,000행까지입니다.

<!-- 권한: master.regions.export -->
## 엑셀 다운로드

현재 배정표 전체를 내려받습니다. 칸은 우편번호, 시도, 시군구, 법정동, 대표 주소, 폐지, 온도대, 센터코드, 센터명, 배정 구분, 확인입니다. 고쳐서 그대로 엑셀 업로드에 쓸 수 있어요.

## 변경 이력 탭

저장 한 번이 작업 하나입니다. 작업마다 일시, 작업 종류, 범위, 온도대, 변경 건수, 사유, 작업자가 나옵니다. 범위를 누르면 우편번호별 변경 전·후 센터가 보입니다.

## 시뮬레이터 탭

주소와 우편번호를 넣으면 실제 납품처·주문과 같은 규칙으로 결과를 보여 줍니다. 저장하지는 않아요.
- **주소 정제 결과**: 등급과 우편번호·법정동입니다.

  | 등급 | 뜻 |
  | - | - |
  | A | 건물 확정 |
  | B | 우편번호 확정 |
  | C | 법정동 추정 |
  | D | 시군구 추정 |
  | F | 실패 |

- **배송센터 결정 결과**: 결정된 센터, 결정 기준(우편번호·법정동·시군구), 확인 필요 여부와 이유를 보여 줍니다.
- 등급이 운영사의 자동 지정 기준(기본 D 이상)보다 낮거나, 지역의 우편번호가 여러 센터로 나뉘어 있으면 "확인 필요"입니다.

## 센터와의 관계

> [!WARNING]
> 배정된 우편번호가 있는 센터는 **폐쇄할 수 없습니다.** 먼저 다른 센터로 옮기세요.

- 센터에서 취급 온도대를 빼려면, 그 온도대로 배정된 우편번호가 없어야 합니다.
- 일시중지 센터는 배정이 유지되지만 요약과 결정 결과에 경고가 붙습니다.
