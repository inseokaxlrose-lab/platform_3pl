센터 직원은 **자기 센터를 이용하는 화주사만** 볼 수 있고, 등록·수정·상태 변경은 운영사 사용자만 합니다.

![화주사 목록](/help/admin/master/shippers/list.png)

① 검색 조건 · ② 목록(파란 글자를 누르면 상세) · ③ [화주사 등록]

## 검색 · 목록 보기

- **기본 조건**: 검색어(화주사 코드·사용자 정의 코드·화주사명·약칭), 상태(여러 개), 이용 센터.
- **[상세 조건]**: 화주 유형, 업종, 연동 방식, API 사용, 계약종료일, 사업자등록번호(숫자 일부), 등록일.
- **이용 센터** 칸의 `★`는 기본 센터입니다. 계약종료일이 비어 있으면 `자동연장`으로 보입니다.
- 행을 누르면 수정 화면으로 갑니다. 조건·페이지·정렬은 주소창에 남아 [목록]으로 돌아와도 그대로입니다.

## 코드

| 코드 | 예 | 설명 |
| - | - | - |
| 화주사 코드 | `SH0001` | 비워 두면 자동으로 붙습니다. 직접 넣을 수도 있지만 `SH0001` 같은 자동 모양은 쓸 수 없고, 등록 후에는 바꿀 수 없습니다 |
| 코드 접두어 | `GN` | 2글자(영문 대문자 + 영문·숫자, 헷갈리는 I·O·0·1 제외). 이 화주사의 **거래처·품목 코드를 자동으로 만들 때 앞에 붙습니다**(`GNC000001`·`GNS000001`). 거래처·품목 코드가 한 번이라도 만들어지면 바꿀 수 없습니다 |
| 사용자 정의 코드 | `ERP-1001` | 운영사 ERP 등 다른 시스템에서 이 화주사를 부르는 코드(선택). 운영사 안에서 겹칠 수 없습니다 |

> [!TIP]
> **연동** 섹션의 **연동 조회 키**는 엑셀 업로드·API가 거래처·품목을 무엇으로 찾을지 정합니다. **우리 코드**(기본)면 품목코드·거래처코드로, **사용자 정의 코드**면 화주 시스템의 코드로 찾습니다.

## 상태

| 상태 | 포털 로그인 | 새 입고(ASN) | 품목·거래처 등록 |
| - | - | - | - |
| 준비중 (새 화주사) | 가능 | 불가 | 가능 |
| 운영중 | 가능 | 가능 | 가능 |
| 일시정지 | 조회만 | 불가 | 불가 (진행 중인 입고는 계속 처리) |
| 해지 | 불가 | 불가 | 불가 |

> [!NOTE]
> 새 화주사는 **준비중**으로 시작합니다. 품목·포털 사용자를 준비한 뒤 [상태 변경]으로 **운영중**으로 바꿔야 입고를 받을 수 있습니다.

## [화주사 등록]

![화주사 등록 화면](/help/admin/master/shippers/new.png)

① 섹션 목차(누르면 그 섹션으로) · ② 기본 정보 · ③ [저장]

1. **기본 정보**: 화주사명과 **사업자등록번호**(필수, 검증번호까지 확인)를 넣습니다. 화주사 코드를 비우면 `SH0001`처럼 자동으로 붙습니다. **코드 접두어**(2글자)는 필수입니다. 법인등록번호는 사업자 구분이 법인일 때만 보입니다.
2. **연락처·주소**: 번호는 숫자만 쳐도 하이픈이 붙습니다. 주소는 반품 회수지 기본값으로도 씁니다.
3. **담당자**(최대 10명): 연락처·이메일 중 하나 필수, 대표 1명. 부서·직책은 선택이고, **알림**은 그 담당자가 알림 메일을 받을지입니다(기본 받음). **연동** 칸을 고른 사람은 API 키 발급·만료 알림을 받는 연동 담당자로, 1명만·이메일 필수입니다.
4. **이용 센터**: [센터 추가]로 1곳 이상 넣고 **기본** 센터 1곳을 고릅니다(하나뿐이면 저절로 기본). 시작일·종료일·상태(이용중/이용종료)를 정합니다.
5. **계약·정산**: 계약시작일(필수), 계약종료일(비우면 기한 없음), 자동연장, 정산 주기, 정산 마감일, 결제 조건, 세금계산서 이메일.
6. **운영 설정**·**거래처·주문 정책**·**연동**을 확인하고 [저장]합니다. 그 자리에 "등록했습니다."가 나오고, [계속 등록]으로 다음 화주사를 넣거나 [등록한 항목 보기]로 수정 화면으로 갑니다.

> [!TIP]
> 같은 회사의 사업부별 화주처럼 **사업자등록번호가 같은 화주사**도 등록할 수 있습니다. 저장하면 같은 번호의 화주사가 있다고 알려 줍니다.

> [!WARNING]
> 운영사 요금제에 **최대 화주 수**가 정해져 있으면 그 수를 넘겨 등록할 수 없습니다.

## 운영 설정 (상속)

- **운영사 값 사용**에 체크하면 운영사 설정을 따릅니다(재고할당 규칙·출고 마감시각·로트·유통기한·시리얼 관리·정산 마감일). 체크를 풀면 이 화주사만 다르게 정합니다.
- 실제로 쓰는 값은 **구체적인 쪽이 이깁니다**: 품목 → 화주사×센터 → 화주사 → 센터 → 운영사.
- 로트·유통기한 관리는 **품목 기본값**입니다. 품목에서 다시 정할 수 있습니다.
- 입고·출고 최소 잔여일, 부분출고 허용, 재고 부족 시 처리, 거래처·주문 정책은 출고·주문 작업에서 쓰입니다.

## 출고 설정

택배 송장의 **보내는 사람**과 기본 택배사입니다.

- **발송인명**·**발송 전화**: 비우면 화주사명·대표 전화를 씁니다.
- **보내는 주소**: **출고 센터 주소**(기본) / **화주사 주소** / **직접 입력** 중에서 고릅니다. 직접 입력한 주소는 반품 회수지로도 씁니다.
- **기본 택배사**: 이 화주·센터의 **운송 계약**이 없을 때 쓰는 택배사입니다. 사용 중지한 운송사는 새로 고를 수 없습니다.

## 수정 · [상태 변경]

- 화주사 코드를 뺀 칸을 고칠 수 있습니다(코드 접두어는 거래처·품목 코드가 만들어지기 전까지만). 이미 연결된 센터가 일시중지됐어도 이용 센터로 그대로 둘 수 있지만, 새로 붙일 수는 없습니다.
- 그 센터에 이 화주사의 **재고나 끝나지 않은 입고**가 있으면 이용 센터에서 빼거나 이용종료로 바꿀 수 없습니다.
- 화면 위 [상태 변경]으로 준비중·운영중·일시정지·해지를 바꿉니다. 일시정지·해지는 **사유가 필수**입니다.
- 목록에서 여러 곳을 골라 [일시정지]·[운영중으로]를 한꺼번에 할 수 있습니다(해지된 화주사는 건너뜀).
- **포털 사용자** 섹션에서 이 화주사 소속 사용자를 확인하고, 사용자 메뉴로 이동할 수 있습니다.

> [!WARNING]
> **해지**는 재고와 끝나지 않은 입고가 없을 때만 됩니다. 해지하면 소속 포털 사용자는 로그인할 수 없고, 화면은 읽기 전용이 됩니다.

## API 키

편집 화면 아래 **API 키** 섹션에서 화주 시스템이 연동 API를 부를 때 쓰는 키를 발급·수정·폐기합니다. [저장]과 상관없이 바로 처리되고, 운영사 관리자(API 키 권한)에게만 보입니다. 순서는 **연동 → API 키** 도움말을 보세요.
