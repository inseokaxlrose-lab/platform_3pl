---
title: 거래처
summary: 화주사의 고객사를 등록하고, 물건을 받는 납품처와 배송센터·담당자를 관리합니다.
---

거래처는 **화주사별**로 관리합니다. 같은 거래처코드라도 화주사가 다르면 다른 거래처입니다. 거래처마다 실제로 물건을 받는 **납품처**를 하나 이상 두고, 납품처 주소로 권역설정의 **배송센터**를 정합니다. 센터 직원은 소속 센터를 이용하는 화주사의 거래처만 보고 다룹니다.

![거래처 목록](/help/admin/master/customers/list.png)

① 검색 조건 · ② 목록(파란 글자를 누르면 상세) · ③ [거래처 등록]

## 검색 · 목록 보기

- 검색어(거래처코드·사용자 정의 코드·명·약칭·사업자번호·화주사), **화주사**, **상태**, **배송센터 확인 필요**로 찾고, [조회] 또는 Enter로 적용합니다. 유형·그룹·주문 주소 사용·등록 경로·등록일은 [상세 조건]에 있습니다.
- 행이나 거래처코드를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 기본 납품처 지역 | 기본 납품처 주소의 시·군·구 |
| 배송센터 | 기본 납품처의 배송센터 |
| 확인 필요 | 배송센터를 정하지 못한 납품처 수(주황). 거래처를 열어 납품처에서 센터를 고르세요 |

> [!TIP]
> **배송센터 확인 필요 = 있음**으로 거르면 손봐야 할 거래처만 모아 볼 수 있습니다.

## [거래처 등록]

![거래처 등록](/help/admin/master/customers/new.png)

① 거래처 주소 · ② 납품처 · ③ [저장]

1. **화주사**를 고르고 **거래처코드**·**거래처명**을 입력합니다. 거래처코드를 **비워 두면 자동으로 붙습니다**: 화주사 코드 접두어 + `C` + 6자리(예: `GNC000001`). 직접 넣으면 영문·숫자·`-`·`_`(소문자는 대문자로)이고, 자동 모양은 직접 쓸 수 없습니다. **등록 후 바꿀 수 없으며** 같은 화주사 안에서 겹칠 수 없습니다. 화주 시스템(ERP 등)의 거래처 코드는 **사용자 정의 코드**에 넣습니다.
2. **주소·연락처**: [주소 검색]으로 거래처(본사) 주소를 고릅니다.
3. **납품처**를 넣지 않으면 [저장]할 때 **거래처 주소로 기본 납품처**가 만들어집니다(코드는 `거래처코드-01`, 이름은 거래처와 같게). 납품처코드도 비워 두면 `거래처코드-02`처럼 자동으로 붙습니다. 받는 곳이 따로 있으면 [납품처 추가]로 직접 넣습니다.
4. **출고 조건**(선택): 최소 잔여 유통기한(일)·비율(%)보다 짧게 남은 재고는 이 거래처로 출고하지 않습니다(출고 작업에서 적용).
5. **담당자**는 최대 5명, 대표 1명입니다. 담당 업무 목록은 시스템 > 공통코드의 `CONTACT_ROLE`, 거래처 유형은 `PARTNER_TYPE`입니다.
6. [저장]하면 "등록했습니다."가 나오고 입력 칸이 잠깁니다. [계속 등록]은 빈 양식으로, [등록한 항목 보기]는 수정 화면으로 갑니다.

> [!NOTE]
> 배송센터를 정하지 못한 납품처가 있으면 저장은 되고, 메시지 끝에 "배송센터 확인이 필요한 납품처가 있습니다: 코드"가 붙습니다.

## [엑셀 업로드]

여러 거래처·납품처를 한 번에 등록하거나 고칩니다. 화주 연동 API와 같은 규칙으로 처리합니다. 거래처 등록·수정 권한이 둘 다 있어야 버튼이 보입니다.

1. [엑셀 업로드] → [양식 내려받기]로 양식을 받습니다. 안내 시트에 칸별 설명이 있습니다.
2. **한 줄이 납품처 하나**입니다. 화주사코드·거래처코드가 같은 줄들이 거래처 하나가 되고, 거래처 칸은 줄마다 같게 넣습니다(다르면 오류). 납품처코드를 비우면 거래처만 등록·수정합니다.
3. 파일을 고르면 실제로 처리해 본 결과가 미리보기에 나옵니다(예: `거래처 신규 3 · 수정 1 · 변경 없음 0 / 납품처 배송센터 지정 5 · 확인 필요 1`). 저장은 아직 안 됩니다.
4. 오류가 없으면 [등록]합니다.

> [!NOTE]
> 이미 있는 거래처·납품처는 **넣은 칸만** 고치고 비운 칸은 그대로 둡니다(값을 지우려면 화면에서). 파일에 없는 납품처도 지우지 않습니다.

> [!WARNING]
> 오류가 하나라도 있으면 파일 전체가 등록되지 않습니다. 배송센터를 정하지 못한 납품처는 오류가 아니라 **확인 필요**로 저장됩니다.

## 납품처 · 배송센터

- 납품처 줄을 누르면 오른쪽에 편집 창이 열립니다. 고친 뒤 [적용]하면 표에 반영되고, 화면의 [저장]을 눌러야 실제로 저장됩니다.
- **기본 납품처**(라디오)는 꼭 1곳이며, 주문에 납품처가 없으면 기본 납품처로 갑니다. 사용 중인 납품처도 1곳 이상 있어야 합니다. 그래서 기본 납품처·마지막 사용 중 납품처는 [빼기]가 잠깁니다.
- **거래처 주소와 동기화**(기본 납품처만): 켜 두면 거래처 주소를 바꿀 때 납품처 주소도 바뀌고 배송센터를 다시 정합니다.
- **배송센터**
  1. **권역 자동**: [저장]할 때 주소로 권역설정을 찾아 정합니다. 주소를 고르면 "이 지역의 기본 배송센터"가 미리 보입니다.
  2. **직접 선택**: 그 화주사가 이용하는 센터만 고를 수 있습니다. 지역 기본 센터와 다르면 **권역 불일치**(⚠)로 표시됩니다.
- 주소·센터를 바꾸지 않은 납품처는 저장해도 지정이 그대로입니다.

| 표시 | 뜻 |
| - | - |
| 지정 완료 | 배송센터가 정해짐 (권역 자동·수동·연동) |
| 확인 필요 | 정하지 못함. 사유: 권역설정에 배정되지 않은 지역 / 여러 센터가 섞인 지역 / 주소 정제 실패 / 화주 이용 센터가 아님 / 센터 일시중지·폐쇄 |
| 정제 등급 | 주소를 얼마나 정확히 찾았는지 (A·B 정확, C·D 지역까지만, F 실패) |

> [!WARNING]
> "확인 필요" 납품처로는 배송센터를 자동으로 정할 수 없습니다. 권역설정에서 그 지역을 배정하거나, 납품처에서 센터를 직접 고르세요.

## 수정 · 거래중지

- 화주사·거래처코드·납품처코드를 뺀 칸을 고칠 수 있습니다.
- **연동 정보**(등록 경로·마지막 연동)는 읽기만 합니다.
- **거래중지**하면 새 출고요청을 받지 않습니다. 진행 중인 주문은 그대로 처리합니다. [거래재개]로 되돌리며, 목록에서 여러 곳을 골라 한 번에 처리할 수도 있습니다.

## 삭제 · 되살리기

- 출고 기록이 없는 거래처만 지울 수 있습니다. 납품처도 함께 지워집니다. 지운 거래처는 상태 거르기의 **삭제됨**에서 골라 [되살리기]로 되돌립니다.
- 같은 화주사에 같은 거래처코드가 다시 생겼으면 되살릴 수 없습니다.
