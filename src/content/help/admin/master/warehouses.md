## 창고 유형

유형에 따라 입고·출고가 되는지, 재고를 주문에 할당할 수 있는지, 적치될 때 재고상태가 정해집니다.

| 유형 | 입고 | 출고 | 출고 할당 | 기본 재고상태 |
| - | - | - | - | - |
| 일반 보관 | ○ | ○ | ○ | 정상 |
| 입고대기 | ○ | | | 정상 |
| 출고대기 | | ○ | | 정상 |
| 반품대기 | ○ | | | 보류 |
| 검수·보류 | ○ | | | 보류 |
| 불량 | ○ | | | 불량 |
| 유통가공 | ○ | ○ | | 정상 |
| 크로스도킹 | ○ | ○ | | 정상 |

- **기본** 배지가 붙은 창고(입고대기 `INBOUND`·출고대기 `OUTBOUND`·반품대기 `RETURN`)는 센터 등록 때 자동으로 만들어진 **시스템 기본 창고**입니다. 설명·정렬순서·비고만 고칠 수 있고, 삭제·사용 중지할 수 없습니다.

## 검색 · 목록 보기

- **기본 조건**: 센터, 검색어(창고코드·창고명), 창고 유형(여러 개), 상태. **[상세 조건]**: 온도대(여러 개), 출고 할당 가능, 등록일.
- 기본 순서는 **센터 → 창고 정렬순서 → 창고코드**입니다. 센터·창고코드는 가로로 스크롤해도 왼쪽에 고정됩니다.
- 창고코드 옆에 **기본** 배지와 설명이 작게 보입니다. 행을 누르면 수정 화면으로 갑니다.

## [창고 추가]

1. **센터**를 고릅니다 (고를 센터가 하나면 저절로 골라집니다). 센터는 등록 후 바꿀 수 없습니다.
2. **창고코드**(영문 대문자·숫자·밑줄, 소문자는 대문자로)와 창고명을 넣습니다. 코드는 같은 센터 안에서 겹치면 안 되고, 등록 후 바꿀 수 없습니다.
3. **창고 유형**을 고르면 아래 **운영 속성**이 유형 기본값으로 채워집니다. 운영 속성을 이미 고친 뒤 유형을 바꾸면 "유형 기본값으로 바꾸기 / 현재 값 유지"를 묻습니다.
4. **온도대**는 센터의 **취급 온도대** 중에서만 고를 수 있습니다. 필요한 온도대가 없으면 센터 화면에서 먼저 더하세요.
5. [저장]하면 수정 화면으로 갑니다. 센터에 출고 할당 가능한 창고가 하나도 없으면 저장 후 안내가 보입니다.

> [!NOTE]
> 준비중·운영중 센터에만 창고를 추가할 수 있습니다.

## 수정

- 센터·창고코드를 뺀 칸을 고칠 수 있습니다. [저장]은 그 자리에서 저장, [취소]는 마지막 저장 내용으로 되돌립니다.
- **재고가 있는 창고**는 창고 유형·온도대를 바꿀 수 없습니다 (재고상태·할당 대상이 바뀌기 때문). 재고를 옮긴 뒤 바꾸세요.
- **기본 로케이션**은 이 창고의 사용 중인 로케이션에서 고릅니다. 로케이션을 정하지 않고 적치할 때 씁니다.
- [로케이션 보기]는 이 창고의 로케이션 목록으로 갑니다.

<!-- 권한: master.warehouses.update -->
## 구역

수정 화면 아래 **구역** 표에서 이 창고의 구역(같은 방식으로 운영하는 로케이션 묶음)을 관리합니다. [저장]을 누르면 창고와 함께 저장됩니다.

- **구역코드**(영문 대문자·숫자 10자)는 로케이션 코드 앞자리로 쓰여 **저장 후 바꿀 수 없습니다.** 같은 창고 안에서 겹치면 안 됩니다.
- 구역 유형 목록은 **공통코드 › 구역 유형**에서 관리합니다. 피킹 순서는 구역 간 피킹 동선 순서입니다.
- **로케이션이 있는 구역은 지울 수 없고**, 재고가 있는 구역은 사용 중지할 수 없습니다.
- 로케이션 [일괄 생성]은 구역을 골라야 하므로, 먼저 구역을 만드세요. 시스템 기본 창고에는 구역이 없습니다.

<!-- 권한: master.warehouses.update -->
## 사용 중지 · 다시 사용

- 수정 화면 위의 버튼, 또는 목록에서 여러 개를 골라 처리합니다. 시스템 기본 창고는 목록에서 고를 수 없습니다.
- **재고가 남아 있으면** 사용 중지할 수 없습니다. 사용 중지한 창고의 로케이션은 입고·출고 대상에서 빠집니다.

<!-- 권한: master.warehouses.delete -->
## 삭제 · 되살리기

- **로케이션과 재고 기록이 하나도 없는 창고만** 지울 수 있습니다(잘못 만든 경우). 쓰인 창고는 사용 중지하세요.
- 상태 거르기의 **삭제됨**에서 골라 [되살리기]할 수 있습니다. 같은 센터에 같은 코드가 다시 생겼으면 되살릴 수 없습니다.
