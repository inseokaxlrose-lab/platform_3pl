---
title: 창고
summary: 센터 안의 보관 구역(창고)을 관리합니다. 입고대기 창고는 센터마다 자동으로 하나씩 있습니다.
---

센터 직원은 **소속 센터의 창고만** 보고 다룹니다.

## 목록 보기

- 위쪽 **센터 고르기**로 한 센터의 창고만 볼 수 있습니다. 정렬을 고르지 않으면 센터별로 묶어 보여줍니다.
- 창고 코드 옆 작은 글씨는 시스템 코드(`WH000001`)입니다. 검색칸에서 창고 코드·창고명·센터로 찾을 수 있습니다.

| 칸 | 뜻 |
| - | - |
| 유형 | **일반**: 사용자가 만든 보관 창고 / **입고대기**: 입고 확정 후 적치 전까지 물건이 머무는 곳 (센터마다 1개, 자동) |
| 보관 조건 | 상온 / 냉장 / 냉동 |
| 로케이션 수 | 창고 안의 보관 위치 개수 |

## [창고 등록]

1. **센터**를 고릅니다. 센터 상세 화면의 [창고 추가]로 들어오면 그 센터가 미리 골라져 있습니다. 센터는 등록 후 바꿀 수 없습니다.
2. 창고명과 **보관 조건**(상온·냉장·냉동)을 정합니다. 창고 코드는 비우면 시스템 코드로 채워집니다.
   - 창고 코드는 **같은 센터 안에서만** 겹치면 안 됩니다. 다른 센터에는 같은 코드가 있어도 됩니다.
   - `WH000001`처럼 시스템 코드 모양은 쓸 수 없습니다.
3. SAP·ERP와 연동한다면 **외부 코드**를 적습니다.

> 새로 만드는 창고는 항상 **일반** 유형입니다. 입고대기 창고는 센터 등록 때 자동으로만 만들어집니다. 사용 중지된 센터에는 창고를 추가할 수 없습니다.

## 수정 · 사용 중지

- 창고 코드·창고명·보관 조건·외부 코드를 고칠 수 있습니다. 센터·유형·시스템 코드는 바뀌지 않습니다.
- 창고는 지우지 않고 **사용 중지**합니다.
- **입고대기 창고**는 이름·보관 조건·외부 코드만 고칠 수 있습니다. 코드(`INBOUND`)를 바꾸거나 사용 중지할 수 없습니다 — 입고 확정된 물건이 들어갈 곳이 늘 있어야 하기 때문입니다.
