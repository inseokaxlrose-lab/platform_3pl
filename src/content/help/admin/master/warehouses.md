---

센터 직원은 **소속 센터의 창고만** 보고 다룹니다.

## 검색 · 목록 보기

- **기본 조건**: 검색어(창고 코드·시스템 코드·창고명·센터), 센터, 상태. **[상세 조건]**: 유형, 보관 조건(여러 개), 등록일.
- [조회] 또는 Enter로 적용합니다. 조건·페이지·정렬은 주소창에 남아서 상세 화면에 갔다 돌아와도 그대로입니다.
- 정렬을 고르지 않으면 센터별로 묶어 보여줍니다. 창고 코드·창고명은 가로로 스크롤해도 왼쪽에 고정됩니다. 행을 누르면 상세 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 유형 | **일반**: 사용자가 만든 보관 창고 / **입고대기**: 입고 확정 후 적치 전까지 물건이 머무는 곳 (센터마다 1개, 자동) |
| 보관 조건 | 상온 / 냉장 / 냉동 |
| 로케이션 수 | 창고 안의 보관 위치 개수 |

## [창고 등록]

1. **센터**를 고릅니다. 센터 상세 화면의 [창고 추가]로 들어오면 그 센터가 미리 골라져 있습니다. 센터는 등록 후 바꿀 수 없습니다.
2. 창고명과 **보관 조건**(상온·냉장·냉동)을 정합니다. 창고 코드는 비우면 시스템 코드로 채워집니다.
   - 창고 코드는 **같은 센터 안에서만** 겹치면 안 됩니다. 다른 센터에는 같은 코드가 있어도 됩니다.
   - `WH000001`처럼 시스템 코드 모양은 쓸 수 없습니다.
3. SAP·ERP와 연동한다면 저장한 뒤 **외부코드 매핑** 메뉴에서 외부 코드를 넣습니다.
4. 아래 막대의 [저장]을 누르면 만든 창고의 수정 화면으로 이동합니다.

> 새로 만드는 창고는 항상 **일반** 유형입니다. 입고대기 창고는 센터 등록 때 자동으로만 만들어집니다. 사용 중지된 센터에는 창고를 추가할 수 없습니다.

## 수정 · 사용 중지

- 창고 코드·창고명·보관 조건을 고칠 수 있습니다. 센터·유형·시스템 코드는 바뀌지 않습니다.
- 고치면 아래 막대에 **변경사항 있음**이 보이고, [저장]은 그 자리에서 저장, [취소]는 마지막 저장 내용으로 되돌립니다.
- 창고는 지우지 않고 **상태** 섹션의 [사용 중지]로 멈춥니다 (바로 처리). 목록에서 여러 개를 골라 [사용 중지]·[다시 사용]할 수도 있습니다.
- **로케이션** 섹션에서 [로케이션 관리]·[일괄 생성]으로 이 창고의 로케이션 화면에 갑니다.
- **입고대기 창고**는 이름·보관 조건만 고칠 수 있습니다. 코드(`INBOUND`)를 바꾸거나 사용 중지할 수 없습니다 — 입고 확정된 물건이 들어갈 곳이 늘 있어야 하기 때문입니다.
