title: 단위
summary: 수량·포장·중량·부피·길이·면적 단위를 관리합니다. 시스템 기본 단위는 모든 운영사가 함께 쓰고, 필요한 단위만 추가합니다.
---

단위는 **시스템 기본 단위**와 **운영사 추가 단위** 두 가지입니다.

- **시스템 기본 단위**(목록의 `기본` 배지): EA·BOX·KG 등 20개를 솔루션이 제공합니다. 모든 운영사가 같은 코드를 쓰며 **고치거나 지울 수 없습니다.** 다만 쓰지 않는 단위는 **우리 운영사에서만 사용 중지**할 수 있습니다.
- **운영사 추가 단위**: 시스템 단위에 없는 단위만 [단위 추가]로 만듭니다(예: 근, 케이스). 시스템 단위와 같은 코드는 쓸 수 없습니다.

![단위 목록](/help/admin/master/units/list.png)

① 검색 조건(단위 유형은 여러 개 고를 수 있음) · ② 목록(단위코드를 누르면 편집 화면) · ③ [단위 추가]

| 유형 | 예 | 환산 |
| - | - | - |
| 수량 | EA(개)·SET·PAIR | 없음 (EA가 기준) |
| 포장 | BOX·PACK·BAG·BDL·PLT | **품목마다** 입수량을 정함 (1 BOX = 24 EA) |
| 중량 · 부피 · 길이 · 면적 | KG·G·TON·LB / L·ML·CBM / M·CM·MM·INCH / M2 | 기준단위(KG·L·M·M2) × 환산계수 (1 G = 0.001 KG) |

> [!NOTE]
> 재고는 항상 품목의 **기본단위**로 저장합니다. BOX·PLT는 화면·출력에서 바꿔 보여 주는 단위이고, 박스에 몇 개가 들었는지는 품목에서 정합니다.

## 목록 보기

- 검색어(단위코드·단위명·영문명), 단위 유형(여러 개), 상태로 찾고, [상세 조건]에서 시스템 기본 단위만 / 추가 단위만 볼 수 있습니다.
- 정렬을 고르지 않으면 단위 유형 → 정렬순서 → 코드 순입니다. 건수가 적어 한 쪽에 100개까지 보입니다.

## [단위 추가]

![단위 추가 화면](/help/admin/master/units/new.png)

① 단위 유형 · ② 환산(중량·부피·길이·면적만) · ③ [저장]

1. **단위코드**(영문 대문자로 시작, 대문자·숫자·밑줄 1~10자)와 **단위명**을 넣습니다.
2. **단위 유형**을 고릅니다. 코드와 유형은 **등록 후 바꿀 수 없습니다.**
3. **소수 자리수**는 이 단위로 수량을 몇 자리까지 받을지입니다(EA 0, KG 3).
4. 중량·부피·길이·면적 단위면 **환산** 섹션에 환산계수를 넣습니다. 기준단위는 유형에 따라 자동으로 정해지고, 옆에 `1 근 = 0.6 KG`처럼 미리보기가 나옵니다.
5. [저장]하면 그 자리에 "등록했습니다."가 나옵니다. [계속 등록]으로 다음 단위를 넣거나 [등록한 항목 보기]로 편집 화면으로 갑니다.

> [!TIP]
> 포장 단위(BOX 등)를 고르면 환산 섹션이 없습니다. 박스·팔레트의 수량 환산은 **품목**에서 정합니다.

## 수정 · 사용 중지

- 운영사 추가 단위만 고칠 수 있습니다. 단위명·영문명·출력명·소수 자리수·정렬순서·환산계수·표준코드·설명·비고를 고칩니다.
- **소수 자리수를 줄일 때**: 이미 더 많은 소수 자리로 저장된 수량(재고·이력·ASN·검수·실사)이 있으면 막힙니다.
- **환산계수를 바꾸면** 편집 화면에 변경 기록(언제·누가·이전→이후)이 남고, 쓰는 곳이 있으면 저장 뒤 알려 줍니다.
- 쓰지 않을 단위는 목록에서 골라 **사용 중지**합니다. 새로 고르는 목록에서 빠지고, 이미 쓰는 데이터는 그대로 보입니다. 쓰는 품목이 있으면 경고가 나옵니다.

## 사용 중지 · 다시 사용

1. 목록에서 단위 줄의 체크박스를 고릅니다. 시스템 기본 단위도 고를 수 있습니다.
2. 표 위의 [사용 중지] 또는 [다시 사용]을 누릅니다.

- **시스템 기본 단위**는 **우리 운영사에서만** 사용 중지됩니다. 다른 운영사와 시스템 단위 자체는 그대로입니다(예: LB·INCH를 쓰지 않는 회사).
- 사용 중지한 단위는 단위 고르기(품목의 기본단위·환산단위 등)에서 빠지고, 이미 쓰는 데이터는 그대로 보입니다.

> [!WARNING]
> **EA·BOX·PLT**(기본 수량·라벨 단위)와 운영사의 **중량·길이 표시 단위**(로케이션 용량을 보여 주는 단위, 기본 KG·CM)는 사용 중지할 수 없습니다. 표시 단위로 쓰는 단위는 지울 수도 없습니다.

## 삭제

목록에서 골라 [삭제]합니다. **어디에서도 쓰지 않는 단위만** 지워집니다(품목 기본단위·환산단위, 운영사 표시 단위, ASN·검수 입력 단위). 쓰고 있으면 사용 중지하세요. 지운 코드는 새 단위에 다시 쓸 수 있습니다.

## 되살리기

상세 조건의 **상태**에서 **삭제됨**을 고르면 지운 단위만 보입니다. 골라서 [되살리기]를 누르면 지우기 전 상태(사용·사용 중지)로 목록에 다시 나타납니다.

- 그 사이 **같은 코드로 새로 만든** 단위가 있으면 되살릴 수 없습니다. 새것을 지우거나 코드를 바꾼 뒤 다시 시도하세요.
- 지울 때 함께 지운 **외부 코드**는 되살아나지 않습니다. 필요하면 **외부코드 매핑** 메뉴에서 다시 입력하세요.

## 연동 · 외부 코드

- **표준 단위코드**: 국제 표준(UN/ECE Rec.20) 코드입니다. 시스템 단위에는 미리 들어 있습니다(KG = KGM, BOX = XBX, PLT = XPX).
- 화주·외부 시스템의 단위 코드(예: SAP의 `PC`)는 **외부코드 매핑** 메뉴의 "단위" 대상에서 넣습니다. 시스템 기본 단위도 운영사마다 따로 매핑할 수 있습니다.
