---
title: 단위
summary: 품목의 기본단위·환산단위로 고를 단위(EA, KG, BOX, PLT 등)를 관리합니다.
---

| 종류 | 뜻 | 예 |
| - | - | - |
| **기본단위** | 재고를 세는 단위. 재고는 항상 이 단위로 저장됩니다 | EA(개), KG(킬로그램), L(리터) |
| **환산단위** | 기본단위를 묶은 단위. 품목마다 입수량을 정합니다 (예: 1 BOX = 24 EA) | BOX, CARTON, PLT |

- **소수 자리수**는 기본단위의 수량을 몇 자리까지 받을지입니다. EA는 0(정수만), KG는 3(1.250 kg). 환산단위는 해당 없음.
- **시스템 단위**(EA·BOX·PLT)는 프로그램이 직접 쓰는 단위(기본 단위, 라벨 단위)라 지우거나 사용 중지할 수 없고 종류도 바꿀 수 없습니다.
- 단위는 운영사 전체에서 함께 씁니다 (센터·화주사별로 나누지 않음).

## 목록 보기

- 검색어(코드·이름), 종류, 상태로 찾습니다. 정렬을 고르지 않으면 기본단위 → 환산단위, 정렬 순서대로 보여줍니다.
- 행을 누르면 수정 팝업이 열립니다. SAP·ERP 코드 컬럼은 [컬럼]에서 켤 수 있습니다.

<!-- 권한: master.units.create -->
## [단위 추가]

코드(영문 대문자로 시작, 대문자·숫자·밑줄 1~10자), 이름, 종류, 소수 자리수를 입력합니다. **코드는 등록 후 바꿀 수 없습니다** — 품목·재고에 이 글자가 저장되기 때문입니다. SAP·ERP와 연동하면 그쪽 단위 코드(예: EA ↔ `PC`, KG ↔ `KGM`)를 적습니다.

<!-- 권한: master.units.update -->
## 수정 · 사용 중지

- 이름·종류·소수 자리수·정렬 순서·외부 코드를 고칠 수 있습니다.
- 쓰지 않을 단위는 **사용 중지**합니다. 새로 고르는 목록에서 빠지고, 이미 쓰는 품목은 그대로입니다. 목록에서 여러 개를 골라 할 수도 있습니다.

<!-- 권한: master.units.delete -->
## 삭제

목록에서 골라 [삭제]합니다. **품목에서 쓰지 않는 단위만** 지워집니다 (시스템 단위 제외). 되돌릴 수 없습니다.
