---
title: 로케이션
summary: 창고 안의 보관 위치(예 A-01-02 = A구역 1열 2단)를 관리합니다. 여러 칸은 일괄 생성으로 한 번에 만듭니다.
---

센터 직원은 **소속 센터 창고의 로케이션만** 다룹니다. 로케이션 코드는 **등록 후 바꿀 수 없습니다** — 재고·적치 기록이 이 주소를 가리키기 때문입니다. 잘못 만들었다면 삭제(쓰인 적 없을 때) 또는 사용 중지하세요.

## 목록 보기

- 위쪽에서 **센터 → 창고 → 구역** 순서로 골라 볼 수 있습니다. 구역은 창고를 골랐을 때 고를 수 있습니다.
- 정렬을 고르지 않으면 센터 → 창고 → 코드 순서로 보여줍니다.
- 입고대기 창고의 `DEFAULT`는 "입고대기 기본"으로 표시되며, 입고 확정된 물건이 적치 전까지 머무는 자리입니다.

## 일괄 생성

1. [일괄 생성]을 누르고 **창고**를 고릅니다. 창고 상세 화면의 [일괄 생성]으로 들어오면 그 창고가 미리 골라져 있습니다.
2. 범위를 정합니다.

| 칸 | 예 | 결과 |
| - | - | - |
| 구역 | A ~ B | A, B |
| 열 (자릿수 2) | 1 ~ 10 | 01 ~ 10 |
| 단 (자릿수 2) | 1 ~ 5 | 01 ~ 05 |
| 구분자 | 하이픈 | `A-01-01` … `B-10-05` (100개) |

3. **[미리보기]**로 만들 개수와 처음·마지막 코드를 확인합니다. 이미 있는 코드는 건너뜁니다.
4. **[생성]**을 누릅니다. 미리보기를 한 뒤에만 누를 수 있고, 범위를 바꾸면 다시 미리보기를 해야 합니다.

> 한 번에 2,000개까지 만들 수 있습니다. 입고대기 창고·사용 중지된 창고에는 만들 수 없습니다. 같은 범위를 다시 실행해도 이미 있는 칸은 건너뛰므로 안전합니다.

## 한 칸 추가

[한 칸 추가]에서 창고와 코드(영문·숫자·하이픈 1~30자)를 입력합니다. 같은 창고 안에 같은 코드가 있으면 추가되지 않습니다.

<!-- 권한: master.locations.update -->
## 사용 중지 · 다시 사용

목록 왼쪽 체크박스로 여러 개를 고른 뒤 [사용 중지] / [다시 사용]을 누릅니다. 사용 중지한 로케이션에는 새로 적치할 수 없습니다. 입고대기 창고의 `DEFAULT`는 사용 중지할 수 없습니다.

<!-- 권한: master.locations.delete -->
## 삭제

여러 개를 골라 [삭제]합니다. **한 번도 쓰이지 않은 로케이션만** 삭제되며(일괄 생성 실수 정리용), 재고 기록이 있는 로케이션은 사용 중지해야 합니다. 삭제는 되돌릴 수 없습니다.
