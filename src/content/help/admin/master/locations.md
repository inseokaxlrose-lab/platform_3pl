title: 로케이션
summary: 재고가 놓이는 한 칸(예 A-01-02 = A구역 1열 2단)을 관리합니다. 여러 칸은 일괄 생성 또는 엑셀 업로드로 한 번에 만듭니다.
---

센터 직원은 **소속 센터의 로케이션만** 다룹니다. 로케이션 코드(영문·숫자·하이픈, 바코드·스캐너용)는 **같은 창고 안에서 겹치면 안 되고, 등록 후 바꿀 수 없습니다** — 라벨이 붙어 있고 재고·적치 기록이 이 주소를 가리키기 때문입니다. 바꿔야 하면 새로 만들고 기존 것은 사용 중지하세요.

- **구역**은 창고 화면의 **구역** 표에서 먼저 만듭니다 (예: A구역 랙 보관, P구역 피킹).
- 온도대·보세·위험물은 로케이션이 아니라 **창고 설정을 따릅니다.**

![로케이션 목록](/help/admin/master/locations/list.png)

① 검색 조건 · ② 목록(파란 글자를 누르면 상세) · ③ [엑셀 업로드]·[한 칸 추가]·[일괄 생성]

## 검색 · 목록 보기

- **기본 조건**: 로케이션 코드(**앞부분** 일치, 예: `A-01` → A-01로 시작), **코드 범위**(시작~끝, 예: `A-01-01` ~ `A-03`), **센터 → 창고 → 구역** 순서로 고르기. 센터를 바꾸면 창고·구역이, 창고를 바꾸면 구역이 비워집니다.
- **[상세 조건]**: 로케이션 유형(여러 개), 상태(사용·사용 중지·삭제됨), 열, 단, 다화주 혼적, 재고(빈 로케이션 / 재고 있음), 등록일.
- 기본 순서는 **센터 → 창고 정렬순서 → 구역 정렬순서 → 로케이션 코드**이고, 한 페이지 50건입니다.
- 코드 옆에 **기본** 배지(시스템 기본 로케이션)와 설명이 작게 보입니다. **출고 할당 가능**은 실제 적용값(로케이션이 비워 두면 창고 값)입니다.

## 일괄 생성

1. [일괄 생성]을 누르고 **센터 → 창고 → 구역**을 고릅니다. 목록에서 창고·구역을 골라 둔 채 누르면 미리 골라져 있습니다.
2. **범위**를 정합니다: 열 시작~끝·자릿수, 단 시작~끝·자릿수. 랙의 가로 칸이 있으면 **연 사용**을 켜고 연 범위도 넣습니다.
3. **코드 패턴**을 확인합니다. 기본은 `{ZONE}-{ROW}-{LEVEL}` (창고의 구분자가 "없음"이면 `{ZONE}{ROW}{LEVEL}`).

| 토큰 | 뜻 | 예 (구역 A, 열 1 자릿수 2, 단 2 자릿수 2) |
| - | - | - |
| `{ZONE}` | 구역코드 | A |
| `{ROW}` | 열 | 01 |
| `{BAY}` | 연 (연 사용일 때) | 03 |
| `{LEVEL}` | 단 | 02 |

   → `{ZONE}-{ROW}-{LEVEL}` = `A-01-02`, `{ZONE}-{ROW}-{BAY}-{LEVEL}` = `A-01-03-02`

4. **공통 속성**(로케이션 유형·용량·적치/피킹/할당 가능·혼적)을 정합니다. 만들 로케이션에 모두 같은 값이 들어갑니다.
5. **[미리보기]**로 만들 개수, 처음·마지막 코드 5개씩, 이미 있어 건너뛸 개수를 확인한 뒤 **[생성]**. 끝나면 "생성 n개 · 건너뜀 n개"와 **[생성된 로케이션 보기]**가 나옵니다.

> [!NOTE]
> 한 번에 5,000개까지. 이미 있는 코드는 덮어쓰지 않고 건너뛰므로 같은 범위를 다시 실행해도 안전합니다. 시스템 기본 창고·사용 중지된 창고에는 만들 수 없습니다.

## 한 칸 추가

[한 칸 추가] → 센터·창고·구역을 고르고 열·단을 넣으면 **코드를 자동으로 제안**합니다 (직접 고칠 수 있음). 섹션: 기본 정보 / 위치 구성 / 용량 / 운영 속성.

- **용량**은 운영사 단위(cm·inch, kg·lb)로 보입니다. 가로·세로·높이를 넣으면 **최대 부피(CBM)**가 계산됩니다 (직접 고칠 수 있음).
- **적치·피킹·출고 할당 가능**은 "창고 값 사용"이 기본입니다. 이 로케이션만 다르게 하려면 체크를 풀고 정하세요.
- **혼적**: 다품목·다로트는 기본 허용, **다화주는 기본 금지**(화주 간 재고 섞임 방지).

## 엑셀 업로드

[일괄 생성]의 범위로 만들기 어려운 창고는 엑셀로 한 줄씩 올립니다.

1. [엑셀 업로드] → **[양식 내려받기]**로 양식을 받습니다.
2. 한 줄에 로케이션 하나: **센터코드·창고코드·로케이션코드**(필수), 설명·구역(그 창고의 구역코드)·열·단·비고(선택).
3. **[파일 고르기]**로 올리면 줄마다 오류를 미리 보여 줍니다. 오류가 하나라도 있으면 파일 전체가 등록되지 않습니다.
4. 오류가 없으면 **[등록]**. 이미 있는 로케이션 코드는 건너뜁니다.

## 수정

목록에서 줄을 누르면 수정 창이 열립니다. 코드·창고는 바꿀 수 없고, 구역은 같은 창고의 구역으로만 옮길 수 있습니다. **시스템 기본 로케이션**(시스템 기본 창고의 `DEFAULT`)은 설명·비고만 고칠 수 있습니다.

<!-- 권한: master.locations.update -->
## 사용 중지 · 다시 사용

목록 왼쪽 체크박스로 여러 개를 고른 뒤 [사용 중지] / [다시 사용]. **재고가 남아 있으면 사용 중지할 수 없습니다.** 시스템 기본 로케이션은 고를 수 없습니다.

- 창고·구역이 사용 중지면 로케이션이 사용 중이어도 입고·출고 대상에서 빠집니다.

<!-- 권한: master.locations.delete -->
## 삭제 · 되살리기

- **재고 기록이 하나도 없는 로케이션만** 삭제됩니다(일괄 생성 실수 정리용). 쓰인 로케이션은 사용 중지하세요.
- 상태에서 **삭제됨**을 고르면 지운 로케이션만 보입니다. 골라서 [되살리기]하면 다시 나타납니다. 같은 창고에 같은 코드가 다시 생겼으면 되살릴 수 없습니다.

## 엑셀

[엑셀] → **조건에 맞는 전체** 또는 **선택 행만**. 보이는 컬럼·순서 그대로 `로케이션_날짜_시각.xlsx`로 내려받습니다 (최대 1만 건).
