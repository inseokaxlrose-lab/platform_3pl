title: 센터
summary: 물류센터를 등록·관리합니다. 등록하면 입고대기 창고와 기본 로케이션이 자동으로 만들어집니다.
---

센터 직원은 **소속 센터만** 보고 고칠 수 있습니다. 운영사 사용자는 모든 센터를 봅니다.

## 코드 3가지

| 코드 | 예 | 설명 |
| - | - | - |
| 시스템 코드 | `CT000001` | 저장할 때 자동으로 붙는 번호. **절대 바뀌지 않으며** 라벨·문서·이력에 쓰입니다 |
| 센터 코드 | `ICN` | 화면에서 쓰는 코드. 비우면 시스템 코드를 그대로 씁니다. 나중에 바꿀 수 있습니다 |
| 외부 코드 | SAP `1000` | SAP·ERP와 연동할 때 그쪽 시스템의 센터 코드 (**외부코드 매핑** 메뉴에서 넣음) |

## 검색

- **기본 조건**: 검색어(센터 코드·시스템 코드·센터명·주소), 상태(전체/사용/사용 중지), 대표 전화(일부만, 하이픈 넣어도 됨).
- **[상세 조건]**을 펼치면 센터장, 창고 보관 조건(그 조건의 창고가 있는 센터), 등록일 기간으로 더 거를 수 있습니다. 상세 조건을 쓰고 있으면 버튼에 개수가 보입니다.
- 조건을 고른 뒤 **[조회]** 또는 Enter. [초기화]는 조건을 모두 비웁니다.
- 조건·페이지·정렬은 주소창에 들어 있어서, **상세 화면에 갔다가 [목록]이나 뒤로 가기로 돌아와도 그대로**이고, 주소를 복사해 보내면 같은 결과가 보입니다.

## 목록 보기

- 행을 누르거나 센터 코드를 누르면 상세 화면으로 갑니다. 센터 코드·센터명은 가로로 스크롤해도 왼쪽에 고정됩니다.
- **창고 수**에는 자동으로 만들어진 입고대기 창고도 포함됩니다.
- [컬럼]에서 보일 컬럼·순서를 바꾸고, 제목 칸 오른쪽 끝을 끌어 너비를 바꿉니다. 시스템 코드·센터장 연락처·수정일시는 처음에 숨겨져 있습니다. 설정은 사용자별로 저장됩니다.

## 여러 센터 사용 중지 · 다시 사용

목록 왼쪽 체크박스로 고른 뒤 [사용 중지] / [다시 사용]을 누르고, 대상 건수를 확인합니다. 운영사 사용자만 할 수 있습니다. 전체 선택은 현재 페이지 기준입니다.

<!-- 권한: master.centers.create -->
## [센터 등록]

1. 센터명을 입력합니다. 센터 코드는 비워 두면 시스템 코드로 채워집니다.
   - 센터 코드: 영문·숫자·하이픈·밑줄 2~20자, 소문자는 대문자로 바뀝니다.
   - `CT000001`처럼 시스템 코드 모양은 쓸 수 없습니다.
2. 연락처·주소([주소 검색])를 입력합니다. 전화번호는 숫자만 쳐도 하이픈이 자동으로 붙습니다.
3. 아래 막대의 [저장]을 누르면 **입고대기 창고**(`INBOUND`)와 그 안의 **기본 로케이션**(`DEFAULT`)이 함께 만들어지고, 만든 센터의 수정 화면으로 이동합니다. 입고대기 창고는 입고 확정된 물건이 적치 전까지 머무는 곳입니다.

> 센터 등록은 운영사 사용자만 할 수 있습니다.

<!-- 권한: master.centers.update -->
## 수정

- 센터 코드·센터명·연락처·주소를 고칠 수 있습니다. 시스템 코드는 바뀌지 않습니다.
- 고치면 아래 막대에 **변경사항 있음**이 보입니다. [저장]은 그 자리에서 저장하고, [취소]는 마지막 저장 내용으로 되돌립니다. 저장하지 않고 다른 메뉴로 가려 하면 확인 창이 뜹니다.
- 맨 아래 **창고** 섹션에서 이 센터의 창고를 확인합니다. [창고 추가]를 누르면 이 센터가 미리 골라진 창고 등록 화면으로 갑니다.
- 제목 오른쪽 [목록]은 마지막으로 본 목록(검색 조건 그대로)으로 돌아갑니다.

<!-- 권한: master.centers.update -->
## 사용 중지

- 센터는 지우지 않고 **상태** 섹션의 [사용 중지]로 멈춥니다 (입고·재고 기록 보호). 저장 막대와 상관없이 바로 처리됩니다.
- 사용 중지하면 그 센터 소속 직원은 이 센터의 데이터를 볼 수 없습니다. [다시 사용]으로 되돌릴 수 있습니다.
- 사용 중지는 운영사 사용자만 할 수 있습니다.
