---
title: 센터
summary: 물류센터를 등록·관리합니다. 등록하면 입고·출고·반품 대기 창고와 기본 로케이션이 자동으로 만들어집니다.
---

센터 직원은 **소속 센터만** 보고 고칠 수 있습니다. 운영사 사용자는 모든 센터를 봅니다.

## 코드 3가지

| 코드 | 예 | 설명 |
| - | - | - |
| 센터코드 | `ICN01` | 화면·라벨·문서에서 쓰는 코드. **필수**이고 등록 후에는 바꿀 수 없습니다 |
| 사용자 정의 코드 | `WH-01` | 운영사·화주 시스템에서 이 센터를 부르는 코드(선택). 언제든 고칠 수 있고, 운영사 안에서 겹칠 수 없습니다 |
| 외부 코드 | SAP `1000` | SAP·ERP와 연동할 때 그쪽 시스템의 센터 코드 (**외부코드 매핑** 메뉴에서 넣음) |

## 운영 상태

| 상태 | 뜻 | 할 수 있는 일 |
| - | - | - |
| 준비중 | 새로 등록한 센터 | 창고·로케이션·권역 배정·이용 화주사를 준비합니다. 입고 등 새 업무는 받지 않습니다 |
| 운영중 | 정상 운영 | 모든 업무 |
| 일시중지 | 잠시 멈춤 (점검·공사 등) | 새 업무·설정 추가를 막습니다. 소속 직원은 계속 데이터를 봅니다 |
| 폐쇄 | 운영 종료 | 소속 직원의 데이터 범위에서 빠지고, 센터 정보는 읽기 전용이 됩니다 |

## 검색

- **기본 조건**: 검색어(센터코드·사용자 정의 코드·센터명·약칭), 운영 상태(여러 개), 센터 유형(여러 개).
- **[상세 조건]**: 지역(예: 경기, 이천), 취급 온도대, 보세 여부, 등록일 기간.
- 조건을 고른 뒤 **[조회]** 또는 Enter. [초기화]는 조건을 모두 비웁니다.
- 조건·페이지·정렬은 주소창에 들어 있어서, **상세 화면에 갔다가 [목록]이나 뒤로 가기로 돌아와도 그대로**입니다.

## 목록 보기

- 기본 순서는 **정렬순서 → 센터코드**입니다. 정렬순서는 센터 화면의 "정렬순서" 칸(작을수록 위)으로 정합니다.
- **대표 담당자**는 담당자 중 대표로 정한 사람입니다. **로케이션 수**는 보관 창고의 로케이션만 셉니다(대기 창고 제외).
- [컬럼]에서 보일 컬럼·순서·너비를 바꿀 수 있습니다. 정렬순서·수정일시는 처음에 숨겨져 있습니다.

## [센터 등록]

![센터 등록 화면](/help/admin/master/centers/new.png)

① 섹션 목차(누르면 그 칸으로) · ② 입력 칸 · ③ [저장] (바꾼 것이 있을 때 켜짐)

1. **센터코드**(영문 대문자·숫자, 소문자는 대문자로)와 **센터명**을 입력합니다.
2. **주소**는 필수입니다(택배 집하·배차 기준). [주소 검색]으로 고르면 지역·지번주소도 자동으로 채워집니다.
3. 시설 정보(면적·도크 수·취급 온도대·보세), 운영 설정(운영 시간·요일·입고/출고 마감), 담당자를 필요한 만큼 넣습니다.
4. [저장]하면 **준비중** 상태로 만들어지고, **입고대기·출고대기·반품대기 창고**와 각 창고의 `DEFAULT` 로케이션이 함께 생깁니다. 이 세 로케이션이 기본 입고·출고·반품 로케이션이 됩니다.
5. 저장하면 그 자리에 "등록했습니다."가 나오고 입력 칸이 잠깁니다. [계속 등록]을 누르면 빈 양식으로 다음 센터를 이어서 넣고, [등록한 항목 보기]를 누르면 수정 화면에서 기본 로케이션 등을 이어서 정합니다.

> [!NOTE]
> 센터 등록은 운영사 사용자만 할 수 있습니다. 요금제의 센터 수 한도를 넘으면 등록할 수 없습니다.

## 수정

- 센터코드를 뺀 모든 칸을 고칠 수 있습니다. [저장]은 그 자리에서 저장하고, [취소]는 마지막 저장 내용으로 되돌립니다.
- **출고 마감**은 기본으로 **운영사 값**을 따릅니다. "운영사 값 사용"을 풀면 이 센터만의 시각을 정할 수 있습니다.
- **기본 입고·출고·반품 로케이션**은 이 센터의 사용 중인 로케이션에서 고릅니다. 기본 입고 로케이션은 필수입니다.
- **담당자**는 최대 10명, 연락처·이메일 중 하나는 필수, 대표 1명을 정합니다. 부서·직책은 선택이고, **알림**은 그 담당자가 알림 메일을 받을지입니다(기본 받음). 담당 업무 목록은 **공통코드 › 센터 담당 업무**에서 관리합니다.
- 아래 **창고** 섹션에서 이 센터의 창고를 보고, 준비중·운영중 센터면 [창고 추가]를 할 수 있습니다. **권역설정** 섹션에는 이 센터에 배정된 우편번호 수(온도대별)가 나오고, [권역설정으로]를 누르면 권역설정 화면으로 갑니다.
- [창고 보기]·[로케이션 보기]는 이 센터의 창고·로케이션 목록으로 갑니다.
- **취급 온도대**는 하나 이상 필수입니다. 창고 온도대는 이 안에서 고르며, 창고가 쓰고 있는 온도대는 뺄 수 없습니다.

## [상태 변경]

- 제목 아래 상태 배지 옆, 오른쪽 위 [상태 변경]에서 바꿀 상태를 고릅니다. 저장 막대와 상관없이 바로 처리됩니다.
- **일시중지·폐쇄**는 사유가 필수이고, **폐쇄**는 운영 종료일도 넣어야 합니다.
- 재고가 남아 있거나 끝나지 않은 입고(ASN)가 있으면 폐쇄할 수 없습니다. 재고를 옮기고 입고를 마감한 뒤 다시 시도하세요.
- 상태 변경은 운영사 사용자만 할 수 있습니다.

<!-- 권한: master.centers.delete -->
## [삭제]

- **한 번도 쓰이지 않은 센터만** 지울 수 있습니다(잘못 등록한 경우). 대기 창고와 기본 로케이션도 함께 정리됩니다.
- 보관 창고·재고·입고·권역설정 배정·이용 화주사·소속 사용자 중 하나라도 있으면 지울 수 없습니다. 이때는 상태를 **폐쇄**로 바꾸세요.
