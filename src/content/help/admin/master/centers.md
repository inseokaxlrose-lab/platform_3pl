title: 센터
summary: 물류센터를 등록·관리합니다. 등록하면 입고대기 창고와 기본 로케이션이 자동으로 만들어집니다.
---

센터 직원은 **소속 센터만** 보고 고칠 수 있습니다. 운영사 사용자는 모든 센터를 봅니다.

## 코드 3가지

| 코드 | 예 | 설명 |
| - | - | - |
| 시스템 코드 | `CT000001` | 저장할 때 자동으로 붙는 번호. **절대 바뀌지 않으며** 라벨·문서·이력에 쓰입니다 |
| 센터 코드 | `ICN` | 화면에서 쓰는 코드. 비우면 시스템 코드를 그대로 씁니다. 나중에 바꿀 수 있습니다 |
| 외부 코드 | SAP `1000` | SAP·ERP와 연동할 때 그쪽 시스템의 센터 코드 |

- 목록 검색칸에서 **센터 코드와 시스템 코드 모두** 찾을 수 있습니다.

## 목록 보기

- 센터 코드를 누르면 상세 화면으로 갑니다. 코드 옆 작은 글씨는 시스템 코드입니다.
- **창고 수**에는 자동으로 만들어진 입고대기 창고도 포함됩니다.

## [센터 등록]

1. 센터명을 입력합니다. 센터 코드는 비워 두면 시스템 코드로 채워집니다.
   - 센터 코드: 영문·숫자·하이픈·밑줄 2~20자, 소문자는 대문자로 바뀝니다.
   - `CT000001`처럼 시스템 코드 모양은 쓸 수 없습니다.
2. 연락처·주소([주소 검색])를 입력합니다.
3. SAP·ERP와 연동한다면 **외부 코드**에 그쪽 코드를 적습니다. 다른 센터가 이미 쓰는 외부 코드는 저장되지 않습니다.
4. 저장하면 **입고대기 창고**(`INBOUND`)와 그 안의 **기본 로케이션**(`DEFAULT`)이 함께 만들어집니다. 입고 확정된 물건이 적치 전까지 머무는 곳입니다.

> 센터 등록은 운영사 사용자만 할 수 있습니다.

<!-- 권한: master.centers.update -->
## 수정

- 센터 코드·센터명·연락처·주소·외부 코드를 고칠 수 있습니다. 시스템 코드는 바뀌지 않습니다.
- 오른쪽 **창고** 목록에서 이 센터의 창고를 확인합니다. 창고 추가·수정은 창고 메뉴에서 합니다.

## 사용 중지

- 센터는 지우지 않고 **사용 중지**합니다 (입고·재고 기록 보호).
- 사용 중지하면 그 센터 소속 직원은 이 센터의 데이터를 볼 수 없습니다. [다시 사용]으로 되돌릴 수 있습니다.
- 사용 중지는 운영사 사용자만 할 수 있습니다.
