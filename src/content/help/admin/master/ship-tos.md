납품처는 거래처가 실제로 물건을 받는 곳입니다. 이 화면은 **배송센터를 정하지 못한 납품처**(확인 필요)와 **권역설정과 다른 센터로 지정된 납품처**(권역 불일치)를 모아 처리하는 곳입니다. 납품처 자체를 추가·수정하려면 납품처코드를 눌러 그 거래처 화면으로 가세요. 권한은 거래처 메뉴와 같습니다.

![납품처 목록](/help/admin/master/ship-tos/list.png)

① 빠른 보기·검색 조건 · ② 목록(코드를 누르면 거래처 화면의 납품처로) · ③ 일괄 처리 버튼

## 검색 · 목록 보기

- **빠른 보기**: [확인 필요] [권역 불일치] [정제 등급 C 이하]를 누르면 손봐야 할 납품처만 나옵니다.
- 검색어(거래처·납품처 코드·명), 화주사, 배송센터, 지정 상태로 찾습니다. 지정 구분·확인 필요 사유·권역 불일치·정제 등급·시군구·등록 경로·납품처 상태는 [상세 조건]에 있습니다.

| 칸 | 뜻 |
| - | - |
| 배송센터 | 이 납품처로 배송하는 센터 |
| 권역 기준 센터 | 주소로 권역설정에서 찾은 센터. 배송센터와 다르면 **권역 불일치**(⚠) |
| 지정 구분 | 권역 자동 / 수동(화면에서 고름) / 연동(화주가 보냄). 권역설정이 바뀌면 **권역 자동**만 따라 바뀝니다 |
| 확인 필요 사유 | 권역설정에 배정되지 않은 지역 / 여러 센터가 섞인 지역 / 주소 정제 실패 / 화주 이용 센터가 아님 / 센터 일시중지·폐쇄 |
| 정제 등급 | A·B 정확, C·D 지역까지만 추정, F 실패 |

## 일괄 처리

목록에서 납품처를 고른 뒤 누릅니다. 처리 결과(지정 완료·확인 필요·건너뜀 건수)는 버튼 옆에 나옵니다.

1. **[배송센터 일괄 지정]**: 센터를 골라 지정합니다(지정 구분 **수동**). 그 화주가 이용하지 않는 센터인 납품처는 건너뛰고 결과에 코드가 나옵니다.
2. **[권역 기준으로 재지정]**: 수동·연동 지정도 버리고, 주소로 권역설정을 찾아 **권역 자동**으로 정합니다. 못 정하면 확인 필요로 남습니다.
3. **[재정제]**: 저장해 둔 주소 정제 결과를 쓰지 않고 다시 찾습니다. 권역 자동 납품처는 센터도 다시 정하고, 수동·연동 지정은 센터를 그대로 두고 권역 불일치만 새로 봅니다.

> [!TIP]
> 확인 필요가 **권역설정에 배정되지 않은 지역**이면, 권역설정에서 그 지역을 배정하는 편이 빠릅니다. 저장하면 그 지역 납품처가 자동으로 다시 정해집니다.

> [!WARNING]
> 일괄 처리하면 그 거래처 화면을 열어 두었던 사람은 저장할 때 "다른 사람이 먼저 고쳤습니다"로 막힙니다. 화면을 새로 열어 다시 고치세요.
