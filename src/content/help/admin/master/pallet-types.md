---
title: 팔레트 종류
summary: 품목의 PLT(팔레트) 수량·높이·중량을 계산하는 팔레트 규격을 관리합니다. 시스템 기본 T11·T12가 있고, 필요한 종류만 추가합니다.
---

품목 화면에서 **팔레트 종류 + 단당 박스 수(TI) × 단수(HI)**를 넣으면, 여기 규격으로 PLT 하나의 수량·높이·중량·CBM을 계산합니다.

![팔레트 종류 목록](/help/admin/master/pallet-types/list.png)

① 검색 조건 · ② 목록(코드를 누르면 편집 화면) · ③ [팔레트 종류 등록]

| 구분 | 뜻 |
| - | - |
| 시스템 기본 | 솔루션이 제공하는 T11(110×110cm)·T12(120×100cm). 모든 운영사가 함께 쓰며 직접 고치거나 지울 수 없습니다 |
| 운영사 | 우리 운영사가 추가한 종류 |
| 덮어씀 | 시스템 기본과 같은 코드로 등록해 **우리 운영사 값**으로 바꾼 종류. 지우면 시스템 값으로 돌아갑니다 |

> [!NOTE]
> 규격은 cm·kg입니다. **권장 최대 적재 높이**는 팔레트를 포함한 높이이고, 품목의 계산 높이가 이것을 넘으면 품목 저장 때 경고가 나옵니다(저장은 됩니다).

## 목록 보기

- 검색어(코드·이름)와 상태로 찾습니다. 목록은 우리 운영사에서 쓰는 종류만, 코드마다 하나씩 보입니다.
- **운영사 기본** 배지가 붙은 종류가 품목 등록 때 처음 골라져 있는 팔레트입니다.

## [팔레트 종류 등록]

1. **코드**(영문 대문자·숫자·하이픈·밑줄 20자 이하)와 **이름**을 넣습니다. 코드는 등록 후 바꿀 수 없습니다.
2. **가로·세로·높이**(팔레트 자체), **자체 중량**을 넣습니다.
3. 필요하면 **권장 최대 적재 높이**와 **최대 적재 중량**을 넣습니다. 비우면 그 항목은 경고하지 않습니다.
4. [저장]합니다.

> [!TIP]
> T11 규격을 우리 센터에 맞게 바꾸려면, 시스템 T11 편집 화면의 [이 운영사 값으로 덮어쓰기]를 누르거나 코드 `T11`로 새로 등록합니다. 목록 구분이 **덮어씀**으로 바뀝니다.

<!-- 권한: master.units.update -->
## 수정 · [운영사 기본으로]

- 우리 운영사가 추가했거나 덮어쓴 종류만 고칠 수 있습니다. 바꾼 규격은 **품목을 다시 저장할 때** PLT 계산에 반영됩니다.
- 목록에서 한 줄을 고르고 [운영사 기본으로]를 누르면 품목 등록 때 처음 골라지는 팔레트가 바뀝니다. 사용 중지한 종류는 기본으로 정할 수 없습니다.

<!-- 권한: master.units.delete -->
## 삭제

- 우리 운영사가 추가했거나 덮어쓴 종류만 지울 수 있습니다. 덮어쓴 종류를 지우면 시스템 기본 값으로 돌아갑니다.
- **운영사 기본**으로 정한 운영사 전용 종류는 지울 수 없습니다. 먼저 다른 종류를 기본으로 정하세요.
