이 화면은 **운영사 사용자만** 쓸 수 있습니다. 센터 직원·화주사 사용자는 권한그룹을 받아도 이 메뉴를 쓸 수 없습니다 (권한을 스스로 올리는 것을 막기 위해서).

## 목록 보기

- 검색칸에 **아이디·이름·이메일** 일부를 넣으면 찾습니다.
- 제목을 누르면 정렬, [컬럼]에서 보이는 칸과 순서를 바꿀 수 있습니다. 바꾼 모양은 내 계정에 저장됩니다.
- 아이디를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 유형 | 운영사 / 센터 / 화주사 |
| 소속 | 센터 직원은 소속 센터, 화주사 사용자는 소속 화주사 |
| 상태 | 사용 / 사용 중지 |

## [사용자 등록]

1. 아이디·이름·유형·비밀번호를 입력합니다.
   - 아이디: 영문·숫자·점·밑줄·하이픈 3~30자, 대소문자를 구분하지 않습니다.
   - 비밀번호: 8자 이상.
2. 유형에 맞게 **소속**을 고릅니다.
   - 센터 직원: 소속 센터 1개 이상 (볼 수 있는 데이터가 이 센터로 제한됩니다)
   - 화주사 사용자: 소속 화주사 1개
   - 운영사: 소속 없음 (전체 데이터)
3. **권한그룹**을 고릅니다. 유형에 맞는 영역의 그룹만 나옵니다.

> 아이디와 유형은 등록한 뒤에 바꿀 수 없습니다. 잘못 만들었다면 사용 중지하고 새로 만드세요.

<!-- 권한: system.users.update -->
## 정보 수정

이름·이메일·소속·권한그룹을 바꿀 수 있습니다. 바꾼 권한은 그 사용자의 **다음 화면 이동부터** 적용됩니다.

<!-- 권한: system.users.update -->
## 개별 권한 (추가·제외)

권한그룹과 다르게 줄 권한만 정합니다. 칸을 누를 때마다 **그룹대로 → ＋추가 → −제외** 순서로 바뀝니다.

- **제외가 그룹보다 우선**합니다.
- 메뉴의 **조회**를 빼면 그 메뉴의 버튼 권한도 모두 사라집니다.
- 아래 **최종 권한 미리보기**에서 결과를 확인한 뒤 [개별 권한 저장]을 누르세요.
- 자기 자신의 개별 권한은 바꿀 수 없습니다. 다른 관리자에게 요청하세요.

<!-- 권한: system.users.update -->
## 사용 중지 · 비밀번호 초기화

- **사용 중지**: 즉시 로그아웃되고 로그인할 수 없습니다. 계정은 지우지 않고 기록을 남깁니다. [다시 사용]으로 되돌릴 수 있습니다. 자기 자신은 사용 중지할 수 없습니다.
- **비밀번호 초기화**: 새 비밀번호를 정하면 기존 로그인이 모두 끊깁니다. 새 비밀번호는 사용자에게 안전한 방법으로 따로 알려 주세요.
