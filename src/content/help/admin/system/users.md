이 화면은 **운영사 사용자만** 쓸 수 있습니다. 센터 직원·화주사 사용자는 권한그룹을 받아도 이 메뉴를 쓸 수 없습니다 (권한을 스스로 올리는 것을 막기 위해서).

## 목록 보기

- **기본 조건**: 검색어(아이디·이름·이메일), 유형, 상태. **[상세 조건]**: 권한그룹, 소속 센터, 소속 화주사, 등록일.
- [조회] 또는 Enter로 적용합니다. 조건·페이지·정렬은 주소창에 남아 수정 화면에 갔다 [목록]으로 돌아와도 그대로입니다.
- 제목을 누르면 정렬, [컬럼]에서 보이는 칸과 순서를 바꿀 수 있습니다(이메일은 처음에 숨김). 바꾼 모양은 내 계정에 저장됩니다.
- 행이나 아이디를 누르면 수정 화면으로 갑니다.

| 칸 | 뜻 |
| - | - |
| 유형 | 운영사 / 센터 / 화주사 |
| 소속 | 센터 직원은 소속 센터, 화주사 사용자는 소속 화주사 |
| 상태 | 사용 / 사용 중지 |

## [사용자 등록]

1. 아이디·이름·유형을 입력하고 **처음 비밀번호** 방식을 고릅니다.
   - 아이디: 영문·숫자·점·밑줄·하이픈 3~30자, 대소문자를 구분하지 않습니다.
   - 처음 비밀번호: **자동 생성**(기본)이면 저장할 때 시스템이 임시 비밀번호를 만들어 한 번 보여 줍니다. **직접 입력**이면 영문·숫자를 모두 넣어 8자 이상, 아이디와 같으면 안 됩니다.
2. 유형에 맞게 **소속**을 고릅니다.
   - 센터 직원: 소속 센터 1개 이상 (볼 수 있는 데이터가 이 센터로 제한됩니다)
   - 화주사 사용자: 소속 화주사 1개
   - 운영사: 소속 없음 (전체 데이터)
3. **권한그룹**을 고릅니다. 유형에 맞는 영역의 그룹만 나옵니다.
4. [저장]하면 그 자리에 "등록했습니다."가 나오고 입력 칸이 잠깁니다. [계속 등록]을 누르면 빈 양식으로 다음 사용자를 이어서 넣고, [등록한 항목 보기]를 누르면 수정 화면으로 갑니다. 빠진 칸이 있으면 저장되지 않고 첫 번째 오류 칸으로 이동합니다.

> [!NOTE]
> 처음 비밀번호는 **임시 비밀번호**입니다. 사용자가 처음 로그인하면 새 비밀번호로 바꾸기 전에는 다른 화면을 쓸 수 없습니다. 자동 생성한 비밀번호는 창을 닫으면 다시 볼 수 없으니 [복사]해 두고 사용자에게 안전하게 전달하세요.

> [!WARNING]
> 아이디와 유형은 등록한 뒤에 바꿀 수 없습니다. 잘못 만들었다면 사용 중지하고 새로 만드세요.

## 정보 수정

이름·이메일·소속·권한그룹을 바꾸고 위쪽 헤더의 [저장]을 누릅니다. [취소]는 마지막 저장 내용으로 되돌립니다. 바꾼 권한은 그 사용자의 **다음 화면 이동부터** 적용됩니다.

아래쪽 **개별 권한**·**계정 관리** 섹션은 저장 막대와 상관없이 각자의 버튼으로 바로 처리됩니다.

<!-- 권한: system.users.update -->
## 개별 권한 (추가·제외)

권한그룹과 다르게 줄 권한만 정합니다. 칸을 누를 때마다 **그룹대로 → ＋추가 → −제외** 순서로 바뀝니다.

- **제외가 그룹보다 우선**합니다.
- 메뉴의 **조회**를 빼면 그 메뉴의 버튼 권한도 모두 사라집니다.
- 아래 **최종 권한 미리보기**에서 결과를 확인한 뒤 [개별 권한 저장]을 누르세요.
- 자기 자신의 개별 권한은 바꿀 수 없습니다. 다른 관리자에게 요청하세요.

## 사용 중지 · 비밀번호 초기화

- 목록에서 여러 명을 골라 [사용 중지]·[다시 사용]할 수도 있습니다 (대상 인원 확인).
- **사용 중지**: 즉시 로그아웃되고 로그인할 수 없습니다. 계정은 지우지 않고 기록을 남깁니다. [다시 사용]으로 되돌릴 수 있습니다. 자기 자신은 사용 중지할 수 없습니다.
- **비밀번호 초기화**: 등록 때처럼 **자동 생성**(기본) 또는 **직접 입력**으로 임시 비밀번호를 정합니다. 기존 로그인이 모두 끊기고, 사용자는 다음 로그인 때 새 비밀번호로 바꿔야 합니다. 임시 비밀번호는 사용자에게 안전한 방법으로 따로 알려 주세요.

> [!TIP]
> 사용자는 언제든 화면 오른쪽 위 이름 → [비밀번호 변경]에서 자기 비밀번호를 바꿀 수 있습니다(현재 비밀번호 확인). 바꾸면 다른 기기의 로그인은 끊깁니다.
