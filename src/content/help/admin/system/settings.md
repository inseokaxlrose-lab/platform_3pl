---
title: 운영 설정
summary: 우리 운영사에만 적용되는 설정입니다. 칸을 비우면 그 기능을 쓰지 않습니다.
---

여러 화면에 공통으로 쓰이는 값을 운영사마다 정합니다. 바꾸면 저장한 뒤부터 바로 적용됩니다.

![운영 설정](/help/admin/system/settings/main.png)

① 재고 설정 · ② API 연동 설정 · ③ [저장]

| 설정 | 쓰는 곳 |
| - | - |
| 기본 임박 알림 일수 | **재고 조회**의 유통기한 임박 표시. 품목에 임박 기준 일수가 없으면 이 일수를 씁니다(품목에 정해져 있으면 품목 값). 비우면 기준이 없는 품목은 만료만 표시합니다. |
| API 키 최대 유효기간 | **API 키** 발급. 정하면 만료일이 필수가 되고, 오늘부터 이 일수 안으로만 정할 수 있습니다. 비우면 제한이 없습니다. |

<!-- 권한: system.settings.update -->
## [저장]

1. 바꿀 칸에 일수를 넣거나, 쓰지 않으려면 칸을 비웁니다 (1~3650일).
2. [저장]합니다. 화면 위에 마지막으로 바꾼 사람과 시각이 보입니다.

> [!NOTE]
> API 1회 최대 건수·요청 로그 보관 기간·비밀번호 규칙처럼 모든 운영사에 같은 값(법·성능 기준)은 여기서 바꾸지 않습니다.
