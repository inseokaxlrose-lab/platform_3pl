---
title: 권한그룹
summary: 직무별로 메뉴·버튼 권한을 묶어 두고, 사용자에게 그룹으로 배정합니다.
---

사용자의 최종 권한은 **받은 권한그룹들의 권한을 모두 합친 것**에, 사용자별 추가·제외를 더한 결과입니다 (사용자 화면의 "개별 권한").

## 검색 · 목록 보기

- 검색어(이름·설명)와 **영역**으로 찾고, [조회] 또는 Enter로 적용합니다. 조건은 주소창에 남아 수정 화면에 갔다 [목록]으로 돌아와도 그대로입니다.

| 칸 | 뜻 |
| - | - |
| 영역 | 운영사 화면용 / 화주 포털용 |
| 권한 수 | 그룹에 담긴 권한 개수 |
| 사용자 수 | 이 그룹을 받은 사용자 수 |

- 행이나 이름을 누르면 수정 화면으로 갑니다.
- `슈퍼 관리자`·`센터 운영자`·`센터 작업자`·`화주사 사용자`는 개발용 기본 그룹입니다. 시드를 다시 실행하면 원래 권한으로 돌아가므로, 회사에 맞게 바꿀 때는 새 그룹을 만들어 쓰세요.

<!-- 권한: system.roles.create -->
## [권한그룹 등록]

1. **이름**(겹치면 안 됨)과 **영역**을 정합니다.
   - 운영사 화면용: 운영사·센터 직원에게 배정
   - 화주 포털용: 화주사 사용자에게 배정
2. 권한 표에서 메뉴·버튼을 체크합니다.
   - 버튼 권한(등록·수정 등)을 체크하면 **조회도 자동으로** 체크됩니다.
   - 조회를 풀면 그 메뉴의 줄 전체가 풀립니다.
   - 묶음 이름 옆 체크로 기준정보·입고 같은 묶음 전체를 한 번에 고를 수 있습니다.
3. [저장]하면 그 자리에 "등록했습니다."가 나오고 입력 칸이 잠깁니다. [계속 등록]을 누르면 빈 양식으로 다음 그룹을 이어서 넣고, [등록한 항목 보기]를 누르면 수정 화면으로 갑니다.

> 영역을 바꾸면 다른 영역의 권한은 의미가 없어서 체크가 모두 비워집니다.

<!-- 권한: system.roles.update -->
## 수정

이름·설명·권한을 바꾸고 위쪽 헤더의 [저장]을 누릅니다. [취소]는 마지막 저장 내용으로 되돌립니다. 이 그룹을 받은 사용자 모두에게 **다음 화면 이동부터** 적용됩니다.

<!-- 권한: system.roles.delete -->
## 삭제

수정 화면 맨 아래 **삭제** 섹션의 [권한그룹 삭제]로 지웁니다. 사용자가 한 명이라도 이 그룹을 받고 있으면 지울 수 없습니다. 먼저 사용자 화면에서 그룹을 빼 주세요. 지운 그룹의 이름은 새 그룹에 다시 쓸 수 있습니다.

<!-- 권한: system.roles.delete -->
## 되살리기

목록 조건의 **상태**에서 **삭제됨**을 고르면 지운 권한그룹만 보입니다. 골라서 [되살리기]를 누르면 지우기 전 권한 그대로 돌아옵니다. 그 사이 **같은 이름으로 새로 만든** 그룹이 있으면 되살릴 수 없습니다.
