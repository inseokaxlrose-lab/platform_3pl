---
title: 권한그룹
summary: 직무별로 메뉴·버튼 권한을 묶어 두고, 사용자에게 그룹으로 배정합니다.
---

사용자의 최종 권한은 **받은 권한그룹들의 권한을 모두 합친 것**에, 사용자별 추가·제외를 더한 결과입니다 (사용자 화면의 "개별 권한").

## 목록 보기

| 칸 | 뜻 |
| - | - |
| 영역 | 운영사 화면용 / 화주 포털용 |
| 권한 수 | 그룹에 담긴 권한 개수 |
| 사용자 수 | 이 그룹을 받은 사용자 수 |

- 이름을 누르면 수정 화면으로 갑니다.
- `슈퍼 관리자`·`센터 운영자`·`센터 작업자`·`화주사 사용자`는 개발용 기본 그룹입니다. 시드를 다시 실행하면 원래 권한으로 돌아가므로, 회사에 맞게 바꿀 때는 새 그룹을 만들어 쓰세요.

<!-- 권한: system.roles.create -->
## [권한그룹 등록]

1. **이름**(겹치면 안 됨)과 **영역**을 정합니다.
   - 운영사 화면용: 운영사·센터 직원에게 배정
   - 화주 포털용: 화주사 사용자에게 배정
2. 권한 표에서 메뉴·버튼을 체크합니다.
   - 버튼 권한(등록·수정 등)을 체크하면 **조회도 자동으로** 체크됩니다.
   - 조회를 풀면 그 메뉴의 줄 전체가 풀립니다.
   - 묶음 이름 옆 체크로 기준정보·입고 같은 묶음 전체를 한 번에 고를 수 있습니다.

> 영역을 바꾸면 다른 영역의 권한은 의미가 없어서 체크가 모두 비워집니다.

<!-- 권한: system.roles.update -->
## 수정

이름·설명·권한을 바꿀 수 있습니다. 이 그룹을 받은 사용자 모두에게 **다음 화면 이동부터** 적용됩니다.

<!-- 권한: system.roles.delete -->
## 삭제

사용자가 한 명이라도 이 그룹을 받고 있으면 지울 수 없습니다. 먼저 사용자 화면에서 그룹을 빼 주세요. 삭제는 되돌릴 수 없습니다.
