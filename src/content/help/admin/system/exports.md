---

수량은 모두 **기본단위**이고, 엑셀에서 더할 수 있게 숫자로 들어갑니다. 센터 직원은 소속 센터의 자료만 받습니다.

| 자료 | 내용 |
| - | - |
| 입고 실적 | 기간 안에 입고 확정한 줄 (확정 일시·번호, ASN, 화주사 문서 번호, 품목, 로트, 수량, 확정자) |
| 기간 재고 수불 | 화주사·품목별 **기초 재고 + 입고 + 조정(+) + 조정(−) = 기말 재고**. 보관료 정산의 기초 자료입니다. 적치 같은 이동은 위치만 바뀌어 합계에 영향이 없습니다 |
| 현재 재고 | 지금 재고 (로케이션·로트별, 수량 0 제외) |

## [엑셀 내려받기]

1. **자료**를 고릅니다. 입고 실적·재고 수불은 **기간**(최대 1년)이 필요합니다. 처음에는 이번 달 1일 ~ 오늘입니다.
2. 필요하면 **센터·화주사**로 좁힙니다.
3. [엑셀 내려받기]를 누릅니다. 1만 행을 넘으면 앞의 1만 행만 담기므로 기간·조건을 좁혀 나눠 받습니다.
