센터가 "언제 일하는가"를 정합니다. 국가 공휴일은 공공데이터포털에서 자동으로 가져오고, 회사 사정에 맞는 휴무일(쉬는 날)과 특근일(쉬는 날이지만 일하는 날)은 여기서 등록합니다.

![휴무관리 목록](/help/admin/system/holidays/list.png)

① 연도별 국가 공휴일 가져오기 결과 · ② 개별 휴일(누르면 수정) · ③ [공휴일 다시 가져오기]

| 구분 | 뜻 |
| - | - |
| 국가 공휴일 | 공공데이터포털에서 가져온 공휴일(대체·임시공휴일 포함). 전국 공통이라 고치거나 지울 수 없습니다 |
| 휴무 | 운영사나 센터가 쉬는 날 (예: 종무식, 설비 점검, 재고 실사) |
| 특근 | 국가 공휴일이나 쉬는 요일이어도 일하는 날 (예: 설 연휴 전 토요일) |

## 영업일을 정하는 순서

어떤 날 센터가 일하는지는 아래 순서로 먼저 맞는 것을 따릅니다.

1. 그 센터를 골라 등록한 휴무·특근
2. 운영사 전체로 등록한 휴무·특근
3. 국가 공휴일 → 쉼
4. 센터의 운영 요일(센터 화면의 운영 요일)

> [!TIP]
> 운영사 전체를 특근으로 정해도, 어느 센터가 그날 점검으로 쉬면 그 센터를 골라 **휴무**로 등록하세요. 센터를 고른 휴일이 먼저입니다.

## 국가 공휴일

- 화면을 열 때 올해·내년 공휴일이 아직 없으면 자동으로 가져옵니다. 내년 공휴일이 아직 발표되지 않았으면 "발표 전"으로 보이고, 하루에 한 번 다시 확인합니다.
- 화면 위쪽 배지에 연도별 결과(가져온 날 수 · 발표 전 · 실패)가 보입니다. 배지에 마우스를 올리면 실패 사유가 나옵니다.

> [!WARNING]
> 공휴일 API 키가 없으면 국가 공휴일을 가져오지 못한다는 안내가 나옵니다. 시스템 담당자에게 공공데이터포털 「한국천문연구원_특일 정보」 키 설정을 요청하세요.

## [공휴일 다시 가져오기]

임시공휴일이 새로 지정됐을 때 씁니다.

1. [공휴일 다시 가져오기]를 누르고 연도를 고릅니다.
2. [가져오기]를 누르면 그 연도의 국가 공휴일을 통째로 다시 받습니다. 받지 못하면 기존 공휴일은 그대로 둡니다.

<!-- 권한: system.holidays.create -->
## [휴일 등록]

1. **날짜**와 **구분**(휴무 / 특근)을 고릅니다.
2. **적용 범위**에서 센터를 고르면 그 센터에만, 비우면(운영사 전체) 모든 센터에 적용됩니다.
3. **이름**을 넣고 [저장]합니다.

> [!NOTE]
> 같은 범위(운영사 전체 또는 같은 센터)에 같은 날짜는 한 건만 등록할 수 있습니다. 운영사 전체와 센터는 같은 날짜여도 따로 등록할 수 있습니다.

## 수정

목록에서 개별 휴일을 누르면 수정 창이 열립니다. 날짜·구분·적용 범위·이름을 모두 고칠 수 있습니다.

<!-- 권한: system.holidays.delete -->
## 삭제 · 되살리기

- 목록에서 골라 [삭제]하거나, 수정 창의 [삭제]를 누릅니다. 국가 공휴일은 고를 수 없습니다. 국가 공휴일에 일하려면 같은 날짜로 **특근**을 등록하세요.
- 상세 조건의 상태 **삭제됨**에서 지운 휴일을 보고 [되살리기]할 수 있습니다. 그 사이 같은 범위·같은 날짜에 다른 휴일을 등록했으면 되살릴 수 없습니다.
