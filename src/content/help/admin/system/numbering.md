화주사·거래처·납품처·품목 코드와 입고예정·입고확정·관리 라벨·실사/조정 번호는 **비워 두고 저장하면 여기 규칙대로 자동으로 붙습니다**.

![체번 규칙 목록](/help/admin/system/numbering/list.png)

① 대상별 번호 모양·다음 번호·적용 규칙 · ② 대상 이름을 누르면 수정 화면

| 칸 | 뜻 |
| - | - |
| 번호 모양 | 접두어 + 구분 문자 + 날짜 + 구분자 + 일련번호. `0` 개수가 일련번호 자리수 |
| 다음 번호 | 지금 저장하면 붙을 번호의 예. 화주 접두어가 붙는 대상은 첫 화주사 기준 |
| 번호 범위 | 이 범위마다 일련번호를 따로 셉니다 (예: 품목은 화주사마다 1부터) |
| 적용 규칙 | **시스템 기본** 또는 우리 운영사가 바꾼 **운영사 규칙** |
| 발급한 번호 | 이 대상으로 이미 자동 번호를 붙인 적이 있는지 |

## 번호 모양 바꾸기

![체번 규칙 수정](/help/admin/system/numbering/edit.png)

① 번호 모양 칸 · ② 미리보기(다음 번호·시스템 기본) · ③ 화면 버튼

<!-- 권한: system.numbering.update -->
## [저장]

1. 바꿀 수 있는 칸은 **고정 접두어**(영문 대문자 1~5자), **구분 문자**(영문 대문자 1자), **날짜**(YYMMDD), **구분자**, **일련번호 자리수**(2~8), **일련번호 초기화**(매일·매월·매년)입니다.
2. 칸을 바꾸면 아래 **미리보기**에 다음 번호가 바로 나옵니다.
3. [저장]하면 앞으로 붙는 번호부터 새 모양이 됩니다.

> [!NOTE]
> 번호 범위와 접두어 출처(화주 접두어·거래처코드)는 대상마다 정해진 구조라 바꿀 수 없습니다. 초기화 주기를 쓰려면 날짜가 있어야 합니다(같은 번호가 다시 나오지 않게).

> [!WARNING]
> 이미 붙은 번호는 그대로 남고 일련번호는 이어집니다. 새 모양의 번호가 **이미 있는 코드**(예전에 직접 넣은 코드 등)와 겹치면 저장되지 않고 겹치는 코드를 알려 줍니다. 코드 칸 길이를 넘는 모양도 저장할 수 없습니다.

<!-- 권한: system.numbering.update -->
## [기본으로 되돌리기]

- 운영사 규칙을 지우고 시스템 기본 모양으로 돌아갑니다. 이때도 겹치는 코드가 있는지 먼저 확인합니다.
